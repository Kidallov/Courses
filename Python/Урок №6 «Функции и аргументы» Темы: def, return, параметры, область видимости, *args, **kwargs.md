## Что такое функция?<!-- {"fold":true} -->

**Функция** — это именованный блок кода, который предназначен для выполнения одной конкретной задачи. Функции помогают структурировать программу, делают код более читаемым, устраняют дублирование и позволяют легко повторно использовать код.

Представьте себе функцию как "чёрный ящик": вы передаёте ему какие-то данные (входные данные), он выполняет внутри себя какие-то операции, и возвращает вам результат (выходные данные). Вам не обязательно знать, *как* именно он это делает, главное — *что* он делает.

## Объявление функции. `def`<!-- {"fold":true} -->

Для объявления функции в Python используется ключевое слово `def`.

```python
def имя_функции():
    # Тело функции
    # Код, который выполняется при вызове
Пример: Простая функция-приветствие

def say_hello():
    print("Привет, мир!")

# Вызов функции
say_hello()  # Выведет: Привет, мир!
```

## Ключевое слово `return`<!-- {"fold":true} -->

Функция может не только выполнять действия (например, печатать текст), но и возвращать результат своей работы. Для этого используется ключевое слово `return`.

- `return` завершает выполнение функции и передаёт указанное значение обратно в то место, откуда функция была вызвана.
- Если после `return` есть другие строки кода в функции, они выполнены не будут.
- Если функция не содержит `return` или содержит `return` без значения, она возвращает специальное значение `None`.

**Пример: Функция, возвращающая сумму двух чисел**

```python
def add_numbers(a, b):
    result = a + b
    return result

# Вызов функции и сохранение результата
sum_result = add_numbers(5, 3)
print(sum_result)  # Выведет: 8
```

**Пример: Функция с `return` без значения (прерывание)**

```python
def check_age(age):
    if age < 0:
        print("Возраст не может быть отрицательным!")
        return  # Функция завершится здесь, если age < 0
    print(f"Вам {age} лет.")

check_age(25)  # Выведет: "Вам 25 лет."
check_age(-5)  # Выведет: "Возраст не может быть отрицательным!" и завершится.
```

## Параметры и аргументы<!-- {"fold":true} -->

Важно различать эти два понятия:

- **Параметры** — это переменные, указанные в скобках при *объявлении* функции. Они являются "заглушками" для будущих данных.
- **Аргументы** — это конкретные значения, которые мы передаём в функцию при её *вызове*.

```python
# a и b - это параметры
def multiply(a, b):
    return a * b

# 5 и 4 - это аргументы
result = multiply(5, 4)
```

### Типы аргументов

1. **Позиционные аргументы:** Значения аргументов присваиваются параметрам в порядке их следования.

   ```python
   def greet(name, greeting):
       print(f"{greeting}, {name}!")
   
   greet("Анна", "Привет")  # Привет, Анна!
   # "Анна" -> name, "Привет" -> greeting
   ```

2. **Именованные (keyword) аргументы:** Позволяют передавать аргументы, явно указывая имя параметра. Порядок передачи при этом не важен.

   ```python
   greet(greeting="Добрый день", name="Петр")  # Добрый день, Петр!
   ```

3. **Аргументы по умолчанию:** Параметрам можно задавать значения по умолчанию. Если при вызове не передать соответствующий аргумент, будет использовано значение по умолчанию. Такие параметры всегда должны следовать после параметров без умолчания.

   ```python
   def greet(name, greeting="Здравствуй"):
       print(f"{greeting}, {name}!")
   
   greet("Мария")           # Здравствуй, Мария!
   greet("Иван", "Привет")  # Привет, Иван!
   ```

## Область видимости (Scope)<!-- {"fold":true} -->

Область видимости определяет, в каких частях программы "видна" и может быть использована переменная.

- **Глобальная область видимости:** Переменные, объявленные вне всех функций. Они доступны для чтения в любом месте программы, в том числе внутри функций.
- **Локальная область видимости:** Переменные, объявленные внутри функции. Они создаются при вызове функции и уничтожаются после её завершения. Они не видны за пределами функции.

```python
x = 10  # Глобальная переменная

def my_function():
    y = 20  # Локальная переменная
    print(f"Внутри функции: x = {x}")  # Можно читать глобальную x
    print(f"Внутри функции: y = {y}")

my_function()
print(f"Снаружи функции: x = {x}")  # Выведет: 10
# print(f"Снаружи функции: y = {y}")  # ОШИБКА! NameError: name 'y' is not defined
```

### Ключевое слово `global`

Если нужно *изменить* глобальную переменную внутри функции, необходимо использовать ключевое слово `global`.

```python
counter = 0

def increment():
    global counter  # Объявляем, что будем использовать глобальную переменную counter
    counter += 1
    print(f"Счётчик: {counter}")

increment()  # Счётчик: 1
increment()  # Счётчик: 2
```

**Важный нюанс:** Без `global` Python создаст новую локальную переменную, и глобальное значение не изменится.

```python
counter = 0

def bad_increment():
    counter = 1  # Создаётся новая локальная переменная, глобальная counter не меняется
    print(f"Локальный счётчик: {counter}")

bad_increment()  # Локальный счётчик: 1
print(f"Глобальный счётчик: {counter}")  # Глобальный счётчик: 0
```

## Произвольное количество аргументов: `*args` и `**kwargs`<!-- {"fold":true} -->

Иногда нужно создать функцию, которая может принимать разное количество аргументов. Для этого в Python есть два специальных синтаксиса.

### `*args` (Arbitrary Arguments List)<!-- {"fold":true} -->

Позволяет функции принимать произвольное количество **позиционных** аргументов. Внутри функции `args` представляется в виде **кортежа**.

```python
def sum_all(*args):
    print(f"args = {args}, тип = {type(args)}")
    total = 0
    for number in args:
        total += number
    return total

print(sum_all(1, 2))        # args = (1, 2), тип = <class 'tuple'> -> 3
print(sum_all(1, 2, 3, 4))  # args = (1, 2, 3, 4), тип = <class 'tuple'> -> 10
print(sum_all())            # args = (), тип = <class 'tuple'> -> 0
```

### `**kwargs` (Arbitrary Keyword Arguments)<!-- {"fold":true} -->

Позволяет функции принимать произвольное количество **именованных** аргументов. Внутри функции `kwargs` представляется в виде **словаря**.

```python
def create_user_profile(**kwargs):
    print(f"kwargs = {kwargs}, тип = {type(kwargs)}")
    profile = {}
    for key, value in kwargs.items():
        profile[key] = value
    return profile

user1 = create_user_profile(name="Alice", age=30)
# kwargs = {'name': 'Alice', 'age': 30}, тип = <class 'dict'>
# user1 = {'name': 'Alice', 'age': 30}

user2 = create_user_profile(username="bob", email="bob@mail.com", country="USA")
# kwargs = {'username': 'bob', 'email': 'bob@mail.com', 'country': 'USA'}
# user2 = {'username': 'bob', 'email': 'bob@mail.com', 'country': 'USA'}
```

### Комбинирование всех типов аргументов<!-- {"fold":true} -->

Порядок следования параметров в объявлении функции строго регламентирован:

1. Обычные позиционные параметры.
2. Параметры с `*args`.
3. Параметры со значением по умолчанию (если не используются `**kwargs`).
4. Параметры с `**kwargs`.

```python
def super_function(pos1, pos2, *args, default_param="default", **kwargs):
    print(f"Позиционные: {pos1}, {pos2}")
    print(f"*args: {args}")
    print(f"Аргумент по умолчанию: {default_param}")
    print(f"**kwargs: {kwargs}")

super_function(1, 2, 3, 4, 5, default_param="моё значение", key1="val1", key2="val2")
```

**Вывод:**

```
Позиционные: 1, 2
*args: (3, 4, 5)
Аргумент по умолчанию: моё значение
**kwargs: {'key1': 'val1', 'key2': 'val2'}
```

**Задача: Валидатор данных пользователя**

Напишите функцию `validate_user_data(**kwargs)`, которая проверяет переданные данные пользователя. Функция должна принимать именованные аргументы. Правила валидации:

- `username`: Должен быть не короче 5 символов.
- `age`: Должен быть целым числом и больше или равен 18.
- `email`: Должен содержать символ `@`.

Функция должна возвращать `True`, если все переданные данные корректны, и `False` — если хотя бы одно правило нарушено. Учтите, что аргументы могут передаваться в любом порядке и их может не быть вовсе.

*Пример:*
```python
print(validate_user_data(username="john_doe", age=25, email="john@example.com")) # True
print(validate_user_data(username="al", age=25, email="john@example.com"))       # False (короткий username)
print(validate_user_data(age=16, email="john@example.com"))                      # False (малый возраст)
```
