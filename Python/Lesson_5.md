# Урок 5. Функции и аргументы в Python

**Тема:** `def`, `return`, параметры и аргументы, область видимости переменных, `*args`, `**kwargs`.

## 1. Что такое функция?

Функция — это именованный блок кода, который выполняет определённую задачу.

Представь, что тебе нужно десять раз выводить приветствие.

Без функции:

```python
print("Привет, Александр!")
print("Привет, Александр!")
print("Привет, Александр!")
```

Код работает, но если приветствие потребуется изменить, придётся редактировать каждую строку.

С функцией:

```python
def say_hello():
    print("Привет, Александр!")


say_hello()
say_hello()
say_hello()
```

Результат:

```text
Привет, Александр!
Привет, Александр!
Привет, Александр!
```

Теперь разберём код:

- `def` — ключевое слово для объявления функции.
- `say_hello` — имя функции.
- `()` — круглые скобки, внутри которых указываются параметры.
- `:` — начало тела функции.
- Отступ в четыре пробела обозначает блок кода, принадлежащий функции.

**Важно:** объявление функции само по себе не выполняет её тело.

Чтобы функция выполнилась, её нужно вызвать:

```python
say_hello()
```

Это называется вызовом функции.

### 1.1. Функция с параметром

Допустим, мы хотим приветствовать разных людей.

```python
def say_hello(name):
    print(f"Привет, {name}!")


say_hello("Александр")
say_hello("Иван")
say_hello("Мария")
```

Результат:

```text
Привет, Александр!
Привет, Иван!
Привет, Мария!
```

Функция получает имя и использует его внутри своего тела.

В этом примере `name` — параметр функции.

Строки `"Александр"`, `"Иван"` и `"Мария"` — аргументы, которые передаются при вызове.

Подробнее разницу между параметрами и аргументами разберём далее.

### Когда нужны функции?

Функции особенно полезны, когда:

1. Один и тот же код используется несколько раз.
2. Нужно разделить большую программу на небольшие части.
3. Нужно упростить чтение и тестирование кода.
4. Нужно отделить вычисления от ввода и вывода.
5. Нужно повторно использовать готовую логику.

## 2. Параметры и аргументы

Это одна из важнейших тем урока.

**Параметр** — переменная, указанная в определении функции.

**Аргумент** — конкретное значение, передаваемое функции при вызове.

Пример:

```python
def add(a, b):
    return a + b


result = add(10, 20)
print(result)
```

Результат:

```text
30
```

Разберём:

```python
def add(a, b):
```

`a` и `b` — параметры.

```python
add(10, 20)
```

`10` и `20` — аргументы.

Во время вызова Python связывает переданные значения с соответствующими параметрами:

```python
a = 10
b = 20
```

После этого выполняется тело функции.

### 2.1. Функция с одним параметром

```python
def square(number):
    return number ** 2


print(square(5))
print(square(10))
print(square(3))
```

Результат:

```text
25
100
9
```

Функция принимает число и возвращает его квадрат.

### 2.2. Функция с несколькими параметрами

```python
def multiply(a, b):
    return a * b


print(multiply(4, 5))
print(multiply(7, 3))
```

Результат:

```text
20
21
```

### 2.3. Позиционные аргументы

Позиционные аргументы передаются в соответствии с порядком параметров.

```python
def introduce(name, age):
    print(f"Меня зовут {name}, мне {age} лет.")


introduce("Александр", 25)
```

Результат:

```text
Меня зовут Александр, мне 25 лет.
```

Первый аргумент передаётся в `name`, второй — в `age`.

Если поменять порядок:

```python
introduce(25, "Александр")
```

Получим:

```text
Меня зовут 25, мне Александр лет.
```

Python не всегда сможет определить, что аргументы переданы неправильно. Он просто присвоит значения указанным параметрам.

Поэтому нужно внимательно следить за порядком аргументов.

### 2.4. Именованные аргументы

Можно явно указывать, какому параметру соответствует значение.

```python
def introduce(name, age):
    print(f"Меня зовут {name}, мне {age} лет.")


introduce(name="Александр", age=25)
```

Результат:

```text
Меня зовут Александр, мне 25 лет.
```

Теперь порядок можно менять:

```python
introduce(age=25, name="Александр")
```

Результат будет таким же.

Именованные аргументы особенно полезны, когда функция принимает несколько параметров.

### 2.5. Параметры со значениями по умолчанию

Иногда параметру можно заранее задать значение.

```python
def say_hello(name="Гость"):
    print(f"Привет, {name}!")


say_hello()
say_hello("Bob")
```

Результат:

```text
Привет, Гость!
Привет, Bob!
```

В первом вызове аргумент не передан, поэтому используется значение по умолчанию.

Во втором вызове переданное значение заменяет значение по умолчанию.

Рассмотрим более практический пример:

```python
def calculate_price(price, discount=0):
    return price - price * discount / 100


print(calculate_price(1000))
print(calculate_price(1000, 10))
print(calculate_price(2000, 25))
```

Результат:

```text
1000.0
900.0
1500.0
```

Если скидка не указана, используется `0`.

**Правило:** параметры со значениями по умолчанию обычно располагают после обязательных параметров.

Правильно:

```python
def create_player(name, age=18):
    pass
```

Неправильно:

```python
# SyntaxError
def create_player(age=18, name):
    pass
```

Здесь `pass` — инструкция-заглушка. Она позволяет оставить тело функции пустым, пока ты не реализовал её логику.

### 2.6. Важная ошибка со значениями по умолчанию

Не рекомендуется использовать изменяемые объекты, например списки и словари, в качестве значений по умолчанию.

Проблемный пример:

```python
def add_player(name, players=[]):
    players.append(name)
    return players


print(add_player("Иван"))
print(add_player("Пётр"))
```

Может показаться, что результат будет таким:

```text
['Иван']
['Пётр']
```

Но фактический результат:

```text
['Иван']
['Иван', 'Пётр']
```

Причина: список создаётся один раз при определении функции и повторно используется при последующих вызовах.

Правильный вариант:

```python
def add_player(name, players=None):
    if players is None:
        players = []

    players.append(name)
    return players


print(add_player("Иван"))
print(add_player("Пётр"))
```

Результат:

```text
['Иван']
['Пётр']
```

Здесь при каждом вызове без переданного списка создаётся новый список.

**Запомни:** для изменяемых значений по умолчанию обычно используют `None`, а нужный объект создают внутри функции.

## 3. Что делает `return`?

`return` — завершает выполнение функции и возвращает результат вызывающему коду.

Рассмотрим пример:

```python
def add(a, b):
    return a + b


result = add(10, 20)
print(result)
```

Результат:

```text
30
```

Функция вычислила сумму и вернула её.

Обрати внимание: функция не выводит сумму на экран самостоятельно. Она возвращает значение, которое можно сохранить в переменную, передать другой функции или использовать в вычислениях.

### 3.1. Разница между `print` и `return`

Это принципиально важный момент.

Посмотрим на первую функцию:

```python
def add(a, b):
    print(a + b)


result = add(10, 20)
print(result)
```

Результат:

```text
30
None
```

Почему?

Внутри функции находится `print(a + b)`. Он выводит число `30` на экран, но не возвращает его вызывающему коду.

Переменная `result` получает значение `None`.

Теперь второй вариант:

```python
def add(a, b):
    return a + b


result = add(10, 20)
print(result)
```

Результат:

```text
30
```

В этом случае функция возвращает число `30`, которое сохраняется в `result`.

Разница:

| `print()` | `return` |
|---|---|
| Выводит информацию на экран | Возвращает значение из функции |
| Сам по себе не завершает функцию | Завершает выполнение функции |
| Удобен для отображения и отладки | Удобен для вычислений и передачи данных |
| Не заменяет возвращаемое значение | Позволяет использовать результат дальше |

Функция может одновременно использовать `print()` и `return`, но эти инструкции решают разные задачи.

Например:

```python
def calculate_sum(a, b):
    result = a + b
    print(f"Вычислена сумма: {result}")
    return result


total = calculate_sum(10, 20)
print(total * 2)
```

Результат:

```text
Вычислена сумма: 30
60
```

### 3.2. Что происходит после `return`?

Как только выполняется `return`, функция заканчивает работу.

```python
def check_number(number):
    return number > 0
    print("Эта строка не выполнится")


print(check_number(5))
```

Результат:

```text
True
```

Инструкция `print()` после `return` недостижима.

Это часто становится причиной ошибок в коде.

### 3.3. Функция может возвращать разные значения

```python
def divide(a, b):
    if b == 0:
        return None

    return a / b


print(divide(10, 2))
print(divide(10, 0))
```

Результат:

```text
5.0
None
```

В данном примере `None` обозначает отсутствие результата при делении на ноль.

В реальных приложениях способ обработки такой ситуации зависит от задачи. Иногда лучше выбросить исключение, иногда вернуть специальное значение.

### 3.4. Несколько `return` в одной функции

```python
def get_grade(score):
    if score >= 90:
        return "Отлично"

    if score >= 70:
        return "Хорошо"

    if score >= 50:
        return "Удовлетворительно"

    return "Неудовлетворительно"


print(get_grade(95))
print(get_grade(75))
print(get_grade(55))
print(get_grade(30))
```

Результат:

```text
Отлично
Хорошо
Удовлетворительно
Неудовлетворительно
```

Функция возвращает результат в зависимости от условия.

Важный момент: после выполнения первого подходящего `return` остальные инструкции функции не выполняются.

### 3.5. Функция может возвращать несколько значений

Python позволяет вернуть несколько значений через запятую.

```python
def calculate(a, b):
    total = a + b
    difference = a - b

    return total, difference


result = calculate(10, 3)
print(result)
```

Результат:

```text
(13, 7)
```

Фактически функция возвращает кортеж.

Можно сразу распаковать его:

```python
total, difference = calculate(10, 3)

print(total)
print(difference)
```

Результат:

```text
13
7
```

Это удобно, когда функция должна вернуть несколько связанных результатов.

## 4. Область видимости переменных

Область видимости определяет, где в программе доступна переменная.

В Python важно понимать два основных случая:

- Локальные переменные.
- Глобальные переменные.

### 4.1. Локальные переменные

Локальная переменная создаётся внутри функции и обычно доступна только внутри неё.

```python
def calculate():
    result = 10 + 20
    print(result)


calculate()
```

Результат:

```text
30
```

Переменная `result` локальная.

Попробуем обратиться к ней за пределами функции:

```python
def calculate():
    result = 10 + 20


calculate()
print(result)
```

Получим ошибку:

```text
NameError: name 'result' is not defined
```

Почему?

Переменная `result` была создана внутри функции и не стала глобальной переменной.

Если нужно использовать результат снаружи, его следует вернуть:

```python
def calculate():
    result = 10 + 20
    return result


value = calculate()
print(value)
```

Результат:

```text
30
```

Здесь `result` остаётся локальной переменной, а возвращённое значение сохраняется в другой переменной — `value`.

### 4.2. Глобальные переменные

Глобальная переменная объявляется за пределами функций.

```python
league_name = "Polar Football League"


def show_league():
    print(league_name)


show_league()
```

Результат:

```text
Polar Football League
```

Функция может читать глобальную переменную.

Но если внутри функции ты присваиваешь значение имени переменной, Python обычно считает это имя локальным.

Рассмотрим ошибку:

```python
counter = 0


def increase_counter():
    counter = counter + 1
    print(counter)


increase_counter()
```

Этот код вызовет `UnboundLocalError`.

Python определяет, что `counter` внутри функции является локальной переменной из-за присваивания. Однако её значение используется до того, как оно было присвоено.

#### Как изменить глобальную переменную?

Для этого существует ключевое слово `global`.

```python
counter = 0


def increase_counter():
    global counter
    counter += 1


increase_counter()
increase_counter()
print(counter)
```

Результат:

```text
2
```

Инструкция `global counter` сообщает Python, что внутри функции нужно работать с глобальной переменной `counter`.

Однако **не стоит злоупотреблять глобальными переменными**.

Они усложняют понимание программы, тестирование и поиск ошибок. В большинстве случаев лучше передавать данные через параметры и возвращать результаты через `return`.

Например, вместо глобального счётчика:

```python
def increase_counter(counter):
    return counter + 1


counter = 0
counter = increase_counter(counter)
counter = increase_counter(counter)

print(counter)
```

Результат:

```text
2
```

Такую функцию легче тестировать и повторно использовать.

### 4.3. Вложенные функции

В Python можно объявлять функцию внутри другой функции.

```python
def outer():
    message = "Привет из внешней функции"

    def inner():
        print(message)

    inner()


outer()
```

Результат:

```text
Привет из внешней функции
```

Внутренняя функция может обращаться к переменным внешней функции.

Если нужно изменить такую переменную, используется `nonlocal`.

```python
def outer():
    counter = 0

    def inner():
        nonlocal counter
        counter += 1

    inner()
    inner()

    print(counter)


outer()
```

Результат:

```text
2
```

`nonlocal` позволяет обращаться к переменной из ближайшей внешней области видимости, отличной от глобальной.

На начальном этапе достаточно запомнить:

- Local — переменная внутри функции.
- Global — переменная на уровне модуля.
- Nonlocal — переменная во внешней, но не глобальной функции.

### 4.4. Как Python ищет переменные?

Упрощённо Python использует правило **LEGB**:

| Область | Название | Где искать |
|---|---|---|
| L | Local | В текущей функции |
| E | Enclosing | Во внешних функциях |
| G | Global | На уровне модуля |
| B | Built-in | Среди встроенных имён Python |

Пример:

```python
name = "Глобальное имя"


def outer():
    name = "Имя внешней функции"

    def inner():
        name = "Локальное имя"
        print(name)

    inner()
    print(name)


outer()
print(name)
```

Результат:

```text
Локальное имя
Имя внешней функции
Глобальное имя
```

Каждая переменная `name` существует в своей области видимости.

## 5. Что такое `*args`?

Иногда заранее неизвестно, сколько аргументов передадут функции.

Например, нужно написать функцию, которая складывает произвольное количество чисел.

Обычная функция:

```python
def add(a, b):
    return a + b


print(add(10, 20))
```

Она принимает только два аргумента.

Если передать три:

```python
add(10, 20, 30)
```

Python выдаст ошибку, потому что функция не ожидает три позиционных аргумента.

Для решения этой задачи можно использовать `*args`.

`*args` позволяет функции принимать произвольное количество дополнительных позиционных аргументов.

Пример:

```python
def add_all(*args):
    print(args)


add_all(10, 20, 30)
add_all(1, 2, 3, 4, 5)
add_all(100)
```

Результат:

```text
(10, 20, 30)
(1, 2, 3, 4, 5)
(100,)
```

Внутри функции `args` представляет собой кортеж.

Обрати внимание: звёздочка `*` — специальный синтаксис Python, а `args` — обычное имя переменной. Теоретически можно использовать другое имя, но `args` является общепринятым соглашением.

### 5.1. Сумма произвольного количества чисел

```python
def add_all(*args):
    total = 0

    for number in args:
        total += number

    return total


print(add_all(10, 20))
print(add_all(1, 2, 3, 4, 5))
print(add_all(100, 200, 300, 400))
```

Результат:

```text
30
15
1000
```

Разберём алгоритм:

1. Функция принимает произвольное количество позиционных аргументов.
2. Python собирает их в кортеж `args`.
3. Цикл `for` перебирает числа.
4. Каждое число прибавляется к `total`.
5. `return` возвращает итоговую сумму.

### 5.2. Функция с обычными параметрами и `*args`

`*args` можно использовать вместе с обычными параметрами.

```python
def print_order(customer_name, *items):
    # customer_name — обычный параметр
    # *items — собирает все остальные переданные аргументы в кортеж (tuple)
    
    print(f"Заказчик: {customer_name}")
    print("Товары в корзине:")
    
    for item in items:
        print(f"- {item}")

# Вызов функции
print_order("Алексей", "Ноутбук", "Мышь", "Коврик")
```

### 5.3. Что произойдёт, если не передать аргументы?

```python
def print_order(*args):
    print(args)


print_order()
```

Результат:

```text
()
```

Пустой кортеж означает, что функция не получила позиционных аргументов.

### 5.4. Распаковка списка с помощью `*`

Звёздочка `*` используется не только при объявлении функций.

Она также позволяет распаковать итерируемый объект в отдельные аргументы.

```python
def add(a, b, c):
    return a + b + c


numbers = [10, 20, 30]

print(add(*numbers))
```

Результат:

```text
60
```

Вызов:

```python
add(*numbers)
```

эквивалентен вызову:

```python
add(10, 20, 30)
```

Это полезно, когда значения уже находятся в списке или кортеже.

## 6. Что такое `**kwargs`?

`**kwargs` позволяет функции принимать произвольное количество дополнительных именованных аргументов.

Если `*args` собирает позиционные аргументы в кортеж, то `**kwargs` собирает именованные аргументы в словарь.

Пример:

```python
def show_info(**kwargs):
    print(kwargs)


show_info(name="Bob", age=17, city="New-York")
```

Результат:

```text
{'name': 'Bob', 'age': 17, 'city': 'New-York'}
```

Внутри функции `kwargs` — обычный словарь.

Здесь:

- `name` — ключ, `"Bob"` — значение.
- `age` — ключ, `17` — значение.
- `city` — ключ, `"New-York"` — значение.

Как и в случае с `args`, имя `kwargs` — соглашение, а не ключевое слово Python.

### 6.1. Перебор `kwargs`

Поскольку `kwargs` — словарь, его можно обрабатывать стандартными методами.

```python
def show_info(**kwargs):
    for key, value in kwargs.items():
        print(f"{key}: {value}")


show_info(
    name="Bob",
    age=17,
    city="New-York",
)
```

Результат:

```text
name: Bob
age: 17
city: New-York
```

Метод `.items()` позволяет перебирать пары «ключ — значение».

### 6.2. Распаковка словаря с помощью `**`

Допустим, у нас есть словарь:

```python
player = {
    "name": "Bob",
    "age": 17,
    "position": "Def",
}
```

И функция:

```python
def show_player(name, age, position):
    print(f"{name}, {age} years old, position: {position}")


show_player(**player)
```

Результат:

```text
Bob, 17 years old, position: Def
```

Выражение:

```python
show_player(**player)
```

эквивалентно:

```python
show_player(
    name="Bob",
    age=17,
    position="Def",
)
```

Это называется распаковкой словаря в именованные аргументы.

## 7. Совместное использование параметров, `*args` и `**kwargs`

В одной функции можно использовать обычные параметры, `*args` и `**kwargs`.

Пример:

```python
def example(name, *args, **kwargs):
    print("name:", name)
    print("args:", args)
    print("kwargs:", kwargs)


example(
    "Bob",
    10,
    20,
    30,
    age=25,
    city="Берлин",
)
```

Результат:

```text
name: Bob
args: (10, 20, 30)
kwargs: {'age': 25, 'city': 'Берлин'}
```

Разберём распределение аргументов:

- `"Bob"` передаётся в `name`.
- `10`, `20`, `30` собираются в кортеж `args`.
- `age=25` и `city="Берлин"` собираются в словарь `kwargs`.

### 7.1. Порядок параметров

При использовании этих конструкций важно соблюдать правильный порядок.

Например:

```python
def example(name, *args, **kwargs):
    pass
```

Это корректно.

А вот такой вариант вызовет синтаксическую ошибку:

```python
# SyntaxError
def example(**kwargs, *args):
    pass
```

Для обычных параметров, `*args` и `**kwargs` действует установленный синтаксис.

Существует также специальный синтаксис для ограничения способов передачи аргументов, который пригодится позже.

Например:

```python
def create_player(name, age, *, position):
    print(name, age, position)


create_player("Bob", 17, position="Def")
```

Результат:

```text
Bob 17 Def
```

Здесь `position` — параметр, который разрешено передавать только по имени.

Такой способ помогает сделать вызовы функций более понятными и предотвращает случайную передачу аргументов не в том порядке.

## 8. Полезные правила при написании функций

### Правило 1. Одна функция — одна ответственность

Не стоит создавать функцию, которая одновременно работает с несколькими данными. Лучше разделить такую логику на отдельные функции.

### Правило 2. Используй `return`, когда результат нужен дальше

```python
def calculate_area(width, height):
    return width * height
```

Результат можно сохранить или передать другой функции.

### Правило 3. Не используй глобальные переменные без необходимости

Передавай данные через параметры, а результаты возвращай через `return`.

### Правило 4. Выбирай понятные имена

Хорошо:

```python
def calculate_total_price(price, quantity):
    return price * quantity
```

Плохо:

```python
def f(a, b):
    return a * b
```

В коротких математических выражениях `a` и `b` могут быть уместны, но в бизнес-логике лучше использовать осмысленные названия.

### Правило 5. Не используй `*args` и `**kwargs` без необходимости

Если функция должна принимать только `name`, `age` и `position`, лучше объявить эти параметры явно.

### Правило 6. Не путай вывод с возвращением результата

`print()` отображает данные. `return` передаёт результат вызывающему коду.

### Правило 7. Не забывай про типы данных

Если функция ожидает числа, передавай числа. Python позволяет передать другие типы, но это не означает, что вычисление будет корректным.
