# Урок 5. Словари и множества в Python

Сегодня мы изучим две важные структуры данных в Python: **словари (dict)** и **множества (set)**. Эти структуры являются неупорядоченными коллекциями (хотя в современных версиях Python словари сохраняют порядок добавления) и предоставляют уникальные возможности для работы с данными.

**Неупорядоченная коллекция** - означает, что элементы в ней не имеют предопределенного порядка. Это означает, что их нельзя найти или обратиться к ним по индексу, а порядок их расположения при выводе может отличаться от порядка их добавления.

## Часть 1: Словари (dict)<!-- {"fold":true} -->

### Что такое словарь?

**Словарь** — это изменяемая неупорядоченная (до Python 3.7) / упорядоченная (Python 3.7+) коллекция пар "ключ-значение". Ключи должны быть уникальными и хешируемыми (обычно строки, числа или кортежи), а значения могут быть любыми объектами.

### Создание словарей

```python
# Пустой словарь
empty_dict = {}
empty_dict2 = dict()

# Словарь с элементами
student = {
    "name": "Анна",
    "age": 20,
    "course": "Информатика"
}

# С помощью функции dict()
colors = dict(red="красный", blue="синий", green="зеленый")

# Словарь из списка кортежей
pairs = [("a", 1), ("b", 2), ("c", 3)]
from_pairs = dict(pairs)
```

### Доступ к элементам

```python
student = {"name": "Иван", "age": 21, "course": "Математика"}

# Получение значения по ключу
print(student["name"])  # Иван

# Метод get() - безопасный доступ
print(student.get("age"))      # 21
print(student.get("grade"))    # None
print(student.get("grade", "Не указано"))  # "Не указано"

# Проверка наличия ключа
if "name" in student:
    print("Ключ 'name' существует")
```

### Изменение словарей

```python
# Добавление или изменение элемента
student["grade"] = "A"           # Добавление
student["age"] = 22              # Изменение

# Удаление элементов
del student["course"]            # Удаление ключа
age = student.pop("age")         # Удаление с возвратом значения
student.popitem()                # Удаление последней пары (Python 3.7+)

# Очистка словаря
student.clear()
```

### Методы словарей

```python
person = {"name": "Мария", "city": "Москва", "age": 25}

# keys() - все ключи
print(list(person.keys()))      # ['name', 'city', 'age']

# values() - все значения
print(list(person.values()))    # ['Мария', 'Москва', 25]

# items() - все пары ключ-значение
for key, value in person.items():
    print(f"{key}: {value}")

# update() - объединение словарей
person.update({"age": 26, "country": "Россия"})

# copy() - создание копии
person_copy = person.copy()
```

### Распаковка словарей

```python
def print_person(name, city, age):
    print(f"{name} из {city}, {age} лет")

person = {"name": "Петр", "city": "Санкт-Петербург", "age": 30}

# Распаковка при вызове функции
print_person(**person)

# Распаковка в другой словарь
defaults = {"theme": "light", "language": "ru"}
user_settings = {"language": "en", "font_size": 14}
combined = {**defaults, **user_settings}
print(combined)  # {'theme': 'light', 'language': 'en', 'font_size': 14}
```

## Часть 2: Множества (set)<!-- {"fold":true} -->

### Что такое множество?

**Множество** — это неупорядоченная коллекция уникальных элементов. Элементы множества должны быть хешируемыми.

### Создание множеств

```python
# Пустое множество
empty_set = set()  # {} создаст пустой словарь!

# Множество с элементами
numbers = {1, 2, 3, 4, 5}
fruits = {"apple", "banana", "orange"}

# Из других коллекций
from_list = set([1, 2, 2, 3, 3, 3])  # {1, 2, 3}
from_string = set("hello")           # {'h', 'e', 'l', 'o'}
```

### Основные операции с множествами

```python
A = {1, 2, 3, 4, 5}
B = {4, 5, 6, 7, 8}

# Добавление элементов
A.add(6)           # Добавить один элемент
A.update([7, 8])   # Добавить несколько элементов

# Удаление элементов
A.remove(3)        # Удалить элемент (KeyError если нет)
A.discard(10)      # Удалить элемент (без ошибки если нет)
element = A.pop()  # Удалить и вернуть случайный элемент

# Проверка принадлежности
print(4 in A)      # True
print(10 in B)     # False
```

### Операции над множествами

```python
A = {1, 2, 3, 4, 5}
B = {4, 5, 6, 7, 8}

# Объединение
union = A | B              # {1, 2, 3, 4, 5, 6, 7, 8}
union = A.union(B)

# Пересечение
intersection = A & B       # {4, 5}
intersection = A.intersection(B)

# Разность
difference = A - B         # {1, 2, 3}
difference = A.difference(B)

# Симметрическая разность
sym_diff = A ^ B           # {1, 2, 3, 6, 7, 8}
sym_diff = A.symmetric_difference(B)

# Сравнение множеств
print(A <= B)              # False (A не подмножество B)
print(A >= {1, 2})         # True (A надмножество {1, 2})
```

## Важные нюансы<!-- {"fold":true} -->

### Для словарей:
- Ключи должны быть хешируемыми (для ключа можно вычислить хеш-значение, а сам ключ не изменяется со временем)
- Словари сохраняют порядок добавления с Python 3.7
- Метод `get()` безопаснее прямого обращения по ключу
- Распаковка полезна для передачи параметров в функции

### Для множеств:
- Элементы должны быть хешируемыми
- Множества неупорядоченны
- Полезны для удаления дубликатов
- Операции над множествами очень эффективны

### Производительность:
- Поиск в словаре и множестве: O(1)
- Поиск в списке: O(n)
- Используйте множества для проверки принадлежности

## Заключение<!-- {"fold":true} -->

Словари и множества — мощные инструменты в Python, которые значительно упрощают работу с данными. Словари идеальны для организации данных по ключам, а множества — для работы с уникальными элементами и выполнения математических операций над наборами.
