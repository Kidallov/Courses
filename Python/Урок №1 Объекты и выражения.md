## 2. Всё — объект
В Python **всё является объектом**: числа, строки, функции и даже программы.

Примеры объектов:
```python
42         # int (целое число)
3.14       # float (вещественное число)
"Hello"    # str (строка)
True       # bool (логический)
```
### Функция type()
```python
Показывает тип объекта:
print(type(42))       # <class 'int'>
print(type("Hi"))     # <class 'str'>
print(type(True))     # <class 'bool'>
```
### Функция id()
```python
Каждый объект имеет уникальный адрес в памяти:
x = 10
print(id(x)) # Может быть: 4354860768
```
### Переменные
```python
Переменная — это имя, которое хранит ссылку на объект.
a = 5
name = "Python"
```
**Правила имен переменных**
* Можно использовать: буквы, цифры, _
* Нельзя начинать с цифры
* Нельзя использовать пробелы и спецсимволы
* Регистрозависимы: Age ≠ age

### Выражения и операторы
| **Тип операторов** | **Пример** |
|:-:|:-:|
| Арифметические | + - * / // % ** |
| Сравнения | == != > < >= <= |
| Логические | and or not |
Пример:
```
x = 2 + 3 * 4
```

### Вывод: print()
```
print("Привет, Python!")
print("Сумма:", 2 + 3)
```

### Ввод данных: input()
```
name = input("Как тебя зовут? ")
print("Привет,", name)
```
**⚠️ Важно: input() всегда возвращает строку!**
