# Проверочная работа по итогу пройденного материала по Python

## Первое задание<!-- {"fold":true} -->
Создайте переменные name, age, classroom, заполните их своими данными и выведите их в консоль строкой «Я name, мне age лет и я учусь в classroom классе». 
**За задание дается 1 балл**

## Второе задание
Напишите программу, которая проверяет введенный возраст через клавиатуру с надписью «Введите ваш возраст: »:
1. Если возраст больше 14 - вывести «У вас есть паспорт»
2. Если больше 18 - вывести «Вы совершеннолетний»
3. В любом другом случае - вывести «Вы слишком юн»

⠀**За задание дается 2 балла**

## Третье задание
Создать массив `fruits` с `apple`, `orange`, `banan`, `table`. Удалить последний элемент, так как он не является фруктом и заменить первый элемент на `peach`.
**За задание дается 1 балл**

## Четвертое задание
Напишите программу, которая идет до диапазона `end_number`, начиная со `start_number` и в этом диапазоне выводит все числа, которые делятся на 3 целочисленно. Если число `end_number` больше 237, то заканчивается на 237.
**За задание дается 2 балла**

## Пятое задание
Задание: **Умный интерактивный калькулятор с расширенной функциональностью**
Создайте функцию `smart_calculator()`, которая реализует интерактивный калькулятор с расширенными возможностями и полной обработкой ошибок.
Основные требования:
1. **Функция должна работать в интерактивном режиме** до явного указания пользователя выйти.
2. **Поддерживаемые операции:**
   * Сложение (+)
   * Вычитание (-)
   * Умножение (*)
   * Деление (/)
   * Возведение в степень (^)
   * Целочисленное деление (//)
   * Факториал (!) - для одного числа
3. **Строгие требования:**
   * Числа должны быть целыми (но с обработкой исключений если введены не целые)
   * Для каждой операции свой формат запроса
   * При некорректном вводе - повторный запрос
   * Если введен неподдерживаемый знак операции - повторный запрос
   * **Деление на ноль** - обрабатывать через try/except ZeroDivisionError
   * **Факториал отрицательного числа** - вызывать ValueError через raise
   * try/except - для обработки ошибок ввода и вычислений
   * else - выводить результат только если нет ошибок
   * finally - выводить разделитель после каждой операции
   * raise - для вызова собственных исключений

⠀
За каждый пункт задания можно получить 2 балла, за пункт с бесконечным вводом +2 балла, полностью выполненное задание можно получить 20 баллов.
