# Урок 11. Классы и основы ООП

> **Темы урока:** `class`, `__init__`, `self`, атрибуты и методы, базовое наследование.

---

## 1. Зачем нужно ООП

До сих пор мы использовали простые типы: числа, строки, списки, словари. Но часто удобнее описать целый **объект** реального мира — машину, пользователя, счёт в банке — со своими данными и действиями.

**ООП** (объектно-ориентированное программирование) позволяет:

- объединять данные и функции, которые с ними работают, в одном месте;
- создавать много похожих объектов по одному «шаблону»;
- описывать общее поведение и переопределять его для частных случаев.

Два ключевых понятия:

- **Класс** — шаблон, описание того, какими данными и действиями обладают объекты.
- **Объект** (экземпляр) — конкретный представитель класса, созданный по этому шаблону.

Аналогия: класс — это чертёж автомобиля, а объект — конкретная машина, собранная по чертежу.

## 2. Определение класса — `class`

```python
class Dog:
    pass          # pass — заглушка «пока пусто»
```

Так объявляется класс. Теперь создадим объект:

```python
rex = Dog()       # создаём экземпляр класса Dog
print(type(rex))  # <class '__main__.Dog'>
```

---

## 3. Конструктор `__init__`

`__init__` — специальный метод, который вызывается **автоматически при создании объекта**. В нём обычно задают начальные данные (атрибуты).

```python
class Dog:
    def __init__(self, name, age):
        self.name = name
        self.age = age

rex = Dog("Рекс", 3)
print(rex.name)   # Рекс
print(rex.age)    # 3
```

`__init__` называют **конструктором** (метод инициализации).

---

## 4. Что такое `self`

`self` — это ссылка на **текущий объект**, для которого вызван метод. Через `self.атрибут` мы обращаемся к данным конкретного экземпляра.

```python
class Dog:
    def __init__(self, name):
        self.name = name

    def bark(self):
        print(f"{self.name} говорит: Гав!")

rex = Dog("Рекс")
lucky = Dog("Лаки")

rex.bark()     # Рекс говорит: Гав!
lucky.bark()   # Лаки говорит: Гав!
```

Правила:

- `self` — это **первый параметр каждого метода** (имя `self` — соглашение, но менять его не стоит).
- При вызове `rex.bark()` Python сам подставляет `rex` на место `self`.
- Без `self` метод не знал бы, к какому объекту обращаться.

## 5. Атрибуты

**Атрибуты** — это переменные, принадлежащие объекту. Они задаются в `__init__` и хранят состояние объекта.

```python
class Dog:
    def __init__(self, name, age):
        self.name = name
        self.age = age

    def have_birthday(self):
        self.age += 1            # изменяем атрибут объекта
        print(f"{self.name} теперь {self.age} лет")

rex = Dog("Рекс", 3)
rex.have_birthday()   # Рекс теперь 4 лет
rex.have_birthday()   # Рекс теперь 5 лет
```

### Атрибуты класса (общие для всех объектов)

Атрибут, объявленный в теле класса (не в `__init__`), — общий для всех экземпляров:

```python
class Dog:
    species = "собака"           # атрибут класса

    def __init__(self, name):
        self.name = name

rex = Dog("Рекс")
lucky = Dog("Лаки")

print(rex.species)    # собака
print(lucky.species)  # собака
```

## 6. Методы

**Метод** — это функция, объявленная внутри класса и работающая с объектом через `self`.

```python
class Rectangle:
    def __init__(self, width, height):
        self.width = width
        self.height = height

    def area(self):
        return self.width * self.height

    def perimeter(self):
        return 2 * (self.width + self.height)

rect = Rectangle(5, 3)
print(rect.area())       # 15
print(rect.perimeter())  # 16
```

### Метод `__str__` — красивый вывод объекта

Без него `print(объект)` показывает нечитаемое служебное представление:

```python
class Dog:
    def __init__(self, name, age):
        self.name = name
        self.age = age

    def __str__(self):
        return f"Собака {self.name}, {self.age} лет"

rex = Dog("Рекс", 3)
print(rex)   # Собака Рекс, 3 лет
```

## 7. Наследование

**Наследование** позволяет создать класс на основе другого, унаследовав его атрибуты и методы, и при необходимости изменить или дополнить их.

- **Родительский (базовый) класс** — тот, от которого наследуются.
- **Дочерний класс** — тот, который наследует.

```python
class Animal:                          # родительский класс
    def __init__(self, name):
        self.name = name

    def speak(self):
        return "Какой-то звук"


class Dog(Animal):                     # дочерний класс
    def speak(self):                   # переопределяем метод
        return f"{self.name}: Гав!"


class Cat(Animal):
    def speak(self):
        return f"{self.name}: Мяу!"


rex = Dog("Рекс")
barsik = Cat("Барсик")

print(rex.speak())     # Рекс: Гав!
print(barsik.speak())  # Барсик: Мяу!
```

Дочерний класс `Dog(Animal)` автоматически получает всё из `Animal`, но переопределяет `speak` — это называется **переопределением метода** (method overriding).

### `super()` — вызвать метод родителя

Если дочерний класс расширяет родительский `__init__`, используют `super().__init__(...)`:

```python
class Animal:
    def __init__(self, name):
        self.name = name


class Dog(Animal):
    def __init__(self, name, breed):
        super().__init__(name)         # вызываем __init__ родителя
        self.breed = breed

    def info(self):
        return f"{self.name} ({self.breed})"


rex = Dog("Рекс", "овчарка")
print(rex.info())   # Рекс (овчарка)
```

Проверить, является ли объект экземпляром класса, можно через `isinstance`:

```python
print(isinstance(rex, Dog))      # True
print(isinstance(rex, Animal))   # True — Dog наследует Animal
```

## 8. Инкапсуляция (кратко)

В Python по соглашению атрибуты, которые не стоит трогать снаружи, называют с подчёркиванием:

- `self._value` — «внутренний», лучше не использовать напрямую;
- `self.__value` — «приватный», Python скрывает его имя (name mangling).

```python
class Counter:
    def __init__(self):
        self._count = 0

    def increment(self):
        self._count += 1

    def get(self):
        return self._count
```

Работать с данными рекомендуют через методы (`increment`, `get`), а не напрямую.

---

## 9. Шпаргалка

| Элемент | Назначение | Пример |
| --- | --- | --- |
| `class Name:` | объявить класс | `class Dog:` |
| `__init__(self, ...)` | конструктор, задаёт атрибуты | `def __init__(self, name):` |
| `self.attr` | атрибут объекта | `self.name = name` |
| `self.method()` | вызов метода внутри класса | `self.bark()` |
| `obj.attr` | доступ к атрибуту снаружи | `rex.name` |
| `obj.method()` | вызов метода снаружи | `rex.bark()` |
| `__str__(self)` | красивый вывод объекта | `print(rex)` |
| `class Child(Parent):` | наследование | `class Dog(Animal):` |
| `super().__init__(...)` | вызвать конструктор родителя | `super().__init__(name)` |
