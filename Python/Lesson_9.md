## 1. Что такое модуль и библиотека

**Модуль** — это файл с кодом на Python (расширение `.py`), который можно подключить к своей программе и использовать его функции и переменные.

**Библиотека** (или пакет) — это набор модулей, объединённых общей целью. Например, `math` — модуль, а большие библиотеки вроде `requests` содержат несколько модулей внутри.

Зачем это нужно:

- не писать один и тот же код заново;
- использовать проверенные готовые решения;
- разбивать большие программы на части.

## 2. Подключение модуля — `import`

```python
import math

print(math.sqrt(16))   # 4.0
print(math.pi)         # 3.141592653589793
```

После `import math` все имена модуля доступны через точку: `math.sqrt`, `math.pi`, `math.floor`.

### Несколько модулей сразу

```python
import math
import random
```

Или в одну строку через запятую (хотя отдельными строками читается лучше):

```python
import math, random
```

---

## 3. Импорт конкретных имён — `from ... import ...`

Если нужна только часть модуля, можно импортировать конкретные функции и пользоваться ими без префикса:

```python
from math import sqrt, pi

print(sqrt(25))   # 5.0
print(pi)         # 3.141592653589793
```

### Импорт всего содержимого — `from ... import *`

```python
from math import *
```

> ⚠️ Использовать `*` не рекомендуется: непонятно, какие имена появились в программе, и возможны конфликты имён.

---

## 4. Псевдонимы — `as`

Короткое имя упрощает код, особенно для модулей с длинными названиями:

```python
import datetime as dt

print(dt.datetime.now())
```

Псевдонимы можно давать и отдельным функциям:

```python
from math import sqrt as корень

print(корень(81))   # 9.0
```

## 5. Стандартные модули

Стандартная библиотека Python поставляется вместе с языком — её не нужно устанавливать отдельно.

### `math` — математика

```python
import math

print(math.sqrt(16))        # 4.0      — квадратный корень
print(math.ceil(3.1))       # 4        — округление вверх
print(math.floor(3.9))      # 3        — округление вниз
print(math.pow(2, 10))      # 1024.0   — возведение в степень
print(math.factorial(5))    # 120      — факториал
print(math.pi)              # число π
print(math.e)               # число e
```

### `random` — случайные числа

```python
import random

print(random.random())              # float от 0.0 до 1.0
print(random.randint(1, 10))        # целое от 1 до 10 включительно
print(random.uniform(1, 2))         # float от 1 до 2
print(random.choice(["a", "b", "c"]))   # случайный элемент

items = [1, 2, 3, 4, 5]
random.shuffle(items)               # перемешать список на месте
print(items)
```

### `datetime` — даты и время

```python
import datetime as dt

now = dt.datetime.now()             # текущие дата и время
print(now)
print(now.year, now.month, now.day)
print(now.hour, now.minute, now.second)

today = dt.date.today()             # только дата
print(today)

delta = dt.timedelta(days=7)        # промежуток времени
print(today + delta)                # дата через неделю
```

### `os` — работа с операционной системой

```python
import os

print(os.getcwd())                  # текущая рабочая папка
print(os.listdir("."))              # содержимое папки

path = os.path.join("data", "file.txt")   # корректный путь на любой ОС
print(path)                         # data/file.txt (или data\file.txt на Windows)

print(os.path.exists("file.txt"))   # True/False — есть ли файл

os.mkdir("new_folder")              # создать папку
```

> Модуль `os` помогает писать переносимый код: `os.path.join` сам подставит нужный разделитель (`/` или `\`).

## 6. Установка сторонних пакетов

Не всё есть в стандартной библиотеке. Сторонние пакеты устанавливаются через менеджер пакетов **pip**.

```bash
pip install requests
```

Примеры популярных пакетов:

| Пакет | Для чего |
| --- | --- |
| `requests` | HTTP-запросы, работа с сайтами и API |
| `pandas` | анализ табличных данных |
| `matplotlib` | построение графиков |
| `flask` | веб-приложения |
| `pillow` | работа с изображениями |

### Полезные команды pip

```bash
pip install requests         # установить пакет
pip install requests==2.31.0 # установить конкретную версию
pip uninstall requests       # удалить пакет
pip list                     # показать установленные пакеты
pip show requests            # информация о пакете
```

### Файл зависимостей requirements.txt

Чтобы перенести проект на другой компьютер, список зависимостей сохраняют в файл:

```bash
pip freeze > requirements.txt     # сохранить список
pip install -r requirements.txt   # установить всё из списка
```

После установки пакет используется так же, как любой модуль:

```python
import requests

response = requests.get("https://example.com")
print(response.status_code)   # 200
```

## 7. Создание собственного модуля

Модулем может быть обычный `.py`-файл. Создадим файл `my_math.py`:

```python
# my_math.py
def add(a, b):
    return a + b

def double(x):
    return x * 2

PI = 3.14159
```

Теперь в другой программе (в той же папке) его можно импортировать:

```python
import my_math

print(my_math.add(2, 3))     # 5
print(my_math.double(10))    # 20
print(my_math.PI)            # 3.14159
```

## 8. Шпаргалка

| Действие | Код |
| --- | --- |
| Подключить модуль | `import math` |
| Импортировать конкретные имена | `from math import sqrt, pi` |
| Импортировать всё | `from math import *` (не рекомендуется) |
| Дать псевдоним модулю | `import datetime as dt` |
| Дать псевдоним функции | `from math import sqrt as s` |
| Квадратный корень | `math.sqrt(x)` |
| Случайное целое | `random.randint(a, b)` |
| Случайный элемент | `random.choice(seq)` |
| Текущее время | `datetime.datetime.now()` |
| Создать папку | `os.mkdir(name)` |
| Установить пакет | `pip install package` |
