## 1. Функциональный стиль в Python

Python поддерживает не только циклы и явные функции, но и **функциональный стиль**: короткие анонимные функции и функции, которые применяются ко всей последовательности сразу. Это делает код лаконичным и читаемым.

Главные инструменты:

- `lambda` — функция без имени, записанная в одну строку;
- `map` — применить функцию к каждому элементу;
- `filter` — оставить только подходящие элементы;
- `sorted` — отсортировать с гибким правилом через `key`.

---

## 2. Анонимные функции — `lambda`

`lambda` — это компактная функция в одну строку. Она может принимать несколько аргументов и возвращает одно выражение.

```python
# Обычная функция
def double(x):
    return x * 2

# То же самое через lambda
double = lambda x: x * 2

print(double(5))   # 10
```

Синтаксис:

```text
lambda аргументы: выражение
```

Примеры:

```python
add = lambda a, b: a + b
print(add(3, 4))            # 7

is_even = lambda n: n % 2 == 0
print(is_even(10))          # True

upper = lambda s: s.upper()
print(upper("python"))      # PYTHON
```

> Ограничение: внутри `lambda` нельзя писать несколько строк или присваивания — только **одно выражение**. Для сложной логики используйте обычную `def`.

---

## 3. `map` — применить функцию ко всем элементам

`map(func, iterable)` применяет функцию к каждому элементу и возвращает **итератор**. Чтобы увидеть результат, его обычно превращают в список через `list()`.

```python
numbers = [1, 2, 3, 4, 5]

squared = map(lambda x: x ** 2, numbers)
print(list(squared))        # [1, 4, 9, 16, 25]
```

Можно передавать обычную функцию и несколько последовательностей:

```python
def multiply(a, b):
    return a * b

print(list(map(multiply, [1, 2, 3], [10, 20, 30])))   # [10, 40, 90]
```

`map` — ленивый: элементы вычисляются по мере запроса.

```python
m = map(lambda x: x * 2, range(5))
print(next(m))   # 0
print(next(m))   # 2
```

## 4. `filter` — оставить подходящие элементы

`filter(func, iterable)` оставляет только те элементы, для которых функция вернула истинное значение.

```python
numbers = [1, 2, 3, 4, 5, 6]

evens = filter(lambda x: x % 2 == 0, numbers)
print(list(evens))          # [2, 4, 6]
```

Пример с текстом:

```python
words = ["apple", "banana", "kiwi", "pear"]

long = filter(lambda w: len(w) > 4, words)
print(list(long))           # ['apple', 'banana']
```

> Если вместо функции передать `None`, `filter` оставит только истинные элементы:

```python
print(list(filter(None, [0, 1, "", "x", None])))   # [1, 'x']
```

## 5. `zip` — соединить последовательности попарно

`zip` берёт элементы из нескольких последовательностей и собирает их в кортежи. Останавливается на **самой короткой**.

```python
names = ["Анна", "Борис", "Виктор"]
ages  = [25, 30, 35]

print(list(zip(names, ages)))
# [('Анна', 25), ('Борис', 30), ('Виктор', 35)]
```

```python
print(list(zip([1, 2, 3], ["a", "b"])))   # [(1, 'a'), (2, 'b')]
```

`zip` ленивый и возвращает итератор.

## 6. `enumerate` — добавить порядковый номер

```python
fruits = ["яблоко", "груша", "слива"]

for index, fruit in enumerate(fruits, start=1):
    print(index, fruit)
# 1 яблоко
# 2 груша
# 3 слива
```

## 7. Генераторы и `yield`

Функция с `yield` возвращает генератор — объект, который выдаёт значения по одному и «замирает» между вызовами.

```python
def countdown(n):
    while n > 0:
        yield n
        n -= 1

gen = countdown(3)
print(next(gen))   # 3
print(next(gen))   # 2
print(next(gen))   # 1
```

Генераторное выражение — «ленивый» аналог спискового включения:

```python
squares = (x * x for x in range(5))   # круглые скобки — генератор
print(next(squares))                  # 0
print(list(squares))                  # [1, 4, 9, 16]
```

> Генератор одноразовый: после исчерпания пройти по нему заново нельзя.

## 8. `any` и `all`

- `any(iterable)` — `True`, если **хотя бы один** элемент истинный.
- `all(iterable)` — `True`, если **все** элементы истинные.

```python
print(any([0, "", None, 5]))   # True
print(any([0, "", None]))      # False

print(all([1, "x", [1, 2]]))   # True
print(all([1, 0, 5]))          # False
```

Краевые случаи:

```python
print(any([]))   # False
print(all([]))   # True
```

Обе функции ленивые — прекращают проверку, как только ответ становится известен. Часто используются вместе с генераторными выражениями:

```python
numbers = [2, 4, 6, 8]
print(all(n % 2 == 0 for n in numbers))   # True — все чётные
```

## 9. `sorted` и ключ сортировки `key`

`sorted(iterable, key=..., reverse=...)` возвращает **новый** отсортированный список (в отличие от `list.sort()`, который сортирует на месте).

```python
print(sorted([3, 1, 2]))                 # [1, 2, 3]
print(sorted([3, 1, 2], reverse=True))   # [3, 2, 1]
```

### Сортировка по правилу — `key`

Параметр `key` задаёт функцию, по значению которой выполняется сортировка:

```python
words = ["banana", "apple", "kiwi", "pear"]

by_length = sorted(words, key=lambda w: len(w))
print(by_length)   # ['kiwi', 'pear', 'apple', 'banana']
```

Сортировка по убыванию длины:

```python
print(sorted(words, key=len, reverse=True))   # ['banana', 'apple', 'pear', 'kiwi']
```

### Сортировка списка кортежей

```python
students = [("Анна", 90), ("Борис", 75), ("Виктор", 85)]

by_score = sorted(students, key=lambda s: s[1], reverse=True)
print(by_score)
# [('Анна', 90), ('Виктор', 85), ('Борис', 75)]
```

### Сортировка списка словарей

```python
people = [
    {"name": "Анна", "age": 30},
    {"name": "Борис", "age": 25},
    {"name": "Виктор", "age": 35},
]

by_age = sorted(people, key=lambda p: p["age"])
print(by_age)
# [{'name': 'Борис', 'age': 25}, {'name': 'Анна', 'age': 30}, {'name': 'Виктор', 'age': 35}]
```

## 10. Собираем всё вместе

Обработаем список «в одну строку»: оставить только числа, возвести в квадрат и отсортировать.

```python
data = [5, -2, 3, 8, 1, -7]

result = sorted(
    map(lambda x: x ** 2, filter(lambda x: x > 0, data))
)
print(result)   # [1, 9, 25, 64]
```

Читается справа налево: `filter` оставляет положительные → `map` возводит в квадрат → `sorted` сортирует.

## 11. Шпаргалка

| Инструмент | Что делает | Возвращает |
| --- | --- | --- |
| `lambda x: expr` | анонимная функция | значение выражения |
| `map(f, seq)` | применить `f` к каждому элементу | итератор |
| `filter(f, seq)` | оставить элементы, где `f` истинна | итератор |
| `zip(a, b)` | соединить попарно | итератор кортежей |
| `enumerate(seq)` | пары (номер, элемент) | итератор |
| `yield` | приостановить генератор | — |
| `any(seq)` | хотя бы один истинный | `bool` |
| `all(seq)` | все истинные | `bool` |
| `sorted(seq, key=f)` | отсортировать по правилу | список |
