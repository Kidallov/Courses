# Урок 9. Работа с файлами в Python.

## Введение<!-- {"fold":true} -->

Работа с файлами — одна из фундаментальных задач в программировании. Python предоставляет удобные и мощные инструменты для чтения и записи файлов различных форматов. Сегодня мы изучим, как безопасно и эффективно работать с файловой системой.

## 1. Функция `open()`<!-- {"fold":true} -->

Функция `open()` используется для открытия файла и возвращает файловый объект.

### Синтаксис:
```python
file_object = open(file_path, mode='r')
```

### Параметры:
- **file_path** — путь к файлу (относительный или абсолютный)
- **mode** — режим открытия файла (по умолчанию 'r' — чтение)

---

## 2. Режимы открытия файлов<!-- {"fold":true} -->

| Режим                      | Описание                                                    |
|----------------------------|-------------------------------------------------------------|
| `'r'` - read               | Чтение (только чтение, файл должен существовать)            |
| `'w'` - write              | Запись (создаёт новый файл или перезаписывает существующий) |
| `'a'` - add                | Добавление (добавляет данные в конец файла)                 |
| `'x'` - exclusive creation | Эксклюзивное создание (создаёт файл, если он не существует) |
| `'r+'` - read+             | Чтение и запись (курсор в начале файла)                     |
| `'w+'` - write+            | Чтение и запись (создаёт или перезаписывает файл)           |
| `'a+'` - add+              | Чтение и добавление (курсор в конце файла для записи)       |

### Дополнительные модификаторы:
- `'b'` — бинарный режим (например, `'rb'`, `'wb'`)
- `'t'` — текстовый режим (по умолчанию)

**Бинарный режим** — это способ чтения или записи файлов в программировании, при котором данные передаются «как есть», байт в байт, без интерпретации или преобразования символов.

## 3. Методы чтения файлов<!-- {"fold":true} -->

### Метод `read()` — чтение всего файла<!-- {"fold":true} -->
```python
# Открываем файл для чтения
file = open('example.txt', 'r')
content = file.read()  # Читаем весь файл
print(content)
file.close()  # Важно закрыть файл!
```

### Метод `readline()` — чтение одной строки<!-- {"fold":true} -->
```python
file = open('example.txt', 'r')
line1 = file.readline()  # Читаем первую строку
line2 = file.readline()  # Читаем вторую строку
print(f"Первая строка: {line1}")
print(f"Вторая строка: {line2}")
file.close()
```

### Метод `readlines()` — чтение всех строк в список<!-- {"fold":true} -->
```python
file = open('example.txt', 'r')
lines = file.readlines()  # Возвращает список строк
print(f"Всего строк: {len(lines)}")
for line in lines:
    print(line.strip())  # strip() удаляет символы перевода строки
file.close()
```

---

## 4. Методы записи в файлы<!-- {"fold":true} -->

### Метод `write()` — запись строки<!-- {"fold":true} -->
```python
# Открываем файл для записи (существующий файл будет перезаписан!)
file = open('output.txt', 'w')
file.write("Первая строка\n")
file.write("Вторая строка\n")
file.close()
```

### Метод `writelines()` — запись списка строк<!-- {"fold":true} -->
```python
lines = ["Строка 1\n", "Строка 2\n", "Строка 3\n"]
file = open('output.txt', 'w')
file.writelines(lines)  # Записываем все строки из списка
file.close()
```

## 5. Контекстный менеджер `with`<!-- {"fold":true} -->

**Важная особенность Python!** Контекстный менеджер автоматически закрывает файл, даже если произошла ошибка.

### Синтаксис:
```python
with open(file_path, mode) as file:
    # Работа с файлом
    data = file.read()
# Файл автоматически закрывается здесь
```

### Примеры:
```python
# Чтение с использованием with
with open('example.txt', 'r') as file:
    content = file.read()
    print(content)
# Файл уже закрыт, обращаться к file нельзя

# Запись с использованием with
with open('example.txt', 'w', encoding='utf-8') as file:
    file.write("Новые данные")
```

**Преимущества `with`:**
- Автоматическое закрытие файла
- Безопасность при исключениях
- Более чистый и читаемый код

## 6. Построчная обработка файлов<!-- {"fold":true} -->

### Эффективное чтение больших файлов
Для больших файлов не следует использовать `read()` или `readlines()`, так как они загружают весь файл в память.

### Вариант 1: Итерация по файловому объекту<!-- {"fold":true} -->
```python
with open('large_file.txt', 'r') as file:
    for line in file:  # Читаем файл построчно
        # Обработка каждой строки
        processed_line = line.strip().upper()
        print(processed_line)
```

### Вариант 2: Обработка с фильтрацией<!-- {"fold":true} -->
```python
# Чтение только строк, содержащих определённое слово
keywords = ['Python', 'программирование', 'файлы']
with open('article.txt', 'r') as file:
    for line_number, line in enumerate(file, 1):
        if any(keyword in line for keyword in keywords):
            print(f"Строка {line_number}: {line.strip()}")
```

### Вариант 3: Построчная обработка с записью результата<!-- {"fold":true} -->
```python
# Чтение из одного файла, обработка и запись в другой
with open('input.txt', 'r') as input_file, \
     open('output.txt', 'w') as output_file:
    
    for line in input_file:
        # Удаляем пробелы в начале и конце и делаем заглавными все буквы
        processed_line = line.strip().upper()
        # Добавляем номер строки
        output_file.write(f"{processed_line}\n")
```

## 7. Нюансы и важные моменты<!-- {"fold":true} -->

### 1. Различные способы указания путей<!-- {"fold":true} -->
```python
# Абсолютный путь (полный путь к файлу)
path1 = "C:/Users/User/Documents/file.txt"  # Для Windows
path2 = "/home/user/documents/file.txt"     # Для Linux/Mac

# Относительный путь (относительно текущей директории)
path3 = "data/file.txt"      # Файл в папке data
path4 = "../other/file.txt"  # Файл на уровень выше
```

### 2. Обработка исключений<!-- {"fold":true} -->
```python
try:
    with open('nonexistent.txt', 'r') as file:
        content = file.read()
except FileNotFoundError:
    print("Файл не найден!")
except PermissionError:
    print("Нет прав доступа к файлу!")
except UnicodeDecodeError:
    print("Ошибка декодирования! Проверьте кодировку.")
```

### 3. Использование `strip()`, `rstrip()`, `lstrip()`<!-- {"fold":true} -->
```python
with open('file.txt', 'r', encoding='utf-8') as file:
    for line in file:
        clean_line = line.strip() # Удаляет пробелы и \n с обоих концов
        right_clean = line.rstrip() # Удаляет только справа
        left_clean = line.lstrip()  # Удаляет только слева
```

## 8. Практические задания на уроке<!-- {"fold":true} -->

### Задание 1: Анализ текстового файла
Создайте файл `text.txt` с несколькими строками текста. Напишите программу, которая:
1. Подсчитывает общее количество строк
2. Подсчитывает общее количество слов
3. Находит самую длинную строку
4. Записывает результаты в файл `analysis.txt`

###### Решение<!-- {"fold":true} -->
```python
# Пример решения
with open('text.txt', 'r') as file:
    lines = file.readlines()

total_lines = len(lines)
total_words = sum(len(line.split()) for line in lines)
longest_line = max(lines, key=len)

with open('analysis.txt', 'w') as output:
    output.write(f"Всего строк: {total_lines}\n")
    output.write(f"Всего слов: {total_words}\n")
    output.write(f"Самая длинная строка: {longest_line.strip()}\n")
```
