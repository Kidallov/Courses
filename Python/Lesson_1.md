## 🧠 Создание переменной

Формат:  
`Название переменной (должно быть понятным) = значение`

> 💡 **Важно:** знак `=` — это оператор присваивания.

**Пример:**
```python
a = 1
```

---

## 🔢 Типы переменных в Python

| Тип | Описание | Примеры |
| --- | --- | --- |
| `int` | Целочисленный тип данных | `1`, `100`, `1234` |
| `float` | Дробное число | `2.4`, `6.789`, `9.054` |
| `bool` | Булевский тип (логическое значение) | `True` / `False` (Истина / Ложь) |
| `str` | Строковый тип | `'Hello'`, `'Привет'` |

### Функция `type()`
Позволяет узнать тип переменной.

Пример:
```python
x = 5
print(type(x))  # <class 'int'>
```

## 🚀 Самые нужные функции

### `print()` — вывод данных на экран

**Пример:**
```python
a = 1
print(a)
# Вывод: 1
```

### `input()` — ввод данных с клавиатуры

- Всегда возвращает значение типа `str`.
- Чтобы получить число, нужно преобразовать ввод: `int(input())`.

**Примеры:**

1. Простой ввод:
   ```python
   a = input('Введите число: ')
   print(a)
   # Вывод в консоли:
   # Введите число: 2
   # 2
   ```

2. Ввод числа:
   ```python
   num = int(input('Введите целое число: '))
   print(num + 10)
   ```

## 🧩 Логические конструкции и условия

### Операторы сравнения

| Оператор | Значение |
| --- | --- |
| `<` | Меньше |
| `>` | Больше |
| `<=` | Меньше или равно |
| `>=` | Больше или равно |
| `==` | Равно (проверка на равенство) |
| `!=` | Не равно |
| `=` | Присваивание (используется при создании переменной) |

> ⚠️ **Важно:** не путайте `=` (присваивание) и `==` (сравнение).

### Пример построения условия

```python
if (какое-то выражение):
    # выполняется тело условия, если выражение истинно
    pass
elif (какое-то другое выражение):
    # выполняется, если первое условие ложно, а это — истинно
    pass
else:
    # выполняется, если ни одно из предыдущих условий не выполнилось
    pass
```

**Пояснения:**
- `if` — обязательный блок.
- `elif` — необязательный, можно использовать несколько раз.
- `else` — необязательный, используется один раз в конце.

## 🔗 Логические операторы

| Оператор | Описание |
| --- | --- |
| `and` | «И» — условие истинно, только если **все** части истинны |
| `or` | «ИЛИ» — условие истинно, если **хотя бы одна** часть истинна |

**Пример с `and`:**
```python
age = 20
is_student = True

if age >= 18 and is_student:
    print("Доступ разрешён")
```

**Пример с `or`:**
```python
day = "суббота"

if day == "суббота" or day == "воскресенье":
    print("Выходной!")
```
