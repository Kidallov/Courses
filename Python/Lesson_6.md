# Урок 7. Обработка ошибок в Python

**Тема: try, except, else, finally, типы исключений, защита кода от сбоев.**

## 1. Что такое обработка ошибок

При выполнении программы могут возникать ошибки. Например:

* Пользователь ввёл текст вместо числа.
* Программа попыталась разделить число на ноль.
* Код обратился к несуществующему файлу.
* Программа попыталась получить элемент, которого нет в списке.
* Код обратился к переменной, которая не была определена.

Если ошибка не обработана, программа может аварийно завершиться.

Обработка ошибок — это механизм, который позволяет программе предвидеть возможные проблемы, корректно реагировать на них и продолжать работу там, где это возможно.

Рассмотрим пример без обработки ошибок:
```python
number = int(input("Введите число: "))
print(f"Вы ввели число: {number}")
```
Если пользователь введёт hello, программа завершится с ошибкой ValueError.

Теперь обработаем возможную ошибку:
```python
try:
    number = int(input("Введите число: "))
    print(f"Вы ввели число: {number}")
except ValueError:
    print("Ошибка: необходимо ввести целое число.")
```
Теперь программа не завершится аварийно из-за неправильного ввода. Вместо этого пользователь увидит понятное сообщение.

## 2. Конструкция try и except

Для обработки исключений в Python используются блоки try и except.

* try — содержит код, при выполнении которого может возникнуть ошибка.
* except — определяет, что делать, если возникло исключение указанного типа.

Общий синтаксис:
```python
try:
    # Код, в котором может возникнуть ошибка
    ...
except ТипОшибки:
    # Действия при возникновении ошибки
    ...
```

**Пример 1. Деление чисел**
```python
try:
    first_number = int(input("Введите первое число: "))
    second_number = int(input("Введите второе число: "))
    result = first_number / second_number
    print(f"Результат: {result}")
except ValueError:
    print("Ошибка: необходимо вводить целые числа.")
except ZeroDivisionError:
    print("Ошибка: делить на ноль нельзя.")
```

Здесь предусмотрены две возможные ошибки:

1. ValueError — пользователь ввёл значение, которое нельзя преобразовать в целое число.
2. ZeroDivisionError — пользователь попытался разделить число на ноль.

Если пользователь введёт 10 и 2, программа выведет:
```text
Результат: 5.0
```
Если пользователь введёт abc, появится сообщение:
```text
Ошибка: необходимо вводить целые числа.
```
Если пользователь введёт 10 и 0, появится сообщение:
```text
Ошибка: делить на ноль нельзя.
```

**Пример 2. Обработка нескольких типов ошибок**

Можно использовать несколько блоков except, чтобы по-разному реагировать на разные исключения.
```python
try:
    numbers = [10, 20, 30]
    index = int(input("Введите индекс элемента: "))
    print(numbers[index])
except ValueError:
    print("Ошибка: индекс должен быть целым числом.")
except IndexError:
    print("Ошибка: элемента с таким индексом нет.")
```
Если ввести abc, возникнет ValueError.

Если ввести 10, возникнет IndexError, поскольку в списке всего три элемента с индексами 0, 1 и 2.

Важно: блок except обрабатывает только те исключения, которые соответствуют указанному типу. Если возникнет другая ошибка, она не будет обработана этими блоками.

## 3. Основные типы исключений в Python

В Python существует множество встроенных исключений. Рассмотрим наиболее распространённые.

Исключение	Когда возникает	Пример
ValueError	Значение имеет неподходящий формат	int("hello")
TypeError	Операция применяется к неподходящему типу данных	"5" + 10
ZeroDivisionError	Деление на ноль	10 / 0
IndexError	Индекс отсутствует в списке или кортеже	[1, 2][5]
KeyError	В словаре отсутствует указанный ключ	{"name": "Анна"}["age"]
NameError	Используется имя, которое не определено	print(username)
FileNotFoundError	Не найден указанный файл	open("missing.txt")
AttributeError	У объекта нет указанного атрибута или метода	"text".append("!")
ImportError	Не удалось импортировать модуль или объект	Ошибка импорта
OverflowError	Результат вычисления выходит за допустимый диапазон для соответствующей операции	Некоторые операции с числами с плавающей точкой

Пример ValueError
```python
try:
    age = int("двадцать")
except ValueError:
    print("Возраст необходимо указать числом.")
```

Пример TypeError
```python
try:
    result = "Возраст: " + 20
except TypeError:
    print("Нельзя напрямую складывать строку и число.")
```

Правильный вариант:
```python
age = 20
result = "Возраст: " + str(age)
print(result)
```
Либо с использованием f-строки:
```python
age = 20
print(f"Возраст: {age}")
```

Пример KeyError
```python
user = {
    "name": "Анна",
    "age": 25
}
try:
    print(user["email"])
except KeyError:
    print("Поле email отсутствует.")
```

Пример FileNotFoundError
```python
try:
    with open("data.txt", "r", encoding="utf-8") as file:
        content = file.read()
    print(content)
except FileNotFoundError:
    print("Файл не найден.")
```
Если файла data.txt нет, программа выведет сообщение вместо необработанного исключения.

Важно: не нужно запоминать все исключения сразу. Гораздо полезнее понимать причину возникновения ошибки и уметь найти подходящий тип исключения.

## 4. Как работает несколько блоков except

Для одной конструкции try можно указать несколько обработчиков except.

Python проверяет их по порядку и выполняет первый подходящий обработчик.
```python
try:
    number = int(input("Введите число: "))
    result = 100 / number
    print(result)
except ValueError:
    print("Введено не число.")
except ZeroDivisionError:
    print("Делить на ноль нельзя.")
```
Обратите внимание: после выполнения подходящего блока except остальные обработчики этой конструкции не выполняются.

Можно ли использовать except без указания типа?

Технически можно:
```python
try:
    number = int(input("Введите число: "))
    result = 100 / number
except:
    print("Произошла ошибка.")
```
Однако такой подход не рекомендуется.

Пустой except перехватывает практически все исключения, в том числе те, которые не следует скрывать. В результате становится сложнее понять причину сбоя.

Лучше указывать конкретные типы:
```python
try:
    number = int(input("Введите число: "))
    result = 100 / number
except ValueError:
    print("Введите целое число.")
except ZeroDivisionError:
    print("Число не должно быть равно нулю.")
```
Когда допустимо перехватывать Exception?

Все стандартные исключения, которые обычно нужно обрабатывать, наследуются от базового класса Exception.

Поэтому можно написать:
```python
try:
    result = 10 / 0
except Exception as error:
    print(f"Произошла ошибка: {error}")
```
Конструкция except Exception перехватит большинство обычных исключений, но не все возможные исключения Python.

Такой обработчик может быть полезен на границе приложения, например для регистрации непредвиденной ошибки. Однако в обычном коде предпочтительнее обрабатывать конкретные ожидаемые исключения.

Не следует использовать except Exception только для того, чтобы программа не показывала ошибок. Важно понимать, какие ситуации обрабатываются и что программа должна делать дальше.

## 5. Получение информации об ошибке через as

После except можно использовать as, чтобы сохранить объект исключения в переменную.

Это позволяет получить текст ошибки.
```python
try:
    number = int("hello")
except ValueError as error:
    print("Не удалось преобразовать значение.")
    print(f"Подробности: {error}")
```
Примерный результат:
```python
Не удалось преобразовать значение.
Подробности: invalid literal for int() with base 10: 'hello'
```
Переменная error содержит информацию о возникшем исключении.
Это особенно полезно при отладке программы.

Пример с делением
```python
try:
    first_number = int(input("Введите первое число: "))
    second_number = int(input("Введите второе число: "))
    result = first_number / second_number
except (ValueError, ZeroDivisionError) as error:
    print(f"Ошибка: {error}")
else:
    print(f"Результат: {result}")
```
Здесь используется ещё одна возможность Python: несколько типов исключений можно объединить в один обработчик, указав их в кортеже.

## 6. Блок else

Блок else выполняется только в том случае, если код внутри try завершился без исключений.

Общий синтаксис:
```python
try:
    # Код, который может вызвать исключение
    ...
except ValueError:
    # Выполняется при ValueError
    ...
else:
    # Выполняется, если исключения не было
    ...
```

Пример
```python
try:
    number = int(input("Введите число: "))
except ValueError:
    print("Необходимо ввести целое число.")
else:
    print(f"Квадрат числа: {number ** 2}")
```
Если пользователь введёт 5, программа выведет: `Квадрат числа: 25`

Если пользователь введёт hello, программа выведет: `Необходимо ввести целое число.`

В этом случае блок else не выполнится.

Зачем нужен else?

Предположим, что у нас есть код:
```python
try:
    number = int(input("Введите число: "))
    result = number ** 2
    print(f"Результат: {result}")
except ValueError:
    print("Некорректный ввод.")
```
Он работает, но блок try содержит не только потенциально опасную операцию преобразования, но и вычисления с выводом результата.

Лучше отделить потенциально ошибочную операцию от дальнейшей логики:
```python
try:
    number = int(input("Введите число: "))
except ValueError:
    print("Некорректный ввод.")
else:
    result = number ** 2
    print(f"Результат: {result}")
```
Теперь блок try содержит только операцию, которая может вызвать ожидаемую ошибку преобразования.

Правило: размещайте в try минимальный участок кода, для которого действительно предусмотрена обработка исключений.

При этом else не защищает от ошибок внутри самого себя. Если в нём возникнет исключение, оно не будет обработано предшествующим except этой же конструкции.

## 7. Блок finally

Блок finally выполняется практически всегда: независимо от того, возникло исключение или нет.

Он нужен для действий, которые должны выполняться после попытки выполнить код.

Общий синтаксис:
```pyton
try:
    # Основной код
    ...
except ValueError:
    # Обработка ошибки
    ...
finally:
    # Завершающие действия
    ...
```

Пример
```python
try:
    number = int(input("Введите число: "))
    print(f"Вы ввели: {number}")
except ValueError:
    print("Ошибка: введено не целое число.")
finally:
    print("Работа операции завершена.")
```
Если пользователь введёт 10, программа выведет:
```text
Вы ввели: 10
Работа операции завершена.
```
Если пользователь введёт hello, программа выведет:
```text
Ошибка: введено не целое число.
Работа операции завершена.
```
В обоих случаях блок finally выполняется.

Для чего используют finally?

Он подходит для завершающих действий:

* Освобождения ресурсов.
* Закрытия соединений.
* Завершения временных операций.
* Выполнения действий, которые должны происходить независимо от результата.

Однако для файлов и многих других ресурсов в Python существуют более удобные инструменты. Например, конструкция with автоматически управляет закрытием файла.
```python
try:
    with open("data.txt", "r", encoding="utf-8") as file:
        content = file.read()
except FileNotFoundError:
    print("Файл не найден.")
else:
    print(content)
finally:
    print("Чтение файла завершено.")
```
Если файл существует, его содержимое будет выведено, а затем выполнится finally.

Если файл не существует, программа сообщит об ошибке и тоже выполнит finally.

Важно: finally не гарантирует выполнение при абсолютно любых обстоятельствах. Например, принудительное завершение процесса или аварийное прекращение работы интерпретатора может помешать его выполнению.

## 8. Полная конструкция try — except — else — finally

Все четыре блока можно использовать вместе.
```python
try:
    number = int(input("Введите число: "))
    result = 100 / number
except ValueError:
    print("Ошибка: необходимо ввести целое число.")
except ZeroDivisionError:
    print("Ошибка: делить на ноль нельзя.")
else:
    print(f"Результат: {result}")
finally:
    print("Программа завершила обработку операции.")
```

Рассмотрим порядок работы:

1. Python выполняет код в try.
2. Если возникает исключение, Python ищет подходящий except.
3. Если исключения не было, выполняется else.
4. После этого выполняется finally.

Если исключение возникло и было обработано, блок else пропускается, а finally выполняется.

Если исключение не соответствует ни одному обработчику, finally всё равно обычно выполняется, после чего исключение продолжает распространяться вверх по стеку вызовов.

Запомни разницу

Блок	Когда выполняется
try	Выполняется в первую очередь
except	Если возникло соответствующее исключение
else	Если в try не возникло исключений
finally	При завершении конструкции независимо от того, возникло исключение или нет, за исключением особых обстоятельств

## 9. Как правильно защищать код от сбоев

Обработка ошибок — это не просто добавление try и except в каждую функцию. Необходимо заранее определить, какие ситуации могут возникнуть и как программа должна на них реагировать.

Рассмотрим несколько принципов.

**Принцип 1. Проверяй пользовательский ввод**

Пользователь может ввести данные в неожиданном формате.

Плохой вариант:
```python
age = int(input("Введите возраст: "))
print(f"Через год вам будет {age + 1}.")
```
Если пользователь введёт двадцать, программа завершится с исключением.

Более надёжный вариант:
```python
try:
    age = int(input("Введите возраст: "))
except ValueError:
    print("Ошибка: возраст необходимо вводить числом.")
else:
    if age < 0:
        print("Возраст не может быть отрицательным.")
    else:
        print(f"Через год вам будет {age + 1}.")
```
Здесь предусмотрены два разных вида проверки:

* ValueError обрабатывает невозможность преобразовать строку в целое число.
* Условие if age < 0 проверяет допустимость самого значения.

Это разные задачи. Не каждая неправильная ситуация является исключением.

**Принцип 2. Не используй исключения вместо обычных условий**

Например, если нужно проверить, что число положительное, не обязательно вызывать исключение.

Неудачный подход:
```python
try:
    number = int(input("Введите число: "))
    if number <= 0:
        raise ValueError("Число должно быть положительным.")
except ValueError as error:
    print(error)
```
Такой вариант допустим, но для простой проверки он избыточен.

Проще:
```python
try:
    number = int(input("Введите число: "))
except ValueError:
    print("Необходимо ввести целое число.")
else:
    if number <= 0:
        print("Число должно быть положительным.")
    else:
        print(f"Ваше число: {number}")
```
Используй условия для обычных проверок, а исключения — для ошибок и исключительных ситуаций.

**Принцип 3. Не скрывай ошибки**

Не рекомендуется писать:
```python
try:
    result = 10 / 0
except Exception:
    pass
```
Что здесь происходит?

1. Возникает ошибка деления на ноль.
2. Она перехватывается.
3. pass ничего не делает.
4. Программа продолжает работу так, будто ничего не произошло.

В результате ошибка может остаться незамеченной, а программа — работать с некорректным состоянием.

Лучше обработать ожидаемую ошибку понятным образом:
```python
try:
    result = 10 / 0
except ZeroDivisionError:
    print("Невозможно выполнить деление на ноль.")
```

**Принцип 4. Обрабатывай только те ошибки, которые понимаешь**

Представим функцию, которая получает число от пользователя:
```python
def get_number():
    try:
        return int(input("Введите число: "))
    except ValueError:
        print("Некорректный ввод.")
        return None
```
Если преобразование не удалось, функция возвращает None.

Вызывающий код должен учитывать такую возможность:
```python
number = get_number()
if number is not None:
    print(number * 2)
else:
    print("Не удалось получить число.")
```
Если не проверять результат, программа может получить другую ошибку при дальнейшей работе.

Например, операция None * 2 допустима не будет и вызовет TypeError.

**Принцип 5. Разделяй обработку ошибок и основную логику**

Функции легче читать и проверять, когда каждая отвечает за понятную задачу.

Например:
```python
def convert_to_integer(value):
    try:
        return int(value)
    except ValueError:
        return None
def main():
    value = input("Введите целое число: ")
    number = convert_to_integer(value)
    if number is None:
        print("Ошибка: введено некорректное значение.")
        return
    print(f"Квадрат числа: {number ** 2}")
main()
```
Функция convert_to_integer() отвечает за преобразование значения.

Функция main() отвечает за взаимодействие с пользователем и выполнение программы.

Такой подход позволяет повторно использовать функцию преобразования и упрощает тестирование.

Важное замечание: возвращать None при ошибке — не единственный правильный вариант. В зависимости от задачи функция может повторять запрос ввода, возвращать специальный результат или позволять исключению распространяться дальше.

## 10. Как самостоятельно вызвать исключение с помощью raise

Иногда необходимо самостоятельно сообщить о некорректной ситуации. Для этого используется raise.

Например, функция должна принимать только положительные числа.
```python
def calculate_square_root_argument(number):
    if number < 0:
        raise ValueError("Число не может быть отрицательным.")
    return number
```
Если вызвать функцию с отрицательным числом: `calculate_square_root_argument(-5)` => возникнет ValueError.

Это полезно, когда функция должна гарантировать определённые условия работы.

Пример с обработкой
```python
def validate_age(age):
    if age < 0:
        raise ValueError("Возраст не может быть отрицательным.")
    if age > 150:
        raise ValueError("Указан недопустимый возраст.")
    return age
try:
    age = int(input("Введите возраст: "))
    validate_age(age)
except ValueError as error:
    print(f"Ошибка: {error}")
else:
    print(f"Возраст принят: {age}")
```
В этом примере ValueError может возникнуть по двум причинам:

* Невозможно преобразовать введённую строку в целое число.
* Возраст не соответствует заданным ограничениям.

Обработчик перехватывает оба случая.

Обрати внимание: если функция validate_age() получает строку вместо числа, сравнение строки с числом может вызвать TypeError. В этом примере функция вызывается после преобразования через int(), поэтому такая ситуация не возникает при обычном пользовательском вводе.

## 11. Практический пример: безопасный калькулятор

Объединим изученные конструкции в одной программе.

Калькулятор должен:

1. Запрашивать два числа.
2. Запрашивать математическую операцию.
3. Выполнять сложение, вычитание, умножение или деление.
4. Обрабатывать некорректный ввод.
5. Не допускать деления на ноль.
6. Сообщать о неизвестной операции.

```python
def calculate(first_number, second_number, operation):
    if operation == "+":
        return first_number + second_number
    elif operation == "-":
        return first_number - second_number
    elif operation == "*":
        return first_number * second_number
    elif operation == "/":
        if second_number == 0:
            raise ZeroDivisionError("Деление на ноль запрещено.")
        return first_number / second_number
    else:
        raise ValueError("Неизвестная математическая операция.")
try:
    first_number = float(input("Введите первое число: "))
    operation = input("Введите операцию (+, -, *, /): ")
    second_number = float(input("Введите второе число: "))
    result = calculate(first_number, second_number, operation)
except ValueError as error:
    print(f"Ошибка ввода: {error}")
except ZeroDivisionError as error:
    print(f"Ошибка вычисления: {error}")
else:
    print(f"Результат: {result}")
finally:
    print("Работа калькулятора завершена.")
```

Как работает программа

Если введены корректные числа и операция, программа выполняет вычисление и выводит результат.

Если вместо числа введён текст, возникает ValueError, который обрабатывается первым подходящим блоком.

Если пользователь пытается разделить на ноль, функция вызывает ZeroDivisionError.

Если указана неизвестная операция, функция вызывает ValueError с соответствующим сообщением.

В любом обычном сценарии завершения обработки выполняется блок finally.

В этой программе есть важная особенность: ValueError используется и для некорректного числового ввода, и для неизвестной операции. Для небольшого примера это допустимо, но в более крупных программах полезно различать причины ошибок более явно.

## 12. Краткая памятка

Конструкция	Назначение
try	Выполняет код, в котором может возникнуть исключение
except	Обрабатывает соответствующее исключение
except ValueError as error	Перехватывает ValueError и сохраняет объект исключения в переменную
else	Выполняется, если код в try завершился без исключений
finally	Выполняет завершающие действия независимо от возникновения исключения в обычных сценариях
raise	Вызывает исключение
Exception	Базовый класс большинства обычных исключений, которые принято обрабатывать
ValueError	Значение не подходит для ожидаемой операции
TypeError	Операция неприменима к данному типу
ZeroDivisionError	Деление на ноль
IndexError	Индекс отсутствует в последовательности
KeyError	Ключ отсутствует в словаре
FileNotFoundError	Файл не найден

Главное правило: обработка исключений должна делать программу надёжнее и понятнее, а не просто скрывать ошибки.
