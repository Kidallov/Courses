## Что такое условие ?<!-- {"fold":true} -->

Условия позволяют программе **принимать решения** — выполнять тот или иной код в зависимости от ситуации.

Пример реальной логики:
> Если идёт дождь -> взять зонт, иначе идти без зонта.

## Логические конструкции<!-- {"fold":true} -->
### Оператор `if`
**Важно: отступы (4 пробела или таб) обязательны!**
```python
age = 18
if age >= 18:
    print("Доступ разрешён")
```
### Блокelse
```python
age = 16
if age >= 18:
    print("Доступ разрешён")
else:
    print("Доступ запрещён")
```
### Блокelif
```python
Используется, когда условий больше одного.
temperature = 0
if temperature > 0:
    print("Плюс")
elif temperature < 0:
    print("Минус")
else:
    print("Ноль")
```
### Логические операторы
| **Оператор** | **Описание** | **Пример** |
|:-:|:-:|:-:|
| and | И | x > 0 and x < 10 |
| or | ИЛИ | x < 0 or x > 100 |
| not | НЕ | not True == False |
**Пример:**
```python
age = 25
has_passport = True

if age >= 18 and has_passport:
    print("Можно пройти")
```
### Truthy и Falsy значения
В условиях не обязательно писать == True — Python сам оценивает значения как **истинные или ложные**.
**Falsy значения:**
* 0
* 0.0
* пустая строка ""
* пустые коллекции [], {}
* None
* False

**Пример:**
```python
name = ""
if name:
    print("Имя введено")
else:
    print("Имя пустое")
```

### Тернарный оператор
Короткая форма условия в одну строку:
```python
действие(правидивое) if условие else действие(ложное)
```
