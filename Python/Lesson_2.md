# Урок 2. Списки и включения, кортежи

## Цели урока

После урока вы сможете:

- создавать и изменять списки (`list`);
- получать элементы списка по индексу;
- использовать срезы;
- добавлять и удалять элементы;
- сортировать списки;
- перебирать элементы списка с помощью `for`;
- создавать списки с помощью list comprehension;
- понимать разницу между `list` и `tuple`;
- создавать и распаковывать кортежи.

---

## 1. Списки `list`

Список — это упорядоченная изменяемая коллекция элементов.

```python
numbers = [10, 20, 30, 40]
names = ["Анна", "Иван", "Олег"]
```

В одном списке могут находиться значения разных типов:

```python
data = ["Александр", 22, True, 3.14]
```

Однако на практике лучше хранить в одном списке данные одного логического типа.

Например:

```python
students = ["Иван", "Анна", "Олег"]
ages = [19, 21, 20]
```

### Пустой список

```python
numbers = []
```

После этого в него можно добавлять элементы.

---

## 2. Индексы

Каждый элемент списка имеет индекс. Индексация начинается с `0`.

```python
names = ["Анна", "Иван", "Олег"]

print(names[0])  # Анна
print(names[1])  # Иван
print(names[2])  # Олег
```

Схематично:

```text
Элемент:   Анна     Иван     Олег
Индекс:      0        1        2
```

Можно использовать отрицательные индексы:

```python
names = ["Анна", "Иван", "Олег"]

print(names[-1])  # Олег
print(names[-2])  # Иван
```

`-1` означает последний элемент, `-2` — предпоследний и т. д.

---

## 3. Изменение элементов

Список является изменяемым, поэтому его элементы можно заменить.

```python
names = ["Анна", "Иван", "Олег"]

names[1] = "Пётр"

print(names)
```

Результат:

```text
['Анна', 'Пётр', 'Олег']
```

---

## 4. Добавление элементов: `append()`

Метод `append()` добавляет один элемент в конец списка.

```python
numbers = [10, 20, 30]

numbers.append(40)

print(numbers)
```

Результат:

```text
[10, 20, 30, 40]
```

Можно добавлять строки, числа и другие объекты:

```python
names = ["Анна", "Иван"]

names.append("Олег")

print(names)
```

### Важный момент

`append()` добавляет **один объект**.

```python
numbers = [1, 2, 3]

numbers.append([4, 5])

print(numbers)
```

Получим:

```text
[1, 2, 3, [4, 5]]
```

Если нужно добавить элементы другого списка отдельно, можно использовать `extend()`:

```python
numbers = [1, 2, 3]

numbers.extend([4, 5])

print(numbers)
```

Результат:

```text
[1, 2, 3, 4, 5]
```

На этом уроке основной метод добавления — `append()`.

---

## 5. Удаление элементов: `remove()`

Метод `remove()` удаляет первое найденное значение.

```python
numbers = [10, 20, 30, 20]

numbers.remove(20)

print(numbers)
```

Результат:

```text
[10, 30, 20]
```

Удалился только первый найденный `20`.

Если указанного элемента нет, Python выдаст ошибку `ValueError`.

```python
numbers = [10, 20, 30]

numbers.remove(50)
```

Поэтому перед удалением можно проверить наличие элемента:

```python
if 50 in numbers:
    numbers.remove(50)
```

---

## 6. Сортировка: `sort()`

Метод `sort()` сортирует список.

```python
numbers = [5, 2, 8, 1, 3]

numbers.sort()

print(numbers)
```

Результат:

```text
[1, 2, 3, 5, 8]
```

Для сортировки по убыванию:

```python
numbers = [5, 2, 8, 1, 3]

numbers.sort(reverse=True)

print(numbers)
```

Результат:

```text
[8, 5, 3, 2, 1]
```

Строки также можно сортировать:

```python
names = ["Олег", "Анна", "Иван", "Борис"]

names.sort()

print(names)
```

Результат:

```text
['Анна', 'Борис', 'Иван', 'Олег']
```

### `sort()` изменяет исходный список

```python
numbers = [3, 1, 2]

numbers.sort()

print(numbers)
```

После выполнения `sort()` переменная `numbers` содержит уже отсортированный список.

---

## 7. Длина списка: `len()`

Чтобы узнать количество элементов:

```python
numbers = [10, 20, 30, 40]

print(len(numbers))
```

Результат:

```text
4
```

`len()` часто используется вместе с индексами и циклами.

---

## 8. Проверка наличия элемента

Для проверки используется оператор `in`.

```python
names = ["Анна", "Иван", "Олег"]

print("Иван" in names)
```

Результат:

```text
True
```

Можно использовать в условии:

```python
if "Иван" in names:
    print("Иван найден")
```

Также существует `not in`:

```python
if "Пётр" not in names:
    print("Пётра нет в списке")
```

---

## 9. Срезы списков

Срез позволяет получить часть списка.

Общий синтаксис:

```python
list[start:stop:step]
```

- `start` — начальный индекс;
- `stop` — конечный индекс, который **не включается**;
- `step` — шаг.

Например:

```python
numbers = [0, 1, 2, 3, 4, 5]

print(numbers[1:4])
```

Результат:

```text
[1, 2, 3]
```

Индекс `4` в результат не попадает.

### Срез от начала

```python
numbers = [0, 1, 2, 3, 4, 5]

print(numbers[:3])
```

Результат:

```text
[0, 1, 2]
```

### Срез до конца

```python
print(numbers[3:])
```

Результат:

```text
[3, 4, 5]
```

### Копия списка

```python
copy_numbers = numbers[:]
```

Теперь `copy_numbers` содержит копию элементов списка.

### Срез с шагом

```python
numbers = [0, 1, 2, 3, 4, 5]

print(numbers[::2])
```

Результат:

```text
[0, 2, 4]
```

### Разворот списка

```python
print(numbers[::-1])
```

Результат:

```text
[5, 4, 3, 2, 1, 0]
```

---

## 10. Перебор списка с помощью `for`

Самый распространённый способ обработки списка — цикл `for`.

```python
names = ["Анна", "Иван", "Олег"]

for name in names:
    print(name)
```

Результат:

```text
Анна
Иван
Олег
```

На каждой итерации переменная `name` получает очередной элемент списка.

Можно выполнять действия с каждым элементом:

```python
numbers = [1, 2, 3, 4]

for number in numbers:
    print(number * 2)
```

Результат:

```text
2
4
6
8
```

---

## 11. Перебор с индексами

Если одновременно нужны индекс и значение, удобно использовать `enumerate()`.

```python
names = ["Анна", "Иван", "Олег"]

for index, name in enumerate(names):
    print(index, name)
```

Результат:

```text
0 Анна
1 Иван
2 Олег
```

Можно начать нумерацию с другого числа:

```python
for index, name in enumerate(names, start=1):
    print(index, name)
```

Результат:

```text
1 Анна
2 Иван
3 Олег
```

# 12. List comprehension

List comprehension — это компактный способ создать новый список на основе существующей последовательности.

Обычный вариант:

```python
numbers = [1, 2, 3, 4, 5]

squares = []

for number in numbers:
    squares.append(number ** 2)

print(squares)
```

Результат:

```text
[1, 4, 9, 16, 25]
```

То же самое с list comprehension:

```python
numbers = [1, 2, 3, 4, 5]

squares = [number ** 2 for number in numbers]

print(squares)
```

Общий вид:

```python
[выражение for переменная in последовательность]
```

Например:

```python
names = ["anna", "ivan", "oleg"]

upper_names = [name.upper() for name in names]

print(upper_names)
```

Результат:

```text
['ANNA', 'IVAN', 'OLEG']
```

---

## 13. List comprehension с условием

В list comprehension можно добавить условие.

Например, получить только чётные числа:

```python
numbers = [1, 2, 3, 4, 5, 6]

even_numbers = [number for number in numbers if number % 2 == 0]

print(even_numbers)
```

Результат:

```text
[2, 4, 6]
```

Общий вид:

```python
[выражение for переменная in последовательность if условие]
```

Ещё пример:

```python
numbers = [10, 3, 7, 20, 1, 15]

large_numbers = [number for number in numbers if number > 10]

print(large_numbers)
```

Результат:

```text
[20, 15]
```

### Когда не стоит использовать comprehension

Не нужно превращать сложную логику в одну длинную строку.

Плохо:

```python
result = [some_complex_function(x) for x in data if complicated_condition(x)]
```

Если выражение становится трудно читать, обычный `for` может быть лучше.

# 14. Кортежи `tuple`

Кортеж — это упорядоченная последовательность элементов, которую нельзя изменять после создания.

```python
point = (10, 20)
```

Можно обращаться к элементам по индексу:

```python
point = (10, 20)

print(point[0])
print(point[1])
```

Результат:

```text
10
20
```

Но изменить элемент нельзя:

```python
point[0] = 100
```

Python выдаст ошибку, потому что `tuple` является неизменяемым типом.

---

## 15. Создание кортежа

Обычно используются круглые скобки:

```python
person = ("Александр", 22)
```

Но скобки не являются обязательными:

```python
person = "Александр", 22
```

Это тоже кортеж.

### Кортеж из одного элемента

Здесь есть важная особенность.

```python
number = (10)
```

Это обычное число `int`, а не кортеж.

Для создания кортежа из одного элемента нужна запятая:

```python
number = (10,)

print(type(number))
```

Результат:

```text
<class 'tuple'>
```

---

## 16. Зачем нужны кортежи

Кортеж удобно использовать для данных, которые не должны изменяться.

Например:

```python
coordinates = (55.75, 37.62)
```

Координаты логически представляют единое значение и обычно не должны случайно изменяться внутри программы.

Ещё один пример:

```python
rgb = (255, 128, 0)
```

---

## 17. Перебор кортежа

Кортеж можно перебирать так же, как список:

```python
colors = ("red", "green", "blue")

for color in colors:
    print(color)
```

Также работают индексы и срезы:

```python
numbers = (10, 20, 30, 40, 50)

print(numbers[1])
print(numbers[1:4])
```

---

## 18. Распаковка кортежа

Можно записать элементы кортежа в отдельные переменные:

```python
person = ("Александр", 22)

name, age = person

print(name)
print(age)
```

Результат:

```text
Александр
22
```

Это называется распаковкой.

Особенно часто она используется, когда функция возвращает несколько значений:

```python
def get_user():
    return "Александр", 22

name, age = get_user()

print(name)
print(age)
```

# 19. `list` и `tuple`: основная разница

| Свойство | `list` | `tuple` |
|---|---|---|
| Изменяемость | Изменяемый | Неизменяемый |
| Синтаксис | `[]` | `()` |
| `append()` | Да | Нет |
| `remove()` | Да | Нет |
| `sort()` | Да | Нет |
| Индексы | Да | Да |
| Срезы | Да | Да |
| Перебор `for` | Да | Да |
| List comprehension | Да | Обычно результатом является `list` |

Пример:

```python
numbers_list = [1, 2, 3]
numbers_tuple = (1, 2, 3)
```

Если коллекция должна изменяться — обычно используется `list`.

Если данные должны оставаться неизменными — может подойти `tuple`.

# 20. Практический пример

Представим, что программа хранит оценки студента.

```python
grades = [5, 4, 3, 5, 4]

grades.append(5)

grades.remove(3)

grades.sort()

print(grades)
```

Результат:

```text
[4, 4, 5, 5, 5]
```

Теперь найдём оценки, которые равны `5`:

```python
excellent = [grade for grade in grades if grade == 5]

print(excellent)
```

Результат:

```text
[5, 5, 5]
```

Среднее значение можно вычислить так:

```python
average = sum(grades) / len(grades)

print(average)
```

Здесь используются:

- `sum()` — сумма элементов;
- `len()` — количество элементов;
- `/` — деление.

# 21. Типичные ошибки

### Ошибка 1. Неверный индекс

```python
numbers = [10, 20, 30]

print(numbers[3])
```

Индекса `3` нет. Последний индекс равен `2`.

---

### Ошибка 2. Попытка изменить tuple

```python
point = (10, 20)

point[0] = 100
```

Кортеж неизменяем.

Если нужен изменяемый набор данных, используйте `list`:

```python
point = [10, 20]
point[0] = 100
```

---

### Ошибка 3. Путаница между `append()` и `extend()`

```python
numbers = [1, 2]

numbers.append([3, 4])

print(numbers)
```

Результат:

```text
[1, 2, [3, 4]]
```

А:

```python
numbers = [1, 2]

numbers.extend([3, 4])

print(numbers)
```

Результат:

```text
[1, 2, 3, 4]
```

---

### Ошибка 4. Забыть, что верхняя граница среза не включается

```python
numbers = [0, 1, 2, 3, 4]

print(numbers[1:4])
```

Результат:

```text
[1, 2, 3]
```

Элемент с индексом `4` не включается.
