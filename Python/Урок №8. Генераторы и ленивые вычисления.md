# Урок  8. Генераторы и ленивые вычисления
## Введение<!-- {"fold":true} -->
**Генераторы** в Python — это функции или выражения, которые создают итераторы для **ленивой генерации последовательностей**, экономя **память**, так как не хранят все значения сразу, а выдают их по одному при вызове `next()` или в цикле `for`, используя оператор `yield`. Они идеальны для больших или бесконечных данных, позволяя обрабатывать их постепенно, в отличие от списков, которые загружают всё в память. 
## 1. Ключевое слово `yield`<!-- {"fold":true} -->

Что такое `yield` — аналог `return`, но с важной разницей:

* **return** возвращает значение и завершает функцию.
* **yield** возвращает значение и **приостанавливает** выполнение функции, сохраняя её состояние.

При следующем вызове функция продолжит работу с места, где был **yield**.

```python
def count_up_to(max_num):
	count = 1
	while count <= max_num:
		yield count
		count += 1

# Использование
counter = count_up_to(5)
print(next(counter))  # 1
print(next(counter))  # 2
```

**Нюансы**
* Функция с **yield** становится **генератором**.
* Генератор возвращает **итератор**, который можно обойти через `next()` или в цикле.
* После исчерпания генератора вызов `next()` вызовет исключение `StopIteration`.

## 2. Функция `next()`<!-- {"fold":true} -->

Назначение **next(iterator, [default])** — получает следующее значение из итератора.

Примеры
* **iterator** — итератор (например, генератор).
* **default** (опционально) — значение, которое вернётся, если итератор исчерпан (иначе поднимется StopIteration).

```python
gen = (x for x in range(3))
print(next(gen))        # 0
print(next(gen))        # 1
print(next(gen, "End")) # 2
print(next(gen, "End")) # End (не вызывает исключение)
```
## 3. Генераторы: синтаксис и особенности<!-- {"fold":true} -->

**Два способа создания генераторов**
1. **Функция с** yield (как выше).
2. **Генераторное выражение** (аналог списковых включений, но с круглыми скобками):

```python
squares = (x**2 for x in range(5))
print(list(squares))  # [0, 1, 4, 9, 16]
print(list(squares))  # [] ← генератор уже исчерпан!

list_squares = [x**2 for x in range(5)]
print(list_squares)  # [0, 1, 4, 9, 16]
print(list_squares)  # [0, 1, 4, 9, 16] ← список остается
```

Производительность
```python
import sys

gen = (x for x in range(1000))
print(sys.getsizeof(gen))

lst = [x for x in range(1000)]
print(sys.getsizeof(lst))
```

**Отличия от списков**
* **Память**: генераторы не хранят все значения сразу.
* **Скорость**: для больших данных генераторы быстрее при поочерёдном доступе.
* **Однопроходность**: генератор нельзя «перемотать» назад.

## 4. Функция `iter()`<!-- {"fold":true} -->
Назначение **iter(object, [sentinel])** — превращает объект в итератор.
```python
# Из списка
my_list = [1, 2, 3]
it = iter(my_list)
print(next(it))  # 1

# Из строки
it = iter("abc")
print(next(it))  # 'a'
```

Пример с `sentinel`
```python
# 1. Простой пример с функцией-счетчиком
counter = 0

def get_next_number():
    global counter
    counter += 1
    return counter

# Итератор будет вызывать get_next_number() пока она не вернет 5
# (5 - наш sentinel, маркер остановки)
iterator = iter(get_next_number, 5)

print("Числа до 5:")
for num in iterator:
    print(num)  # Выведет: 1 2 3 4
# Когда функция вернет 5 - итерация остановится
```
**Если объект не итерируемый, iter() вызовет TypeError**
## 5. Ленивый `range`<!-- {"fold":true} -->
В Python 3 `range()` — это **ленивый итератор**. Он не создаёт список чисел сразу, а генерирует их по мере необходимости.
```python
r = range(1000000) # не занимает много памяти
print(sys.getsizeof(r)) # вывод ответа в байтах
print(r[0])
print(r[-1])
```

**Почему это важно**
* Экономия памяти: range(10 в 6) занимает ~80 Б, а list(range(10 в 6)) — ~8 МБ.
* Подходит для больших диапазонов.

## 6. Встроенные функции: `zip`, `enumerate`, `any`, `all`<!-- {"fold":true} -->
zip(*iterables) - Объединяет элементы итераторов в пары (кортежи).
```python
names = ["Alice", "Bob"]
ages = [25, 30]
for name, age in zip(names, ages):
	print(f"{name} is {age} years old")
# Alice is 25 years old
# Bob is 30 years old
```

**Важный момент**: длина результата равна длине самого короткого итератора.

**enumerate(iterable, start=0)** - Добавляет счётчик к элементам итератора.
```python
fruits = ["apple", "banana"]
for i, fruit in enumerate(fruits, start=1):
	print(f"{i}. {fruit}")
# 1. apple
# 2. banana
```

**any(iterable)** - Возвращает True, если **хотя бы один** элемент истинен.
```
print(any([False, True, False]))  # True
print(any([]))                    # False
```

**all(iterable)** - Возвращает True, если **все** элементы истинны.
```
print(all([True, True, False]))  # False
print(all([]))                   # True (пустой итератор)
```

**Важный момент**: all([]) возвращает True по определению (пустое множество считается «все истинны»).
