## Что такое исключения?<!-- {"fold":true} -->

**Исключение (Exception)** — это событие, которое возникает во время выполнения программы и нарушает нормальный ход ее инструкций.

Когда в коде возникает ошибка, Python создает объект-исключение. Если это исключение не обработано, программа "падает" (аварийно завершается), и в консоль выводится **трассировка стека (Traceback)**.

**Пример:**
```python
print("Начало программы")
number = 10 / 0  # Деление на ноль!
print("Конец программы")  # Эта строка никогда не выполнится
```
**Вывод:**
```
Traceback (most recent call last):
  File "test.py", line 2, in <module>
    number = 10 / 0
ZeroDivisionError: division by zero
```
Программа остановилась на строке с делением на ноль, и последующий код не выполнился.

**Зачем обрабатывать исключения?**
* Чтобы программа не завершалась аварийно.
* Чтобы сообщать пользователю понятную информацию о том, что пошло не так.
* Чтобы корректно освобождать ресурсы (например, закрывать файлы) даже в случае ошибки.

---

## Конструкция `try...except`<!-- {"fold":true} -->

Для обработки исключений используется конструкция `try...except`.

```python
try:
    # Код, который может вызвать исключение
    risky_code()
except SomeException:
    # Код, который выполнится, если в блоке try возникло исключение SomeException
    handle_error()
```

**Перепишем наш пример:**
```python
print("Начало программы")

try:
    number = 10 / 0
    print("Результат:", number)
except ZeroDivisionError:
    print("Ошибка! Деление на ноль невозможно.")

print("Конец программы")
```
**Вывод:**
```
Начало программы
Ошибка! Деление на ноль невозможно.
Конец программы
```
Программа продолжила работу после обработки ошибки!

## Типы исключений и их перехват<!-- {"fold":true} -->

В Python много встроенных типов исключений. Вот некоторые частые из них:

* `ZeroDivisionError` — деление на ноль.

* `TypeError` — операция применена к объекту несоответствующего типа.

* `ValueError` — функция получает аргумент правильного типа, но некорректного значения.

* `IndexError` — индекс последовательности вне допустимого диапазона.

* `KeyError` — ключ не найден в словаре.

* `FileNotFoundError` — файл или директория не существует.

* `NameError` — попытка использования необъявленной переменной.

### Как перехватывать разные исключения?<!-- {"fold":true} -->

1. **Несколько блоков `except`:**
   Каждый блок `except` обрабатывает свой тип исключения.

   ```python
   try:
       num = int(input("Введите число: "))
       result = 100 / num
       my_list = [1, 2, 3]
       print(my_list[num])
   except ZeroDivisionError:
       print("На ноль делить нельзя!")
   except ValueError:
       print("Это не число!")
   except IndexError:
       print("Индекс за пределами списка!")
   ```

2. **Перехват нескольких исключений в одном блоке:**
   ```python
   try:
       # некоторый код
       pass
   except (ValueError, TypeError):
       print("Ошибка значения или типа!")
   ```

3. **Перехват всех исключений (антипаттерн!):**
   Использовать `except:` без указания типа — плохая практика, так как вы скроете даже те ошибки, о которых не подозревали (например, опечатку в имени переменной — `NameError`).

   **Плохо:**
   ```python
   try:
       # некоторый код
       pass
   except:
       print("Что-то пошло не так...")
   ```

   **Лучше:** Используйте `Exception`, который является базовым классом для всех встроенных исключений (но не для системных, вроде `SystemExit`).
   ```python
   try:
       # некоторый код
       pass
   except Exception as e:
       print(f"Произошла ошибка: {e}")
   ```
   Переменная `e` содержит объект исключения, и его можно использовать для получения информации об ошибке.

## Блок `else`<!-- {"fold":true} -->

Блок `else` выполняется **только если в блоке `try` не было ни одного исключения**.

```python
try:
    num = int(input("Введите число: "))
    result = 100 / num
except (ValueError, ZeroDivisionError) as e:
    print(f"Ошибка: {e}")
else:
    print(f"Все прошло успешно! Результат: {result}")
```

В этом примере строка с результатом выводится только в том случае, если преобразование в целое число и деление прошли без ошибок.

---

## Блок `finally`<!-- {"fold":true} -->

Блок `finally` выполняется **всегда**, независимо от того, было исключение или нет. Это идеальное место для кода, который должен быть выполнен в любом случае (например, закрытие файла или соединения с базой данных).

```python
try:
    file = open("example.txt", "r")
    data = file.read()
    number = int(data)
except FileNotFoundError:
    print("Файл не найден!")
except ValueError:
    print("В файле не число!")
finally:
    print("Закрываю файл...")
    file.close()  # Файл будет закрыт даже если возникла ошибка
```

**Порядок выполнения:**
1. Выполняется код в `try`.
2. Если есть исключение — выполняется соответствующий `except`.
3. Если исключения не было — выполняется `else`.
4. **В любом случае** выполняется `finally`.

## Оператор `raise` — поднимаем исключения сами<!-- {"fold":true} -->

Иногда вам нужно самим инициировать ошибку. Для этого используется оператор `raise`.

**Зачем это нужно?**

* Для проверки входных данных функции.
* Чтобы сигнализировать о непредвиденном состоянии программы.
* Для создания собственных, специфичных для вашей программы, типов ошибок.

**Пример:**
```python
def calculate_square_root(number):
    if number < 0:
        raise ValueError("Число не может быть отрицательным.")
    return number ** 0.5

try:
    result = calculate_square_root(-10)
except ValueError as e:
    print(e)  # Выведет: Число не может быть отрицательным.
```

## Полезные советы и нюансы<!-- {"fold":true} -->

1. **Конкретность прежде всего.** Всегда старайтесь перехватывать как можно более конкретные исключения. Перехват `Exception` должен быть обоснован.
2. **Не злоупотребляйте обработкой.** Не стоит оборачивать в `try...except` весь код подряд. Обрабатывайте только те места, где ошибки действительно ожидаемы (ввод пользователя, работа с файлами, сетевыми запросами).
3. **Логируйте ошибки.** В больших приложениях вместо `print(e)` лучше использовать модуль `logging` для записи ошибок в файл.
4. **Блок `try` должен быть минимальным.** Помещайте в него только тот код, который может вызвать исключение. Это делает код чище и понятнее.

#### **Сложное задание: "Умный парсер чисел"**

Напишите функцию `smart_number_parser(string)`, которая принимает на вход строку и пытается преобразовать ее в число (целое или с плавающей точкой). Функция должна возвращать число, если преобразование прошло успешно.

**Требования:**

1. **Базовая функциональность:**
   * Используйте `try...except` для перехвата `ValueError` при преобразовании строки в `int`, а затем в `float`.
   * Если оба преобразования неудачны, функция должна вернуть `None`.

2. **Обработка специальных случаев с помощью `raise`:**
   * Если на вход передана пустая строка, функция должна вызывать исключение `ValueError` с сообщением "Строка пуста".
   * Если на вход передан не строковый тип данных (например, число, список и т.д.), функция должна вызывать исключение `TypeError` с сообщением "Функция ожидает строку".

3. **Использование `else` и `finally`:**
   * В блоке `else` выводите сообщение: "Преобразование прошло успешно!".
   * В блоке `finally` выводите сообщение: "Преобразование для строки '<исходная_строка>' завершено." (исходную строку выведите до 10 символов, если она длиннее, добавьте многоточие `...`).

4. **Напишите основной код,** который демонстрирует работу функции в различных сценариях:
   * Корректные строки ("123", "45.67").
   * Некорректные строки ("abc").
   * Пустая строка ("").
   * Не строковый аргумент (например, `123`).

   Для каждого сценария используйте `try...except`, чтобы обработать возможные исключения, которые **вы сами вызываете** в функции (`ValueError` и `TypeError`), и корректно выводите результат или сообщение об ошибке.

**Пример работы программы:**

```python
# Тестовые вызовы
test_cases = ["123", "45.67", "abc", "", 123]

for case in test_cases:
    try:
        print(f"Обрабатываем: {case}")
        result = smart_number_parser(case)
        print(f"Результат: {result}\n")
    except ValueError as e:
        print(f"Ошибка значения: {e}\n")
    except TypeError as e:
        print(f"Ошибка типа: {e}\n")
```

**Ожидаемый вывод:**
```

Преобразование для строки '45.67' завершено.

Преобразование для строки 'abc' завершено.

Ошибка значения: Строка пуста

Обрабатываем: 123
Ошибка типа: Функция ожидает строку
```
