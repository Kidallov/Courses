# Урок 7. Генераторы и ленивые вычисления

> **Темы урока:** `yield`, `next()`, генераторы, `iter()`, ленивый `range`, встроенные функции `zip`, `enumerate`, `any`, `all`.

---

## 1. Зачем нужны ленивые вычисления

Обычный список хранит **все** элементы в памяти сразу:

```python
numbers = [x * x for x in range(10_000_000)]   # ~80 МБ в памяти сразу
```

Если нам нужно пройти по элементам по одному, хранить сразу весь список необязательно. **Ленивые вычисления** (от англ. *lazy* — «ленивый») означают: значение вычисляется **только тогда, когда оно действительно понадобилось**, а не заранее.

Главные плюсы:

- **Экономия памяти** — не храним всё сразу.
- **Скорость старта** — можно начать работать с первым элементом, не дожидаясь расчёта всех.
- **Возможность бесконечных последовательностей** — например, все натуральные числа.

---

## 2. Что такое итератор и функция `iter()`

**Итератор** — это объект, который умеет выдавать элементы по одному. Чтобы получить итератор из любой коллекции (списка, строки, кортежа и т. д.), используют `iter()`:

```python
numbers = [10, 20, 30]
it = iter(numbers)          # получаем итератор

print(next(it))             # 10
print(next(it))             # 20
print(next(it))             # 30
print(next(it))             # StopIteration — элементы закончились
```

Правила:

- `iter(объект)` → возвращает итератор для объекта.
- `next(итератор)` → возвращает следующий элемент.
- Когда элементы заканчиваются, `next()` бросает исключение `StopIteration`.

То же самое делает цикл `for` «под капотом»: берёт итератор и вызывает `next()`, пока не получит `StopIteration`.

---

## 3. Генераторы и ключевое слово `yield`

**Генератор** — это функция, которая вместо `return` использует `yield`. Такая функция возвращает итератор и «запоминает», где она остановилась.

```python
def countdown(n):
    while n > 0:
        yield n            # отдаём значение и замираем
        n -= 1

gen = countdown(3)         # тело функции ещё НЕ выполнилось
print(next(gen))           # 3
print(next(gen))           # 2
print(next(gen))           # 1
print(next(gen))           # StopIteration
```

Что важно понять:

1. Вызов `countdown(3)` **не выполняет** тело функции — он возвращает объект-генератор.
2. Каждый вызов `next()` запускает функцию **с того места, где она остановилась**.
3. Функция сохраняет все свои локальные переменные между вызовами `next()`.
4. Когда функция доходит до конца, генерируется `StopIteration`.

Генератор **нельзя «перемотать» назад** — он одноразовый. Пройденные значения он не хранит.

```python
gen = countdown(3)
print(list(gen))   # [3, 2, 1]
print(list(gen))   # [] — генератор уже исчерпан
```

## 4. Ленивый `range`

В Python 3 `range` — ленивый объект: он не создаёт список, а лишь хранит начало, конец и шаг, вычисляя элементы по запросу.

```python
r = range(10_000_000)       # почти не занимает памяти
print(r[5])                 # 5 — элемент вычисляется на лету
print(len(r))               # 10_000_000
print(3 in r)               # True
```

Поэтому `range(10 ** 12)` можно спокойно создавать — память не закончится. А вот `list(range(10 ** 12))` уже попытается создать огромный список и, скорее всего, упадёт с `MemoryError`.

## 5. Генераторные выражения

Это «ленивая» версия спискового включения — круглые скобки вместо квадратных:

```python
squares = (x * x for x in range(10))   # генератор, а не список
print(next(squares))                    # 0
print(next(squares))                    # 1
```

Сравним:

```python
list_comp = [x * x for x in range(10)]   # список — всё в памяти
gen_expr  = (x * x for x in range(10))   # генератор — по одному
```

## 6. Встроенные функции для работы с итераторами

### `zip` — соединяет последовательности попарно

```python
names = ["Анна", "Борис", "Виктор"]
ages  = [25, 30, 35]

for name, age in zip(names, ages):
    print(name, age)
# Анна 25
# Борис 30
# Виктор 35
```

Особенности:

- `zip` ленивый — возвращает итератор.
- Он останавливается на **самой короткой** последовательности:

```python
print(list(zip([1, 2, 3], ["a", "b"])))   # [(1, 'a'), (2, 'b')]
```

### `enumerate` — добавляет порядковый номер

```python
fruits = ["яблоко", "груша", "слива"]

for index, fruit in enumerate(fruits):
    print(index, fruit)
# 0 яблоко
# 1 груша
# 2 слива
```

Нумерацию можно начать не с нуля:

```python
print(list(enumerate(fruits, start=1)))
# [(1, 'яблоко'), (2, 'груша'), (3, 'слива')]
```

### `any` — «хотя бы один истинный»

Возвращает `True`, если **хотя бы один** элемент истинный (`True`). Как только найден первый истинный элемент — проверка прекращается.

```python
print(any([0, "", None, 5]))   # True — 5 истинный
print(any([0, "", None]))      # False — все ложные
print(any([]))                 # False — пустая последовательность
```

### `all` — «все истинные»

Возвращает `True`, если **все** элементы истинные. Как только найден первый ложный — проверка прекращается.

```python
print(all([1, "x", [1, 2]]))   # True — все истинные
print(all([1, 0, 5]))          # False — 0 ложный
print(all([]))                 # True — пустая последовательность
```

Запомнить пустые случаи просто: `any([])` — `False`, `all([])` — `True`.

## 7. Пример: читаем файл построчно (экономно)

Открытие файла возвращает итератор по строкам — файл не читается в память целиком:

```python
with open("big_file.txt", encoding="utf-8") as f:
    for line in f:            # строки читаются по одной
        if "python" in line.lower():
            print(line.rstrip())
```

Это работает даже с файлами в несколько гигабайт — в памяти всегда только одна строка.

## 8. Шпаргалка

| Конструкция | Что делает | Ленивый? |
| --- | --- | --- |
| `[x for x in ...]` | список, всё в памяти сразу | нет |
| `(x for x in ...)` | генераторное выражение | да |
| `range(...)` | последовательность чисел | да |
| `iter(obj)` | получить итератор | да |
| `next(it)` | следующий элемент | да |
| `zip(a, b)` | попарно соединить | да |
| `enumerate(a)` | пары (номер, элемент) | да |
| `any(iterable)` | хотя бы один истинный | да (останавливается рано) |
| `all(iterable)` | все истинные | да (останавливается рано) |
| `yield` | приостановить генератор | да |
