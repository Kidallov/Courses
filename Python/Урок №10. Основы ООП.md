# Классы и основы ООП

## 1. Что такое класс и объект?

**Класс (`class`)** — это шаблон или "чертеж" для создания объектов. Он описывает, какими свойствами и поведением будет обладать объект.
**Объект (экземпляр)** — это конкретная реализация класса.

## 2. Магический метод `__init__` и `self`

Когда мы создаем объект, Python автоматически вызывает метод `__init__`. Его называют **конструктором**. Он нужен, чтобы задать объекту начальные данные (атрибуты).

* **`self`** — это ссылка на конкретный экземпляр класса. Через него класс "понимает", чьи именно данные он сейчас меняет.

## 3. Атрибуты и методы

* **Атрибуты** — это переменные внутри класса (что объект "знает" о себе: имя, возраст, цвет).
* **Методы** — это функции внутри класса (что объект "умеет" делать).

#### Пример кода:

```python
class Robot:
    # Конструктор
    def __init__(self, name, model):
        self.name = name    # Атрибут
        self.model = model  # Атрибут

    # Метод
    def say_hello(self):
        print(f"Привет! Я робот {self.name}, модель {self.model}.")

# Создаем объекты (экземпляры)
robot_1 = Robot("R2-D2", "Astromech")
robot_2 = Robot("C-3PO", "Protocol")

robot_1.say_hello()
robot_2.say_hello()

```

---

## 4. Базовое наследование

Наследование позволяет создать новый класс на основе уже существующего. Дочерний класс забирает себе все атрибуты и методы родителя, но может добавлять свои.

#### Пример наследования:

```python
class FlyingRobot(Robot): # Наследуемся от Robot
    def fly(self):
        print(f"Робот {self.name} взлетает!")

drone = FlyingRobot("DJI", "Mavic")
drone.say_hello() # Метод взят у родителя
drone.fly()       # Свой метод

```
