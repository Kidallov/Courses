# Урок 8. Работа с файлами

> **Темы урока:** `open`, `read`, `write`, `with`, построчная обработка.

---

## 1. Зачем уметь работать с файлами

Программа, которая хранит данные только в памяти, теряет их при завершении. Файлы позволяют:

- сохранять результат работы (отчёты, логи, настройки);
- читать входные данные (таблицы, тексты, конфигурации);
- обрабатывать большие объёмы информации, которые не помещаются в память целиком.

---

## 2. Открытие файла — `open()`

Функция `open()` возвращает **файловый объект**, через который мы читаем или пишем.

```python
file = open("example.txt", "r", encoding="utf-8")
```

Основные аргументы:

- `"example.txt"` — путь к файлу;
- `"r"` — режим (mode);
- `encoding="utf-8"` — кодировка (важно указывать для текста с кириллицей).

### Режимы открытия

| Режим | Значение | Что делает с файлом |
| --- | --- | --- |
| `"r"` | read | открывает для чтения (по умолчанию); ошибка, если файла нет |
| `"w"` | write | открывает для записи; **создаёт файл или перезаписывает** его с нуля |
| `"a"` | append | открывает для добавления; **дописывает в конец**, не удаляя содержимое |
| `"x"` | exclusive | создаёт новый файл; ошибка, если файл уже существует |
| `"b"` | binary | двоичный режим (например `"rb"`, `"wb"`) |
| `"+"` | update | чтение и запись одновременно (например `"r+"`) |

> ⚠️ Режим `"w"` опасен: он молча стирает всё, что было в файле. Если нужно просто дописать — используйте `"a"`.

## 3. Чтение файла — `read`

### `read()` — прочитать весь файл целиком

```python
file = open("example.txt", "r", encoding="utf-8")
content = file.read()      # строка со всем содержимым
print(content)
file.close()
```

### `read(n)` — прочитать n символов

```python
file = open("example.txt", "r", encoding="utf-8")
chunk = file.read(10)      # первые 10 символов
print(chunk)
file.close()
```

### `readline()` — прочитать одну строку

```python
file = open("example.txt", "r", encoding="utf-8")
first = file.readline()    # первая строка (вместе с "\n")
second = file.readline()   # вторая строка
file.close()
```

### `readlines()` — прочитать все строки списком

```python
file = open("example.txt", "r", encoding="utf-8")
lines = file.readlines()   # ['строка 1\n', 'строка 2\n', ...]
file.close()
```

## 4. Запись в файл — `write`

```python
file = open("output.txt", "w", encoding="utf-8")
file.write("Первая строка\n")
file.write("Вторая строка\n")
file.close()
```

- `write(str)` — записывает одну строку; символ перевода строки `\n` нужно добавлять самому.
- `writelines(list)` — записывает список строк, но **не добавляет** `\n` между ними автоматически:

```python
lines = ["a", "b", "c"]
file.writelines(lines)      # получится "abc" без переносов
```

Чтобы получить переносы, добавляйте их сами:

```python
lines = ["a\n", "b\n", "c\n"]
file.writelines(lines)
```

## 5. Контекстный менеджер `with`

Правило хорошего тона — открывать файл через `with`. Он **гарантированно закроет файл**, даже если внутри блока произойдёт ошибка.

```python
with open("example.txt", "r", encoding="utf-8") as file:
    content = file.read()
    print(content)
# здесь файл уже закрыт автоматически
```

Зачем это важно:

- файл закрывается всегда (даже при исключении);
- ресурсы освобождаются сразу;
- меньше риск «забыть» `close()`.

Без `with` нужно вручную вызывать `file.close()`, и при ошибке между `open` и `close` файл может остаться открытым.

## 6. Построчная обработка

Файловый объект — это итератор по строкам. Поэтому файл можно перебирать в цикле `for` — это читает **по одной строке за раз** и почти не расходует память:

```python
with open("big_file.txt", "r", encoding="utf-8") as file:
    for line in file:
        line = line.rstrip()      # убираем "\n" в конце
        print(line)
```

Это работает даже с файлами в несколько гигабайт: в памяти всегда находится только одна строка, а не весь файл.

### Обработка с номером строки

```python
with open("log.txt", "r", encoding="utf-8") as file:
    for number, line in enumerate(file, start=1):
        if "ERROR" in line:
            print(f"Строка {number}: {line.rstrip()}")
```

### Подсчёт строк, слов и символов

```python
with open("text.txt", "r", encoding="utf-8") as file:
    lines = words = chars = 0
    for line in file:
        lines += 1
        words += len(line.split())
        chars += len(line)

print(f"Строк: {lines}, слов: {words}, символов: {chars}")
```

## 7. Кодировка

Файлы с русским текстом обычно сохраняют в UTF-8. Если при чтении появляются «кракозябры» (например `РџСЂРёРІРµС‚`), скорее всего, кодировка указана неверно.

```python
with open("text.txt", "r", encoding="utf-8") as file:
    text = file.read()
```

На Windows по умолчанию часто используется `cp1251`, поэтому явное указание `encoding="utf-8"` — хорошая привычка.

---

## 8. Типичные ошибки

| Ошибка | Причина |
| --- | --- |
| `FileNotFoundError` | файл не найден (например, неверный путь или режим `"r"` для несуществующего файла) |
| `PermissionError` | нет прав на чтение/запись |
| `UnicodeDecodeError` | неверная кодировка при чтении |
| данные стёрлись | использован режим `"w"` вместо `"a"` |
| всё слиплось в одну строку | забыли `\n` или `writelines` без переносов |

---

## 9. Шпаргалка

| Операция | Код |
| --- | --- |
| Открыть для чтения | `open("f.txt", "r", encoding="utf-8")` |
| Прочитать целиком | `file.read()` |
| Прочитать одну строку | `file.readline()` |
| Прочитать все строки списком | `file.readlines()` |
| Открыть для записи (перезапись) | `open("f.txt", "w", encoding="utf-8")` |
| Открыть для добавления | `open("f.txt", "a", encoding="utf-8")` |
| Записать строку | `file.write("text\n")` |
| Записать список строк | `file.writelines(["a\n", "b\n"])` |
| Построчный перебор | `for line in file:` |
| Автоматическое закрытие | `with open(...) as file:` |
