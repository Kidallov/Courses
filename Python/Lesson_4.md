# 1. Словари `dict`

Словарь — это изменяемая коллекция данных, которая хранит пары:

```text
ключ → значение
```

Например:

```python
user = {
    "name": "Александр",
    "age": 22,
    "language": "Python"
}
```

Здесь:

- `"name"` — ключ;
- `"Александр"` — значение;
- `"age"` — ключ;
- `22` — значение;
- `"language"` — ключ;
- `"Python"` — значение.

В отличие от списка, в словаре мы обычно обращаемся к данным не по числовому индексу, а по ключу.

```python
print(user["name"])
print(user["age"])
```

Результат:

```text
Александр
22
```

---

# 2. Создание словаря

Пустой словарь:

```python
user = {}
```

Словарь с данными:

```python
user = {
    "name": "Иван",
    "age": 20,
    "city": "Москва"
}
```

Можно создавать словари с помощью `dict()`:

```python
user = dict(
    name="Иван",
    age=20,
    city="Москва"
)
```

---

# 3. Ключи словаря

Ключ должен быть уникальным.

Например:

```python
user = {
    "name": "Иван",
    "age": 20,
    "name": "Олег"
}
```

В результате останется только последнее значение для ключа `"name"`:

```python
print(user)
```

Результат:

```text
{'name': 'Олег', 'age': 20}
```

Поэтому один ключ не может нормально использоваться для хранения нескольких независимых значений.

В качестве ключей часто используются строки и числа:

```python
data = {
    "name": "Иван",
    1: "Первый элемент",
    2: "Второй элемент"
}
```

---

# 4. Получение значения по ключу

Самый простой вариант:

```python
user = {
    "name": "Иван",
    "age": 20
}

print(user["name"])
```

Результат:

```text
Иван
```

Если ключа нет, возникнет ошибка `KeyError`:

```python
print(user["email"])
```

Если ключ может отсутствовать, лучше использовать `get()`.

---

# 5. Метод `get()`

`get()` позволяет безопасно получить значение по ключу.

```python
user = {
    "name": "Иван",
    "age": 20
}

print(user.get("name"))
print(user.get("email"))
```

Результат:

```text
Иван
None
```

Если ключ отсутствует, `get()` по умолчанию возвращает `None`.

Можно указать значение по умолчанию:

```python
email = user.get("email", "Email не указан")

print(email)
```

Результат:

```text
Email не указан
```

Это особенно удобно при работе с данными, в которых некоторые поля могут отсутствовать.

---

# 6. Добавление и изменение элементов

Словари изменяемые.

Чтобы добавить новый элемент:

```python
user = {
    "name": "Иван",
    "age": 20
}

user["city"] = "Москва"

print(user)
```

Получим:

```text
{'name': 'Иван', 'age': 20, 'city': 'Москва'}
```

Если ключ уже существует, его значение будет изменено:

```python
user["age"] = 21
```

Теперь:

```text
{'name': 'Иван', 'age': 21, 'city': 'Москва'}
```

Таким образом, одна и та же конструкция используется и для добавления, и для изменения:

```python
dictionary[key] = value
```

---

# 7. Удаление элементов

Для удаления элемента можно использовать `del`:

```python
user = {
    "name": "Иван",
    "age": 20,
    "city": "Москва"
}

del user["city"]

print(user)
```

Результат:

```text
{'name': 'Иван', 'age': 20}
```

Также существует метод `pop()`:

```python
age = user.pop("age")

print(age)
print(user)
```

`pop()` удаляет элемент и возвращает его значение.

---

# 8. Проверка наличия ключа

Оператор `in` проверяет наличие ключа в словаре:

```python
user = {
    "name": "Иван",
    "age": 20
}

print("name" in user)
print("email" in user)
```

Результат:

```text
True
False
```

Можно использовать это в условии:

```python
if "email" in user:
    print(user["email"])
else:
    print("Email отсутствует")
```

# 9. Метод `keys()`

`keys()` возвращает представление всех ключей словаря.

```python
user = {
    "name": "Иван",
    "age": 20,
    "city": "Москва"
}

print(user.keys())
```

Можно перебрать ключи:

```python
for key in user.keys():
    print(key)
```

Результат:

```text
name
age
city
```

На практике часто можно написать короче:

```python
for key in user:
    print(key)
```

Перебор словаря без дополнительного метода также проходит по ключам.

---

# 10. Метод `values()`

`values()` возвращает значения словаря.

```python
user = {
    "name": "Иван",
    "age": 20,
    "city": "Москва"
}

for value in user.values():
    print(value)
```

Результат:

```text
Иван
20
Москва
```

Если нужны только значения, `values()` удобнее, чем перебор ключей.

---

# 11. Метод `items()`

`items()` возвращает пары:

```text
ключ, значение
```

Например:

```python
user = {
    "name": "Иван",
    "age": 20,
    "city": "Москва"
}

for key, value in user.items():
    print(key, value)
```

Результат:

```text
name Иван
age 20
city Москва
```

Это один из самых часто используемых способов перебора словаря.

Например:

```python
prices = {
    "apple": 100,
    "banana": 80,
    "orange": 120
}

for product, price in prices.items():
    print(f"{product}: {price} рублей")
```

---

# 12. Сравнение `keys()`, `values()` и `items()`

Для словаря:

```python
user = {
    "name": "Иван",
    "age": 20
}
```

Используйте:

```python
user.keys()
```

если нужны ключи:

```text
name
age
```

Используйте:

```python
user.values()
```

если нужны значения:

```text
Иван
20
```

Используйте:

```python
user.items()
```

если нужны одновременно ключи и значения:

```text
name Иван
age 20
```

# 13. Распаковка словаря

Распаковка позволяет передавать содержимое словаря в другие структуры и функции.

Для распаковки словаря используется оператор `**`.

Например:

```python
user = {
    "name": "Иван",
    "age": 20
}

other_user = {
    **user,
    "city": "Москва"
}

print(other_user)
```

Результат:

```text
{'name': 'Иван', 'age': 20, 'city': 'Москва'}
```

Таким способом можно создать новый словарь на основе существующего.

---

# 14. Объединение словарей с `**`

Можно объединить несколько словарей:

```python
user_data = {
    "name": "Иван",
    "age": 20
}

contact_data = {
    "email": "ivan@example.com",
    "phone": "+7 900 000-00-00"
}

user = {
    **user_data,
    **contact_data
}

print(user)
```

Результат:

```text
{
    'name': 'Иван',
    'age': 20,
    'email': 'ivan@example.com',
    'phone': '+7 900 000-00-00'
}
```

Если в словарях есть одинаковые ключи, значение из более позднего словаря перезапишет предыдущее:

```python
first = {"name": "Иван"}
second = {"name": "Олег"}

result = {
    **first,
    **second
}

print(result)
```

Результат:

```text
{'name': 'Олег'}
```

---

# 15. Распаковка словаря в функцию

Оператор `**` особенно часто используется при передаче именованных аргументов:

```python
def create_user(name, age):
    print(name, age)

user = {
    "name": "Иван",
    "age": 20
}

create_user(**user)
```

Это эквивалентно:

```python
create_user(
    name="Иван",
    age=20
)
```

То есть ключи словаря становятся именами аргументов функции.

# 16. Множества `set`

Множество — это коллекция уникальных элементов.

Например:

```python
numbers = {1, 2, 3, 4}
```

В отличие от списка, множество не предназначено для хранения элементов с повторяющимися значениями.

```python
numbers = {1, 2, 2, 3, 3, 3}

print(numbers)
```

Результат:

```text
{1, 2, 3}
```

Повторяющиеся элементы автоматически удаляются.

---

# 17. Создание множества

Множество можно создать через фигурные скобки:

```python
numbers = {1, 2, 3}
```

Пустое множество создаётся не так:

```python
numbers = {}
```

Это пустой словарь.

Для пустого множества нужно использовать:

```python
numbers = set()
```

---

# 18. Добавление элементов в `set`

Используется метод `add()`:

```python
numbers = {1, 2, 3}

numbers.add(4)

print(numbers)
```

Результат:

```text
{1, 2, 3, 4}
```

Если добавить уже существующий элемент:

```python
numbers.add(3)
```

Ничего нового не произойдёт.

Множество всё равно будет содержать один `3`.

---

# 19. Удаление элементов из множества

Метод `remove()` удаляет элемент:

```python
numbers = {1, 2, 3}

numbers.remove(2)

print(numbers)
```

Если элемента нет, `remove()` вызовет `KeyError`.

Более безопасный вариант — `discard()`:

```python
numbers.discard(10)
```

Если `10` отсутствует, ошибки не будет.

---

# 20. Проверка принадлежности

Оператор `in` работает с множествами:

```python
numbers = {10, 20, 30}

print(20 in numbers)
print(50 in numbers)
```

Результат:

```text
True
False
```

Проверка принадлежности множеству — одна из наиболее распространённых задач для `set`.

# 21. Операции над множествами

Главная особенность множеств — возможность выполнять операции над коллекциями.

Пусть есть два множества:

```python
a = {1, 2, 3, 4}
b = {3, 4, 5, 6}
```

---

## 21.1. Объединение

Объединение содержит все элементы обоих множеств без повторений.

Используется оператор `|`:

```python
result = a | b

print(result)
```

Результат:

```text
{1, 2, 3, 4, 5, 6}
```

То же самое можно сделать методом:

```python
result = a.union(b)
```

---

## 21.2. Пересечение

Пересечение содержит элементы, которые есть в обоих множествах.

Используется оператор `&`:

```python
result = a & b

print(result)
```

Результат:

```text
{3, 4}
```

Или:

```python
result = a.intersection(b)
```

---

## 21.3. Разность

Разность `a - b` содержит элементы, которые есть в `a`, но отсутствуют в `b`.

```python
result = a - b

print(result)
```

Результат:

```text
{1, 2}
```

Обратная разность:

```python
result = b - a

print(result)
```

Результат:

```text
{5, 6}
```

---

## 21.4. Симметрическая разность

Симметрическая разность содержит элементы, которые принадлежат только одному из двух множеств.

Используется оператор `^`:

```python
result = a ^ b

print(result)
```

Результат:

```text
{1, 2, 5, 6}
```

То же самое:

```python
result = a.symmetric_difference(b)
```

---

# 22. Таблица операций над множествами

Для:

```python
a = {1, 2, 3, 4}
b = {3, 4, 5, 6}
```

получаем:

| Операция | Синтаксис | Результат |
|---|---|---|
| Объединение | `a \| b` | `{1, 2, 3, 4, 5, 6}` |
| Пересечение | `a & b` | `{3, 4}` |
| Разность | `a - b` | `{1, 2}` |
| Обратная разность | `b - a` | `{5, 6}` |
| Симметрическая разность | `a ^ b` | `{1, 2, 5, 6}` |

Эти операции аналогичны операциям над множествами в математике.

# 23. Проверка отношений между множествами

Множества позволяют проверять, является ли одно множество подмножеством другого.

Например:

```python
a = {1, 2, 3}
b = {1, 2, 3, 4, 5}
```

Проверим:

```python
print(a.issubset(b))
```

Результат:

```text
True
```

Это означает, что все элементы `a` входят в `b`.

Обратная проверка:

```python
print(b.issuperset(a))
```

Результат:

```text
True
```

---

# 24. Проверка отсутствия общих элементов

Метод `isdisjoint()` проверяет, не пересекаются ли два множества.

```python
a = {1, 2, 3}
b = {4, 5, 6}

print(a.isdisjoint(b))
```

Результат:

```text
True
```

Если есть хотя бы один общий элемент:

```python
a = {1, 2, 3}
b = {3, 4, 5}

print(a.isdisjoint(b))
```

Результат:

```text
False
```

# 25. Удаление дубликатов с помощью `set`

Одна из самых полезных задач для множества — удалить повторяющиеся значения.

Например:

```python
numbers = [1, 2, 2, 3, 3, 3, 4, 4]

unique_numbers = set(numbers)

print(unique_numbers)
```

Результат:

```text
{1, 2, 3, 4}
```

Если снова нужен список:

```python
unique_numbers = list(set(numbers))
```

Важно: множество не предназначено для сохранения исходного порядка элементов.

# 27. Практический пример со словарём

Представим каталог товаров:

```python
products = {
    "laptop": 80000,
    "phone": 50000,
    "headphones": 10000
}
```

Выведем все товары:

```python
for product in products:
    print(product)
```

Выведем цены:

```python
for price in products.values():
    print(price)
```

Выведем товар и его цену:

```python
for product, price in products.items():
    print(f"{product}: {price} руб.")
```

Найдём товары дешевле 60 000:

```python
cheap_products = {
    product: price
    for product, price in products.items()
    if price < 60000
}

print(cheap_products)
```

Здесь используется уже знакомый нам list/dict comprehension. Для словаря синтаксис выглядит так:

```python
{
    ключ: значение
    for элемент in последовательность
}
```

# 28. `dict` и `set`: разница

На первый взгляд они похожи:

```python
data = {"name": "Иван"}
numbers = {1, 2, 3}
```

Но это разные структуры.

Словарь хранит пары:

```text
ключ → значение
```

Например:

```python
user = {
    "name": "Иван",
    "age": 20
}
```

Множество хранит только уникальные элементы:

```python
numbers = {1, 2, 3}
```

Основное назначение:

- `dict` — быстрый доступ к значению по ключу;
- `set` — хранение уникальных элементов и операции над множествами.

# 29. Типичные ошибки

## Ошибка 1. Путать `{}` и `set()`

```python
empty = {}
```

Это словарь.

```python
empty = set()
```

Это множество.

---

## Ошибка 2. Обращаться к `set` по индексу

Так делать нельзя:

```python
numbers = {10, 20, 30}

print(numbers[0])
```

У множества нет обычной индексной адресации.

Если нужен доступ по позиции, используйте список:

```python
numbers = [10, 20, 30]
```

---

## Ошибка 3. Обращаться к отсутствующему ключу

```python
user = {
    "name": "Иван"
}

print(user["age"])
```

Возникнет `KeyError`.

Безопаснее:

```python
print(user.get("age"))
```

или:

```python
print(user.get("age", 0))
```

---

## Ошибка 4. Ожидать порядок элементов в `set`

Множество не следует использовать, когда порядок элементов имеет смысл.

Например:

```python
numbers = {3, 1, 2}
```

Не следует рассчитывать, что при выводе элементы обязательно будут представлены как:

```text
3, 1, 2
```

Если порядок важен, используйте `list`.
