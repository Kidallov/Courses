# Урок 6. Функции и замыкания в JavaScript

## 1. Объявление функций<!-- {"fold":true} -->

### Function Declaration
Это классический способ объявления функции с помощью ключевого слова `function`.

**Синтаксис:**
```javascript
function имяФункции(параметры) {
    // тело функции
    return результат;
}
```

**Особенности:**
- Поднимаются (hoisted) - можно вызывать до объявления
- Имеют собственный контекст `this`
- Имеют псевдомассив `arguments` - это специальный, **массивоподобный объект**, доступный внутри обычных (не стрелочных) функций, который содержит все значения аргументов, переданных при её вызове, независимо от того, были ли они объявлены в параметрах функции. Он позволяет работать с произвольным количеством аргументов, но не является настоящим массивом, так как не имеет методов типа push или filter, хотя имеет свойство length. 

### Основные характеристики `arguments`:
* **Содержит все аргументы:** Включает как переданные, так и пропущенные, доступные по индексу (например, arguments[0], arguments[1]).
* **Псевдомассив:** Похож на массив (индексы, length), но не имеет методов массивов, поэтому для их использования нужно преобразовывать его в настоящий массив, например, с помощью Array.from().
* **Доступен не во всех функциях:** Не работает в стрелочных функциях, где используется для работы с аргументами.
* **Устаревший способ:** Современная альтернатива — остаточные параметры (...args), которые предоставляют более удобный и гибкий подход к работе с переменным числом аргументов. 


**Пример:**
```javascript
// Можно вызвать до объявления (hoisting)
console.log(sum(5, 3)); // 8

function sum(a, b) {
    return a + b;
}

console.log(sum(10, 20)); // 30

// Основное использование arguments
function sumAll() {
    console.log('Количество аргументов:', arguments.length);
    console.log('Все аргументы:', arguments);
    console.log('Тип arguments:', typeof arguments);
    console.log('Это массив?', Array.isArray(arguments));

    let sum = 0;

    // arguments похож на массив, но это не массив
    // У него есть length и индексы, но нет методов массива
    for (let i = 0; i < arguments.length; i++) {
        sum += arguments[i];
    }

    return sum;
}

console.log(sumAll(1, 2, 3, 4, 5));
// Количество аргументов: 5
// Все аргументы: [Arguments] { '0': 1, '1': 2, '2': 3, '3': 4, '4': 5 }
// Тип arguments: object
// Это массив? false
// 15
```

### Function Expression
Функция, которая присваивается переменной или константе.

**Синтаксис:**
```javascript
const имяФункции = function(параметры) {
    // тело функции
    return результат;
};
```

**Особенности:**
- Не поднимаются - нельзя вызвать до присваивания
- Часто используются как callback-функции - функции, которые передаются как аргументы другим функциям и выполняются после завершения какой-либо асинхронной операции или действия, позволяя коду быть гибким и не блокировать выполнение. 

**Пример:**
```javascript
// Вызов до объявления вызовет ошибку

console.log(multiply(5, 3)); // Ошибка!

const multiply = function(a, b) {
    return a * b;
};

console.log(multiply(5, 3)); // 15

// Функция как callback
const numbers = [1, 2, 3, 4, 5];
const doubled = numbers.map(function(num) { // метод .map() создает новый
	// массив из полученных результатов, исходный массив не меняется
	// Функция возвращает новый массив с точно такой же длиной
    return num * 2;
});
console.log(doubled); // [2, 4, 6, 8, 10]
```

## 2. Стрелочные функции (Arrow Functions)<!-- {"fold":true} -->

Современный краткий синтаксис для создания функций.

**Синтаксис:**
```javascript
// Полная форма
const func = (параметры) => {
    return результат;
};

// Краткая форма (если тело состоит из одного выражения)
const func = (параметры) => выражение;

// Без параметров
const func = () => выражение;

// Один параметр (скобки можно опустить)
const func = параметр => выражение;
```

**Ключевые особенности:**
1. **Нет собственного `this`** - берет `this` из внешней области
2. **Нет псевдомассива `arguments`**
3. **Не могут быть конструкторами** - нельзя использовать с `new`
4. **Нет свойства `prototype`**
5. **Более короткий синтаксис**

**Примеры:**
```javascript
// Классическая функция
const add = function(a, b) {
    return a + b;
};

// Стрелочная функция
const addArrow = (a, b) => a + b;

console.log(add(5, 3)); // 8
console.log(addArrow(5, 3)); // 8

// Разница в this
const person = {
    name: 'Анна',
    // Обычная функция - свой this
    greet: function() {
        console.log('Привет, меня зовут ' + this.name);
    },
    // Стрелочная функция - берет this из внешней области
    greetArrow: () => {
        console.log('Привет, меня зовут ' + this.name); // undefined
    }
};

person.greet(); // Привет, меня зовут Анна
person.greetArrow(); // Привет, меня зовут undefined

// Удобство с методами массива
const numbers = [1, 2, 3, 4, 5];

// Function Expression
const squares = numbers.map(function(num) {
    return num * num;
});

// Стрелочная функция
const squaresArrow = numbers.map(num => num * num);

console.log(squares); // [1, 4, 9, 16, 25]
console.log(squaresArrow); // [1, 4, 9, 16, 25]
```

**Когда использовать стрелочные функции:**
- Callback-функции
- Короткие однострочные функции
- Когда нужно сохранить контекст `this` из внешней области

**Когда НЕ использовать стрелочные функции:**
- Методы объектов (если нужен доступ к `this` объекта)
- Функции, которым нужен `arguments`
- Обработчики событий (если нужен `this` на элемент)

## 3. Параметры и аргументы<!-- {"fold":true} -->

### Параметры по умолчанию
```javascript
function greet(name = 'Гость') {
    return `Привет, ${name}`;
}

console.log(greet()); // Привет, Гость
console.log(greet('Мария')); // Привет, Мария
```

### Rest параметры (`...`)
```javascript
function sumAll(...numbers) {
    return numbers.reduce((sum, num) => sum + num, 0);
	// 0 - значение, которое устанавливаем для sum
}

console.log(sumAll(1, 2, 3)); // 6
console.log(sumAll(1, 2, 3, 4, 5)); // 15
```

### Spread оператор
```javascript
const numbers = [1, 2, 3, 4, 5];

// Передача массива как отдельных аргументов
console.log(Math.max(...numbers)); // 5
console.log(Math.min(...numbers)); // 1
```

## 4. Замыкания и область видимости<!-- {"fold":true} -->

### Лексическое окружение (Lexical Environment)
Каждая функция при создании получает ссылку на внешнее лексическое окружение.

```javascript
let globalVar = 'Я глобальная';

function outer() {
    let outerVar = 'Я из outer';
    
    function inner() {
        let innerVar = 'Я из inner';
        console.log(globalVar); // Доступно
        console.log(outerVar); // Доступно
        console.log(innerVar); // Доступно
    }
    
    inner();
	console.log(innerVar); // Ошибка! innerVar не определена
}

outer();
console.log(outerVar); // Ошибка! outerVar не определена
```

### Замыкания (Closures)
Функция, которая запоминает свое лексическое окружение даже после того, как внешняя функция завершила выполнение.

**Простой пример:**
```javascript
function createCounter() {
    let count = 0; // Приватная переменная
    
    return function() {
        count++; // Замыкание сохраняет доступ к count
        return count;
    };
}

const counter1 = createCounter();
console.log(counter1()); // 1
console.log(counter1()); // 2
console.log(counter1()); // 3

const counter2 = createCounter();
console.log(counter2()); // 1 (новое замыкание, свой count)
```

**IIFE (Immediately Invoked Function Expression)**
```javascript
// Создание изолированной области видимости
(function() {
    const privateVar = 'Я приватная';
    console.log(privateVar); // Доступно
})();

console.log(privateVar); // Ошибка - не доступно

// IIFE с параметрами
const result = (function(a, b) {
    return a * b;
})(5, 3);

console.log(result); // 15
```

### Задание 1: Создание калькулятора
Создайте функцию-калькулятор, которая поддерживает:
- Сложение
- Вычитание
- Умножение
- Деление
- Хранение текущего результата
- Сброс результата к значению, которое было

###### **Решение:**<!-- {"fold":true} -->
```javascript
function Calculator(initialValue = 0) {
    let result = initialValue;
    
    return {
        add: function(num) {
            result += num;
            return this; // Для цепочки вызовов
        },
        
        subtract: function(num) {
            result -= num;
            return this;
        },
        
        multiply: function(num) {
            result *= num;
            return this;
        },
        
        divide: function(num) {
            if (num !== 0) {
                result /= num;
            } else {
                console.error('Деление на ноль!');
            }
            return this;
        },
        
        getResult: function() {
            return result;
        },
        
        reset: function() {
            result = initialValue;
            return this;
        }
    };
}

// Использование
const calc = Calculator(10);
console.log(calc.add(5).multiply(2).subtract(3).getResult()); // 27
```

### Задание 2: **Простая функция с кешированием**

Создайте функцию `rememberColor()`, которая запоминает любимый цвет для каждого имени.

**Требования:**
1. Функция должна принимать имя и цвет
2. Если для имени уже сохранен цвет - выводить его из памяти
3. Если цвета для имени нет - сохранять его
4. Добавить функцию для просмотра всех запомненных пар


###### **Решение:**<!-- {"fold":true} -->
```javascript
// 1. Создаем объект для хранения цветов (наша "память")
const colorMemory = {};

// 2. Функция для запоминания цветов
function rememberColor(name, color) {
    // Проверяем, знаем ли мы уже цвет для этого имени
    if (colorMemory[name]) {
        console.log(`Помню: ${name} любит ${colorMemory[name]}`);
    } else {
        // Если не знаем - запоминаем
        colorMemory[name] = color;
        console.log(`Запомнил: ${name} - ${color}`);
    }
}

// 3. Функция для показа всех запомненных цветов
function showAllColors() {
    console.log('Все запомненные цвета:');
    
    // Проходим по всем именам в памяти
    for (const name in colorMemory) {
        console.log(`${name}: ${colorMemory[name]}`);
    }
}

// 4. Функция для забытия цвета
function forgetColor(name) {
    if (colorMemory[name]) {
        console.log(`Забыл цвет для ${name}`);
        delete colorMemory[name];
    } else {
        console.log(`Не помню цвета для ${name}`);
    }
}

// Пример использования
console.log('=== Тестируем функцию ===');

rememberColor('Анна', 'синий');   // Запомнил: Анна - синий
rememberColor('Иван', 'красный');  // Запомнил: Иван - красный
rememberColor('Мария', 'зеленый'); // Запомнил: Мария - зеленый

console.log('\n--- Пробуем снова ---');
rememberColor('Анна', 'синий');    // Помню: Анна любит синий
rememberColor('Иван', 'красный');   // Помню: Иван любит красный

console.log('\n--- Новый человек ---');
rememberColor('Петр', 'желтый');    // Запомнил: Петр - желтый

console.log('\n--- Показываем все ---');
showAllColors();

console.log('\n--- Забываем кого-то ---');
forgetColor('Иван');
showAllColors();
```
