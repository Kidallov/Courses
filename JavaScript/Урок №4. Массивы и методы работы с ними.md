# Урок 4. Массивы и методы работы с ними
## Введение<!-- {"fold":true} -->

**Массив** — это упорядоченная коллекция данных, которая может содержать элементы любого типа: числа, строки, объекты, другие массивы и даже `null` или `undefined`. Массивы являются одним из самых часто используемых структур данных в JavaScript, поэтому умение эффективно с ними работать — ключевой навык.

## Создание массивов<!-- {"fold":true} -->

### 1. Литерал массива (современный и рекомендуемый способ)

```javascript
// Пустой массив
const emptyArray = [];

// Массив с числами
const numbers = [1, 2, 3, 4, 5];

// Массив со строками
const fruits = ['яблоко', 'банан', 'апельсин'];

// Массив с разными типами данных
const mixed = [1, 'hello', true, null, { name: 'John' }];

// Массив, содержащий другие массивы (многомерный массив)
const matrix = [[1, 2], [3, 4], [5, 6], mixed];
```

### 2. Конструктор Array (используется реже)

```javascript
// Создаст массив с n пустыми элементами
const arr1 = new Array(n);
console.log(arr1); // [ <5 empty items> ]

// Создаст массив с одним элементом - числом 5
const arr2 = new Array('5');
console.log(arr2); // ['5']

// Создаст массив с элементами 1, 2, 3
const arr3 = new Array(1, 2, 3);
console.log(arr3); // [1, 2, 3]
```

**Важный нюанс:** Использование `new Array()` с одним числовым аргументом создает массив с указанной длиной, но без элементов. Это может быть неочевидно и привести к ошибкам, поэтому предпочтительнее использовать литерал `[]`.

## Доступ к элементам и длина массива<!-- {"fold":true} -->

**Элементы в массиве нумеруются, начиная с нуля**

```javascript
const fruits = ['яблоко', 'банан', 'апельсин'];

console.log(fruits[0]); // 'яблоко'
console.log(fruits[1]); // 'банан'
console.log(fruits[2]); // 'апельсин'
console.log(fruits[3]); // undefined (элемента нет)

// Свойство length возвращает длину массива
console.log(fruits.length); // 3

// Последний элемент имеет индекс length - 1
console.log(fruits[fruits.length - 1]); // 'апельсин'
```

## Основные методы для работы с концом и началом массива<!-- {"fold":true} -->

Эти методы изменяют исходный массив (мутируют его).
Метод работает непосредственно с тем массивом, к которому он применен. 
После выполнения метода оригинальный массив изменяется.

### `push()` — добавить элемент в конец<!-- {"fold":true} -->

```javascript
const arr = [1, 2, 3];
arr.push(4);
console.log(arr); // [1, 2, 3, 4]

// Можно добавлять несколько элементов сразу
arr.push(5, 6, 7);
console.log(arr); // [1, 2, 3, 4, 5, 6, 7]

// Метод возвращает новую длину массива
const newLength = arr.push(8);
console.log(newLength); // 8
```

### `pop()` — удалить элемент с конца<!-- {"fold":true} -->

```javascript
const arr = [1, 2, 3];
const lastElement = arr.pop();

console.log(lastElement); // 3
console.log(arr); // [1, 2]
```

### `unshift()` — добавить элемент в начало<!-- {"fold":true} -->

```javascript
const arr = [2, 3];
arr.unshift(1);
console.log(arr); // [1, 2, 3]

// Можно добавлять несколько элементов
arr.unshift(-1, 0);
console.log(arr); // [-1, 0, 1, 2, 3]
```

### `shift()` — удалить элемент с начала<!-- {"fold":true} -->

```javascript
const arr = [1, 2, 3];
const firstElement = arr.shift();

console.log(firstElement); // 1
console.log(arr); // [2, 3]
```

**Нюанс:** Методы `pop()` и `shift()` для пустого массива возвращают `undefined`.

## Методы итерации (перебора)<!-- {"fold":true} -->

Эти методы не изменяют исходный массив (если не изменять элементы вручную), а возвращают новый массив или значение.
Про функции поговорим позже, когда будем проходить тему по ним.

### `map()` — трансформация каждого элемента<!-- {"fold":true} -->

Создает новый массив, применяя переданную функцию к каждому элементу исходного массива.

```javascript
const numbers = [1, 2, 3, 4];

// Умножить каждый элемент на 2
const doubled = numbers.map(num => num * 2);
console.log(doubled); // [2, 4, 6, 8]

// Преобразовать числа в строки
const stringNumbers = numbers.map(num => `Число: ${num}`);
console.log(stringNumbers); // ['Число: 1', 'Число: 2', 'Число: 3', 'Число: 4']

// Исходный массив не изменился
console.log(numbers); // [1, 2, 3, 4]
```

### `filter()` — фильтрация элементов<!-- {"fold":true} -->

Создает новый массив со всеми элементами, прошедшими проверку (условие), заданную в переданной функции.

```javascript
const numbers = [1, 2, 3, 4, 5, 6];

// Оставить только четные числа
const evenNumbers = numbers.filter(num => num % 2 === 0);
console.log(evenNumbers); // [2, 4, 6]

// Оставить только числа больше 3
const greaterThanThree = numbers.filter(num => num > 3);
console.log(greaterThanThree); // [4, 5, 6]
```

### `reduce()` — аккумулятор значений<!-- {"fold":true} -->

Применяет функцию к каждому элементу массива (слева направо), возвращая одно результирующее значение. Это самый мощный, но и самый сложный для понимания метод.

```javascript
const numbers = [1, 2, 3, 4];

// Сумма всех элементов
const sum = numbers.reduce((accumulator, currentValue) => {
  return accumulator + currentValue;
}, 0); // 0 — начальное значение accumulator
console.log(sum); // 10

// Разберем по шагам:
// Шаг 1: accumulator = 0, currentValue = 1 -> return 0 + 1 = 1
// Шаг 2: accumulator = 1, currentValue = 2 -> return 1 + 2 = 3
// Шаг 3: accumulator = 3, currentValue = 3 -> return 3 + 3 = 6
// Шаг 4: accumulator = 6, currentValue = 4 -> return 6 + 4 = 10

// Поиск максимального числа
const max = numbers.reduce((acc, current) => Math.max(acc, current), numbers[0]);
console.log(max); // 4

// Создание объекта с количеством каждого элемента
const fruits = ['яблоко', 'банан', 'яблоко', 'апельсин', 'банан', 'банан'];
const count = fruits.reduce((acc, fruit) => {
  acc[fruit] = (acc[fruit] || 0) + 1;
  return acc;
}, {});
console.log(count); // { яблоко: 2, банан: 3, апельсин: 1 }
```

## Срезы массивов<!-- {"fold":true} -->

### `slice()` — копирование части массива<!-- {"fold":true} -->

Возвращает новый массив, содержащий копию части исходного массива. **Исходный массив не изменяется.**

```javascript
const fruits = ['яблоко', 'банан', 'апельсин', 'киви', 'манго'];

// slice(start, end) — end не включается!
const citrus = fruits.slice(1, 3);
console.log(citrus); // ['банан', 'апельсин']

// Если указан только start, копируется до конца массива
const fromIndex2 = fruits.slice(2);
console.log(fromIndex2); // ['апельсин', 'киви', 'манго']

// Отрицательные индексы — отсчет с конца массива
const lastTwo = fruits.slice(-2);
console.log(lastTwo); // ['киви', 'манго']

// Копирование всего массива (поверхностная копия)
const fruitsCopy = fruits.slice();
console.log(fruitsCopy); // ['яблоко', 'банан', 'апельсин', 'киви', 'манго']

// Исходный массив не изменился
console.log(fruits); // ['яблоко', 'банан', 'апельсин', 'киви', 'манго']
```

### `splice()` — удаление или замена элементов<!-- {"fold":true} -->

Это мощный метод, который может **удалять, добавлять и заменять** элементы. **Он изменяет исходный массив.**

```javascript
let fruits = ['яблоко', 'банан', 'апельсин', 'киви'];

// Удалить 1 элемент, начиная с индекса 1
let removed = fruits.splice(1, 1);
console.log(removed); // ['банан'] (массив удаленных элементов)
console.log(fruits); // ['яблоко', 'апельсин', 'киви']

// Удалить 0 элементов и добавить 'лимон' на позицию 1
fruits = ['яблоко', 'банан', 'апельсин'];
removed = fruits.splice(1, 0, 'лимон');
console.log(removed); // [] (ничего не удалено)
console.log(fruits); // ['яблоко', 'лимон', 'банан', 'апельсин']

// Заменить 1 элемент на индексе 2 на два новых
fruits = ['яблоко', 'банан', 'апельсин'];
removed = fruits.splice(2, 1, 'киви', 'манго');
console.log(removed); // ['апельсин']
console.log(fruits); // ['яблоко', 'банан', 'киви', 'манго']
```

**Важное отличие:** `slice()` не меняет исходный массив, `splice()` — меняет.
