# Модули и библиотеки в JavaScript

**1. Что это такое?**
Представьте, что JavaScript — это набор инструментов. Базовые инструменты (циклы, переменные) у вас всегда под рукой. Но если вам нужны специфические инструменты (например, для сложных вычислений или работы с датами), вы открываете «ящик с инструментами» — это и есть **библиотеки** или **модули**.

**2. Зачем они нужны?**

* **Разделение кода:** Программа не превращается в один бесконечный файл.
* **Повторное использование:** Написали один раз класс для «Животного» — используете его во всех проектах.
* **Готовые решения:** Кто-то уже написал отличный код для анимации или работы с сервером за вас.

**3. Как это работает (основы)?**
В современном JS мы используем две главные команды:

* `export` — «выставляем» функцию или переменную наружу, чтобы другие файлы могли её увидеть.
* `import` — «забираем» нужную деталь в свой файл.

*Пример:*

```javascript
// файл math_utils.js
export const pi = 3.14;
export function double(n) { return n * 2; }

// файл main.js
import { pi, double } from './math_utils.js';
console.log(double(pi)); // 6.28

```

### Задачи для учеников

Вот 3 задачи, которые помогут закрепить теорию на практике:

#### Задача №1. «Библиотека приветствий» (Легкая)

**Задание:** Создайте файл `greetings.js`. В нем напишите и экспортируйте функцию `sayHello(name)`, которая возвращает строку "Привет, [имя]!". В основном файле `index.js` импортируйте эту функцию и вызовите её, передав своё имя.

* **Что проверяем:** Умение создавать именованный экспорт и правильно указывать путь к файлу при импорте.

#### Задача №2. «Математический модуль» (Средняя)

**Задание:** Создайте модуль `calculator.js`. Экспортируйте из него объект, в котором будут методы `add` (сложение) и `subtract` (вычитание). В основном файле импортируйте этот объект и выведите в консоль результат сложения 15 и 27.

* **Что проверяем:** Экспорт объектов и обращение к их методам после импорта.

#### Задача №3. «Внешняя библиотека (CDN)» (Интересная)

**Задание:** Подключите в HTML-файле через тег `<script>` библиотеку [Confetti.js](https://www.google.com/search?q=https://cdn.jsdelivr.net/npm/canvas-confetti%401.5.1/dist/confetti.browser.min.js). Напишите код, который при нажатии на кнопку на странице будет запускать салют из конфетти.

* **Что проверяем:** Понимание того, что библиотеки можно подключать не только файлами, но и по ссылке (CDN), и использовать их готовые функции (в данном случае функцию `confetti()`).
