# Урок 5. Объекты и коллекции

## 1. Создание объектов

### Что такое объект?<!-- {"fold":true} -->
Объект в JavaScript — это составной тип данных для хранения коллекции свойств в формате "ключ: значение". Ключи — строки (или символы), значения могут быть любого типа. Ключи всегда являются уникальными, значения - нет.

### Способы создания объектов

#### 1.1 Литерал объекта (самый простой и популярный)
```javascript
const user = {
  name: "Анна",
  age: 25,
  isAdmin: false
};
```

#### 1.2 Конструктор Object
```javascript
const car = new Object();
car.brand = "Toyota";
car.model = "Camry";
car.year = 2020;
```

#### 1.3 Разница между способами
```javascript
// Литерал объекта
const obj1 = { a: 1 }; // Более быстрый и читаемый

// Конструктор
const obj2 = new Object(); 
obj2.a = 1; // Медленнее, но иногда полезен
```

## 2. Свойства и методы объектов

### 2.1 Свойства объектов
Свойства — это пары ключ-значение внутри объекта.

```javascript
const book = {
  title: "JavaScript для начинающих",
  author: "Иван Петров",
  pages: 350,
  "year of publication": 2023, // Ключ с пробелами в кавычках
  isAvailable: true
};
```

#### Доступ к свойствам:
```javascript
// Точечная нотация (основной способ)
console.log(book.title); // "JavaScript для начинающих"

// Скобочная нотация (для динамических ключей или ключей с пробелами)
console.log(book["author"]); // "Иван Петров"
console.log(book["year of publication"]); // 2023

// Динамический доступ
const propertyName = "pages";
console.log(book[propertyName]); // 350
```

### 2.2 Методы объектов
Методы — это свойства-функции.

```javascript
const calculator = {
  // Свойство
  brand: "Engineering Corp",
  
  // Метод (старый синтаксис)
  add: function(a, b) {
    return a + b;
  },
  
  // Метод (новый синтаксис ES6)
  multiply(a, b) {
    return a * b;
  },
  
  // Метод, использующий другие свойства объекта
  getBrand() {
    return this.brand;
  }
};

// Вызов методов
console.log(calculator.add(5, 3)); // 8
console.log(calculator.getBrand()); // "Engineering Corp"
```

### 2.3 Ключевое слово `this`
`this` ссылается на объект, к которому принадлежит метод.

```javascript
const person = {
  firstName: "Иван",
  lastName: "Петров",
  
  // Метод, использующий this
  getFullName() {
    return this.firstName + " " + this.lastName;
  },
  
  // Метод с вложенной функцией (проблема с this)
  getFullNameWrong() {
   function helper() {
      // Здесь this НЕ ссылается на person!
      return this.firstName + " " + this.lastName;
    }
    return helper(); // Вернет undefined undefined
  }
};

console.log(person.getFullName()); // "Иван Петров"
```

### 2.4 Основные операции с объектами

#### Добавление и изменение свойств:
```javascript
const student = { 
  name: "Алексей",
  age: 20
};

// Добавление нового свойства
student.course = 3;

// Изменение существующего свойства
student.age = 21;

// Добавление метода
student.introduce = function() {
  return "Меня зовут " + this.name;
};
```

#### Удаление свойств:
```javascript
delete student.age; // удаляет свойство age
console.log(student.age); // undefined
```

#### Проверка существования свойства:
```javascript
// Оператор in (проверяет ключ в объекте)
console.log("name" in student); // true
```

### 2.5 Перебор свойств объекта

```javascript
const product = {
  id: 1,
  name: "Ноутбук",
  price: 50000,
  inStock: true
};

// 1. for...in (перебирает все перечисляемые свойства)
for (let key in product) {
  console.log(`${key}: ${product[key]}`);
}

// 2. Object.keys() - массив ключей
const keys = Object.keys(product);
console.log(keys); // ["id", "name", "price", "inStock"]

// 3. Object.values() - массив значений
const values = Object.values(product);
console.log(values); // [1, "Ноутбук", 50000, true]

// 4. Object.entries() - массив пар [ключ, значение]
const entries = Object.entries(product);
console.log(entries); 
// [["id", 1], ["name", "Ноутбук"], ["price", 50000], ["inStock", true]]
```

## 3. Работа с массивами объектов

Массивы объектов — очень распространенная структура данных.

### 3.1 Создание массива объектов
```javascript
const students = [
  { id: 1, name: "Анна", age: 20, course: 2 },
  { id: 2, name: "Иван", age: 21, course: 3 },
  { id: 3, name: "Мария", age: 19, course: 1 },
  { id: 4, name: "Алексей", age: 22, course: 4 }
];
```

### 3.2 Доступ к свойствам объектов в массиве
```javascript
// К первому объекту
console.log(students[0]); // { id: 1, name: "Анна", age: 20, course: 2 }
console.log(students[0].name); // "Анна"
console.log(students[0]["age"]); // 20

// Ко второму объекту
console.log(students[1].course); // 3
```

### 3.3 Методы массивов для работы с объектами

#### forEach - перебор всех элементов
```javascript
students.forEach(function(student) {
  console.log(student.name, "-", student.age, "лет");
});
```

#### map - создание нового массива на основе существующего
```javascript
// Массив имен всех студентов
const names = students.map(function(student) {
  return student.name;
});
console.log(names); // ["Анна", "Иван", "Мария", "Алексей"]

// Массив объектов с дополнительным свойством
const studentsWithStatus = students.map(function(student) {
  return {
    name: student.name,
    age: student.age,
    isAdult: student.age >= 21
  };
});
```

#### filter - фильтрация по условию
```javascript
// Студенты старше 20 лет
const olderStudents = students.filter(function(student) {
  return student.age > 20;
});
console.log(olderStudents); // [{ id: 2, ... }, { id: 4, ... }]

// Студенты 2 курса
const secondCourse = students.filter(function(student) {
  return student.course === 2;
});
```

#### find - поиск первого подходящего элемента
```javascript
// Найти студента с id = 3
const student = students.find(function(item) {
  return item.id === 3;
});
console.log(student); // { id: 3, name: "Мария", age: 19, course: 1 }
```

#### some - проверка, есть ли хотя бы один подходящий элемент
```javascript
// Есть ли студенты 4 курса?
const hasFourthCourse = students.some(function(student) {
  return student.course === 4;
});
console.log(hasFourthCourse); // true
```

#### every - проверка, что все элементы подходят под условие
```javascript
// Все ли студенты старше 18?
const allAdults = students.every(function(student) {
  return student.age > 18;
});
console.log(allAdults); // true
```

#### reduce - агрегация данных
```javascript
// Сумма возрастов всех студентов
const totalAge = students.reduce(function(sum, student) {
  return sum + student.age;
}, 0);
console.log(totalAge); // 82

// Самый старший студент
const oldestStudent = students.reduce(function(oldest, student) {
  return student.age > oldest.age ? student : oldest;
}, students[0]);
console.log(oldestStudent.name); // "Алексей"
```

#### sort - сортировка массива объектов
```javascript
// Сортировка по возрасту (по возрастанию)
const sortedByAge = [...students].sort(function(a, b) {
  return a.age - b.age;
});

// Сортировка по имени (алфавитная)
const sortedByName = [...students].sort(function(a, b) {
  return a.name.localeCompare(b.name);
});

// Сортировка по курсу (по убыванию), затем по возрасту
const complexSort = [...students].sort(function(a, b) {
  if (a.course === b.course) {
    return b.age - a.age;
  }
  return b.course - a.course;
});
```

**Важный нюанс**: Метод `sort` изменяет исходный массив! Используйте копирование:

```javascript
// ПЛОХО: изменяет исходный массив
students.sort((a, b) => a.age - b.age);

// ХОРОШО: создает копию
const sorted = [...students].sort((a, b) => a.age - b.age);
```

## 4. Деструктуризация объектов

Деструктуризация позволяет извлекать значения из объектов в отдельные переменные.

### 4.1 Базовая деструктуризация
```javascript
const person = {
  firstName: "Иван",
  lastName: "Петров",
  age: 30
};

// Извлечение свойств в переменные
const { firstName, lastName, age } = person;
console.log(firstName); // "Иван"
console.log(age); // 30
```

### 4.2 Деструктуризация с переименованием
```javascript
const { firstName: name, age: years } = person;
console.log(name); // "Иван" (переменная name вместо firstName)
console.log(years); // 30 (переменная years вместо age)
```

### 4.3 Значения по умолчанию
```javascript
const { firstName, middleName = "Сергеевич", age } = person;
console.log(middleName); // "Сергеевич" (значение по умолчанию)
```

### 4.4 Комбинирование: переименование + значение по умолчанию
```javascript
const { firstName: name = "Гость", age: years = 18 } = person;
console.log(name); // "Иван"
console.log(years); // 30
```

### 4.5 Вложенная деструктуризация
```javascript
const employee = {
  name: "Анна",
  position: "developer",
  address: {
    city: "Москва",
    street: "Тверская",
    house: 15
  }
};

// Деструктуризация вложенного объекта
const { 
  name, 
  address: { 
    city, 
    street 
  } 
} = employee;

console.log(name); // "Анна"
console.log(city); // "Москва"
console.log(street); // "Тверская"
// console.log(address); // ОШИБКА! address не определена
```

### 4.6 Деструктуризация нескольких уровней с сохранением объекта
```javascript
const { 
  name, 
  address: { 
    city, 
    street 
  },
  address // получаем и весь объект address
} = employee;

console.log(address); // { city: "Москва", street: "Тверская", house: 15 }
```

### 4.7 Rest-оператор при деструктуризации
```javascript
const { name, ...rest } = employee;
console.log(name); // "Анна"
console.log(rest); // { position: "developer", address: {...} }
```

### 4.8 Деструктуризация в циклах
```javascript
const users = [
  { id: 1, name: "Анна", age: 25 },
  { id: 2, name: "Иван", age: 30 },
  { id: 3, name: "Мария", age: 22 }
];

// Деструктуризация в for...of
for (const { name, age } of users) {
  console.log(`${name} - ${age} лет`);
}

// Деструктуризация в forEach
users.forEach(function({ name, id }) {
  console.log(`ID: ${id}, Имя: ${name}`);
});
```

### 4.9 Полезные примеры деструктуризации

#### Пример 1: Обмен значений переменных
```javascript
let a = 5;
let b = 10;

// Без деструктуризации
let temp = a;
a = b;
b = temp;

// С деструктуризацией
[a, b] = [b, a];
```

#### Пример 2: Работа с возвращаемым объектом
```javascript
// Предположим, есть функция (еще не изучали, но скоро изучим)
// которая возвращает объект
function getUserData() {
  return { firstName: "Иван", lastName: "Петров", age: 30 };
}

// Получаем только нужные свойства
const { firstName, age } = getUserData();
```

#### Пример 3: Деструктуризация с вычисляемыми именами свойств
```javascript
const propName = "age";
const { [propName]: userAge } = person;
console.log(userAge); // 30
```
