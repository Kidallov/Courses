# Урок №8. Работа с DOM.

## Что такое DOM?<!-- {"fold":true} -->
`DOM (Document Object Model)` — это программный интерфейс (API) для HTML и XML документов. Он представляет структуру документа в виде дерева объектов, где каждый узел — это часть документа (элемент, атрибут, текст и т.д.).

`API` - набор правил и механизмов, позволяющих двум или более компьютерным программам взаимодействовать друг с другом и обмениваться данными.

## Методы работы JavaScript с браузером.<!-- {"fold":true} -->

### `document.getElementById('myId')`<!-- {"fold":true} -->

#### **Назначение:**
Получает **один элемент** по его уникальному `id` атрибуту.

#### **Синтаксис:**
```javascript
const element = document.getElementById('idName');
```

#### **Особенности:**
- **Возвращает**: Один `Element` или `null`, если элемент не найден
- **Поиск**: Только в пределах всего документа
- **Производительность**: Самый быстрый метод поиска
- **ID должен быть уникальным** на странице, или возвращает первый найденный элемент.

#### **Пример:**
```html
<div id="header">Заголовок</div>
<div id="content">Контент</div>

<script>
    const header = document.getElementById('header');
    console.log(header); // <div id="header">Заголовок</div>
    console.log(header.textContent); // "Заголовок"
    
    const notExist = document.getElementById('footer');
    console.log(notExist); // null
</script>
```

#### **Важные нюансы:**
- Не требует символа `#` перед id
- Чувствителен к регистру: `getElementById('myId')` ≠ `getElementById('MyId')`

### `document.getElementsByClassName('myClass')`<!-- {"fold":true} -->

#### **Назначение:**
Получает **коллекцию элементов** по имени класса.

#### **Синтаксис:**
```javascript
const elements = document.getElementsByClassName('className');
// Можно искать несколько классов
const elements = document.getElementsByClassName('class1 class2');
```

#### **Особенности:**
- **Возвращает**: HTMLCollection элементов
- **HTMLCollection**: Массивоподобный объект, но не настоящий массив

#### **Пример:**
```html
<div class="item">Первый</div>
<div class="item active">Второй</div>
<span class="item">Третий</span>

<script>
    const items = document.getElementsByClassName('item');
    console.log(items.length); // 3
    
    // HTMLCollection можно перебирать
    for (let i = 0; i < items.length; i++) {
        console.log(items[i].textContent);
    }
    
    // Поиск по нескольким классам
    const activeItems = document.getElementsByClassName('item active');
    console.log(activeItems.length); // 1 (только второй div)
</script>
```

#### **Работа с HTMLCollection:**
```javascript
const elements = document.getElementsByClassName('myClass');

// Доступ по индексу
const firstElement = elements[0];

// Перебор
for (let i = 0; i < elements.length; i++) {
    console.log(elements[i]);
}

// Преобразование в массив
const array = Array.from(elements);
const array2 = [...elements];
```

### `document.getElementsByTagName('div')`<!-- {"fold":true} -->

#### **Назначение:**
Получает **коллекцию элементов** по имени тега.

#### **Синтаксис:**
```javascript
const elements = document.getElementsByTagName('tagName');
// Специальный селектор
const allElements = document.getElementsByTagName('*');
```

#### **Особенности:**
- **Возвращает**: HTMLCollection
- **Регистр**: В HTML не чувствителен к регистру, в XML - чувствителен
- **Можно искать все элементы**: `'*'`

#### **Пример:**
```html
<div>Первый div</div>
<p>Параграф</p>
<div>Второй div</div>
<span>Span</span>

<script>
    const divs = document.getElementsByTagName('div');
    console.log(divs.length); // 2
    
    const paragraphs = document.getElementsByTagName('p');
    console.log(paragraphs.length); // 1
    
    // Все элементы на странице
    const allElements = document.getElementsByTagName('*');
    console.log(allElements.length); // Количество всех элементов
    
    // Поиск внутри конкретного элемента
    const container = document.getElementById('container');
    const innerDivs = container.getElementsByTagName('div');
</script>
```

#### **Важные моменты:**
```javascript
// Работа с конкретным элементом
const container = document.querySelector('.container');
const buttons = container.getElementsByTagName('button');
```

### `document.querySelector('.myClass')`<!-- {"fold":true} -->

#### **Назначение:**
Получает **первый элемент**, соответствующий CSS-селектору.

#### **Синтаксис:**
```javascript
const element = document.querySelector('cssSelector');
```

#### **Особенности:**
- **Возвращает**: Один `Element` или `null`
- **Селекторы**: Поддерживает любые CSS-селекторы

#### **Примеры селекторов:**
```javascript
// По классу
const el1 = document.querySelector('.myClass');

// По ID
const el2 = document.querySelector('#myId');

// По тегу
const el3 = document.querySelector('div');

// По атрибуту
const el4 = document.querySelector('[data-test]');
const el5 = document.querySelector('[type="submit"]');

// Комбинированные
const el6 = document.querySelector('div.item.active');
const el7 = document.querySelector('form > input[name="email"]');

// Псевдоклассы
const el8 = document.querySelector('li:first-child');
const el9 = document.querySelector('input:checked');
```

#### **Пример использования:**
```html
<div class="item">Первый</div>
<div class="item active">Второй</div>
<div class="item">Третий</div>

<script>
    // Возвращает первый элемент с классом .item
    const firstItem = document.querySelector('.item');
    console.log(firstItem.textContent); // "Первый"
    
    // Возвращает первый элемент с классом .active
    const activeItem = document.querySelector('.active');
    console.log(activeItem.textContent); // "Второй"
    
    // Сложный селектор
    const item = document.querySelector('div.item.active');
    console.log(item.textContent); // "Второй"
    
    // Если элемент не найден
    const notFound = document.querySelector('.non-existent');
    console.log(notFound); // null
</script>
```

### `document.querySelectorAll('div.items')`<!-- {"fold":true} -->

#### **Назначение:**
Получает **все элементы**, соответствующие CSS-селектору.

#### **Синтаксис:**
```javascript
const elements = document.querySelectorAll('cssSelector');
```

#### **Особенности:**
- **Возвращает**: **Статическую** NodeList элементов
- **NodeList**: Массивоподобный объект с методами для перебора
- **Поддерживает forEach()**: В отличие от HTMLCollection

#### **Пример:**
```html
<div class="item">Первый</div>
<div class="item active">Второй</div>
<span class="item">Третий</span>
<div class="item active">Четвертый</div>

<script>
    // Все элементы с классом .item
    const allItems = document.querySelectorAll('.item');
    console.log(allItems.length); // 4
    
    // Только div с классом .item
    const divItems = document.querySelectorAll('div.item');
    console.log(divItems.length); // 3
    
    // Элементы с двумя классами
    const activeItems = document.querySelectorAll('.item.active');
    console.log(activeItems.length); // 2
</script>
```

#### **Работа с NodeList:**<!-- {"fold":true} -->
```javascript
const elements = document.querySelectorAll('.myClass');

// Доступ по индексу
const first = elements[0];

// Длина коллекции
console.log(elements.length);

// Перебор (NodeList имеет forEach)
elements.forEach(element => {
    console.log(element.textContent);
});

// Преобразование в массив
const array1 = Array.from(elements);
const array2 = [...elements];

// for...of тоже работает
for (const element of elements) {
    console.log(element);
}

// Статичность демонстрация:
const items = document.querySelectorAll('.item');
console.log(items.length); // 2

// Добавляем новый элемент
document.body.innerHTML += '<div class="item">Новый</div>';
console.log(items.length); // 2 (не изменилось!)
```

## **Сравнительная таблица методов:**<!-- {"fold":true} -->

| Метод                      | Возвращает     | "Живая" коллекция | Скорость      | Особенности               |
|----------------------------|----------------|-------------------|---------------|---------------------------|
| `getElementById()`         | Один Element   | Нет               | Самый быстрый | Только по ID              |
| `getElementsByClassName()` | HTMLCollection | Да                | Быстро        | По классам                |
| `getElementsByTagName()`   | HTMLCollection | Да                | Быстро        | По тегам                  |
| `querySelector()`          | Один Element   | Нет               | Средне        | Любой CSS-селектор        |
| `querySelectorAll()`       | NodeList       | Нет               | Медленно      | Все элементы по селектору |

### 
## **Практические рекомендации:**

#### **Когда что использовать:**<!-- {"fold":true} -->
1. **`getElementById()`** - когда нужен один элемент по уникальному `id`
2. **`getElementsByClassName()`** - когда нужны все элементы класса и важна "живая" коллекция
3. **`querySelector()`** - для сложных селекторов или когда нужен первый элемент
4. **`querySelectorAll()`** - для сложных селекторов или когда нужно работать с forEach

**Описание:** Создайте кнопку, которая переключает между светлой и темной темой на странице.

2. **Реализовать переключение темы**:
   - При клике на кнопку:
     - Если тема светлая: переключить на темную
     - Если тема темная: переключить на светлую
   - Менять класс у body между `light` и `dark`

3. **Обновлять текст кнопки**:
   - При светлой теме: "Переключить на темную тему"
   - При темной теме: "Переключить на светлую тему"
