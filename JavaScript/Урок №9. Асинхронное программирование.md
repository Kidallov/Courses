
# Асинхронное программирование в JavaScript

## Зачем нужна асинхронность?<!-- {"fold":true} -->
JavaScript — **однопоточный** язык. Это значит, что он может выполнять только одну задачу в конкретный момент времени. Если мы запустим тяжелую операцию (например, запрос к серверу) синхронно, интерфейс сайта «замрет» до получения ответа.
Асинхронность позволяет инициировать действие и продолжить выполнение другого кода, не дожидаясь завершения этого действия.

## Callback-функции<!-- {"fold":true} -->
Исторически это был первый способ работы с асинхронностью. 
**Callback** — это функция, которая передается в другую функцию в качестве аргумента и вызывается по завершении операции.

```javascript
loadData(() => {
    console.log("Логика после загрузки"); // этот код выполнится после нашей функции
});

function loadData(callback) { // callback функция, так как принимает на вход другую функцию
    setTimeout(() => {
        console.log("Данные загружены"); // выполняется сначала этот код
        callback();
    }, 2000); // ждем две секунды, потом выполняем код
}
```

### Пошаговая хронология<!-- {"fold":true} -->
1. **0 сек:** Вызывается loadData. Внутри нее запускается таймер setTimeout. Программа не «засыпает», она идет дальше, если есть другой код.
2. **... (ожидание) ...**
3. **2 сек:** Таймер срабатывает. Выполняется тело функции внутри setTimeout.
4. В консоли появляется: Данные загружены.
5. Сразу после этого вызывается callback(), который мы передали при старте.
6. В консоли появляется: Логика после загрузки.

### Проблема: Callback Hell<!-- {"fold":true} -->
Когда одна асинхронная операция зависит от другой, код начинает расти «вправо», становясь нечитаемым.

```javascript
getData(res => {
	getMoreData(res, res2 => {
		getEvenMoreData(res2, res3 => {
			// Это называется пирамидой погибели (Pyramid of Doom)
		});
	});
});
```

## Promise<!-- {"fold":true} -->
Промис — это объект-обещание. Он представляет результат асинхронной операции, который будет доступен «когда-то» в будущем.

**Состояния промиса:**
1. **Pending** (Ожидание) — начальное состояние.
2. **Fulfilled** (Выполнено) — операция завершена успешно.
3. **Rejected** (Отклонено) — произошла ошибка.

⠀**Пример создания:**
```javascript
const unstablePromise = new Promise((resolve, reject) => {
  console.log("Соединение с сервером...");

  setTimeout(() => {
    const isSuccess = Math.random() > 0.5; // Генерируем случайное true или false

    if (isSuccess) {
      resolve("🎉 Данные успешно получены!");
    } else {
      reject("❌ Ошибка: Сервер временно недоступен");
    }
  }, 1500); // Имитируем задержку в 1.5 секунды
});

// Запускаем и смотрим результат
unstablePromise
  .then(data => console.log(data))
  .catch(err => console.error(err))
  .finally(() => console.log("🔌 Сессия завершена"));
```

## Async / Await<!-- {"fold":true} -->
Это современный «синтаксический сахар» над промисами, который делает асинхронный код похожим на синхронный.

**Синтаксический сахар** — это специальные возможности синтаксиса языка программирования, которые делают код более читаемым, кратким и удобным для человека, не меняя при этом логику программы.

* `async` перед функцией заставляет её всегда возвращать промис.
* `await` можно использовать только внутри `async-функции`. Он останавливает выполнение до тех пор, пока промис не исполнится.

```javascript
async function showData() {
	try {
		const data = await myPromise; // Ждем выполнения
		console.log(data);
	} catch (error) {
		console.error("Поймали ошибку:", error);
	}
}
```

## Fetch API<!-- {"fold":true} -->
`fetch()` — это встроенный в браузер метод для отправки сетевых запросов. 
Он всегда возвращает промис.

**Стандартный шаблон запроса:**
```javascript
async function getUser() {
	try {
		const response = await fetch('https://jsonplaceholder.typicode.com/users/1');

		if (!response.ok) {
			throw new Error("Ошибка сети");
		}

		const user = await response.json(); // Превращаем ответ в объект JS
		console.log(user.name);
	} catch (err) {
		console.log("Ошибка запроса:", err);
	}
}

getUser();
```

## Сводная таблица<!-- {"fold":true} -->
| **Метод** | **Плюсы** | **Минусы** |
|---|---|---|
| **Callbacks** | Простота в базе | Трудно читать (Callback Hell) |
| **Promises** | Цепочки .then(), лучше обработка ошибок | Всё еще много шаблонного кода |
| **Async/Await** | Чистый, лаконичный код, легко отлаживать | Требует понимания работы промисов |

## Практическое задание<!-- {"fold":true} -->

Попробуйте использовать `fetch` вместе с `async/await`, чтобы получить список постов с ресурса https://jsonplaceholder.typicode.com/posts и вывести заголовки первых 5 постов в консоль.

##### Решение<!-- {"fold":true} -->
```javascript
async function getUser() {
    
    try {
        
        for (let i = 1; i <= 5; i++) {
            const response = await fetch('https://jsonplaceholder.typicode.com/posts/' + i);
            
            if (!response.ok) {
                throw new Error("Ошибка сети");
            }

            const user = await response.json();
            console.log(`ID ${i}: ${user.title}`);
        }
        
    
    } catch (err) {
        console.log("Ошибка запроса:", err);
    }
}
```
