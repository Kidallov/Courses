# Урок 2. Условные операторы и логические конструкции

## Цель урока
Научиться управлять потоком выполнения программы с помощью условий, понимать и использовать логические операторы, а также различать **truthy** и **falsy** значения в JavaScript.

---

## 1. Условные операторы<!-- {"fold":true} -->

Условные операторы позволяют выполнять разные участки кода в зависимости от выполнения определенных условий. Это основа для принятия решений в программе.

### 1.1. Конструкция `if`

Оператор `if` выполняет блок кода, если условие в скобках истинно (true).

**Синтаксис:**
```javascript
if (условие) {
  // код, выполняемый, если условие истинно
}
```

**Пример:**
```javascript
let temperature = 25;

if (temperature > 20) {
  console.log("На улице тепло. Можно идти в футболке.");
}
// Выведет: "На улице тепло. Можно идти в футболке."
```

### 1.2. Конструкция `if...else`

Оператор `else` добавляет блок кода, который выполнится, если условие ложно (false).

**Синтаксис:**
```javascript
if (условие) {
  // код, если условие истинно
} else {
  // код, если условие ложно
}
```

**Пример:**
```javascript
let age = 16;

if (age >= 18) {
  console.log("Вы совершеннолетний.");
} else {
  console.log("Вы несовершеннолетний.");
}
// Выведет: "Вы несовершеннолетний."
```

### 1.3. Конструкция `else if`

Для проверки нескольких условий подряд используется `else if`.

**Синтаксис:**
```javascript
if (условие1) {
  // код, если условие1 истинно
} else if (условие2) {
  // код, если условие2 истинно (а условие1 - ложно)
} else {
  // код, если все предыдущие условия ложны
}
```

**Пример:**
```javascript
let time = 14;

if (time < 12) {
  console.log("Доброе утро!");
} else if (time < 18) {
  console.log("Добрый день!");
} else {
  console.log("Добрый вечер!");
}
// Выведет: "Добрый день!"
```

**Важный нюанс:** Как только одно из условий оказывается истинным, блоки `else if` и `else` ниже — **игнорируются**.

## 2. Логические операторы (`&&`, `||`, `!`)<!-- {"fold":true} -->

Логические операторы используются для комбинации или инверсии булевых (логических) значений.

### 2.1. Логическое И (`&&`)

Возвращает `true`, если **оба** или более операнда истинны.

```javascript
console.log(true && true);   // true
console.log(true && false);  // false
console.log(false && true);  // false
console.log(false && false); // false
```

**Практический пример:**
```javascript
let hasTicket = true;
let hasPassport = true;

if (hasTicket && hasPassport) {
  console.log("Можете пройти на посадку в самолет.");
} else {
  console.log("Вы не можете лететь.");
}
// Выведет: "Можете пройти на посадку в самолет."
```

### 2.2. Логическое ИЛИ (`||`)

Возвращает `true`, если **хотя бы один** из операндов истинен.

```javascript
console.log(true || true);   // true
console.log(true || false);  // true
console.log(false || true);  // true
console.log(false || false); // false
```

**Практический пример:**
```javascript
let isWeekend = true;
let isHoliday = false;

if (isWeekend || isHoliday) {
  console.log("Можно выспаться!");
} else {
  console.log("Пора на работу.");
}
// Выведет: "Можно выспаться!"
```

### 2.3. Логическое НЕ (`!`)

Инвертирует булево значение: `true` становится `false`, а `false` — `true`.

```javascript
console.log(!true);  // false
console.log(!false); // true
```

**Практический пример:**
```javascript
let isRaining = true;

if (!isRaining) {
  console.log("Зонтик не нужен.");
} else {
  console.log("Лучше взять зонтик.");
}
// Выведет: "Лучше взять зонтик."
```

## 3. Тернарный оператор<!-- {"fold":true} -->

Это короткий синтаксис для простого условия `if...else`.

**Синтаксис:**
`условие ? выражениеЕслиИстина : выражениеЕслиЛожь`

**Пример:**
```javascript
let balance = 100;
let message = balance > 0 ? "На счету есть деньги" : "Счет пуст";
console.log(message); // "На счету есть деньги"
```

Это эквивалентно:
```javascript
let balance = 100;
let message;
if (balance > 0) {
  message = "На счету есть деньги";
} else {
  message = "Счет пуст";
}
console.log(message); // "На счету есть деньги"
```

**Особенность:** Тернарный оператор *возвращает значение*, поэтому его результат можно сразу присвоить переменной или использовать в выражении.

## 4. Конструкция `switch/case`<!-- {"fold":true} -->

Используется когда нужно сравнить одно значение со множеством вариантов. Она часто читается легче, чем длинная цепочка `if...else if`.

**Синтаксис:**
```javascript
switch (выражение) {
  case значение1:
    // код, если выражение === значение1
    break;
  case значение2:
    // код, если выражение === значение2
    break;
  // ...
  default:
    // код, если ни один case не подошел
}
```

**Пример:**
```javascript
let dayOfWeek = 3;
let dayName;

switch (dayOfWeek) {
  case 1:
    dayName = "Понедельник";
    break;
  case 2:
    dayName = "Вторник";
    break;
  case 3:
    dayName = "Среда";
    break;
  case 4:
    dayName = "Четверг";
    break;
  case 5:
    dayName = "Пятница";
    break;
  default:
    dayName = "Выходной день";
}
console.log(dayName); // "Среда"
```

**Ключевые моменты:**
- Сравнение в `case` является **строгим** (`===`).
- Ключевое слово `break` критически важно. Если его забыть, выполнение "провалится" на следующий `case`, даже если его условие не совпадает.
- Блок `default` выполняется, если ни один `case` не совпал. Он не является обязательным.

## 5. Truthy и Falsy значения<!-- {"fold":true} -->

В JavaScript любое значение можно привести к булеву типу (`true` или `false`). Это особенно важно в условиях.

### 5.1. Falsy значения
Это значения, которые при приведении к булевому типу становятся `false`. Их **всего 6**:
1. `false`
2. `0`
3. `""` или `''` (пустая строка)
4. `null`
5. `undefined`
6. `NaN`

**Пример:**
```javascript
if ("") {
  console.log("Это никогда не выполнится");
}
if (0) {
  console.log("И это тоже никогда не выполнится");
}
```

### 5.2. Truthy значения
Это **все остальные** значения, которые не являются falsy. Они приводятся к `true`.
- `"hello"` (непустая строка)
- `42` (любое ненулевое число)
- `[]` (пустой массив)
- `{}` (пустой объект)
- `function() {}` (любая функция)

**Пример:**
```javascript
if ("Hello") {
  console.log("Это выполнится, потому что строка не пустая");
}
if ([]) {
  console.log("И это выполнится, пустой массив - truthy значение!");
}
```

**Практическое применение:** Проверка на существование переменной.
```javascript
let userName = "";

// Не очень хорошая проверка, т.к. пустая строка - falsy
if (userName) {
  console.log(`Привет, ${userName}!`);
} else {
  console.log("Пожалуйста, введите свое имя.");
}
// Выведет: "Пожалуйста, введите свое имя."
```

### Задание 1: "Калькулятор скидки"
Напишите программу, которая рассчитывает конечную цену товара с учетом скидки.
- Если сумма покупки больше 1000 рублей, скидка 10%.
- Если сумма покупки больше 5000 рублей, скидка 20%.
- Выведите в консоль исходную сумму, размер скидки и итоговую сумму.

**Решение (пример):**
```javascript
let purchaseAmount = 6000;
let discount;
let finalAmount;

if (purchaseAmount > 5000) {
  discount = purchaseAmount * 0.2;
} else if (purchaseAmount > 1000) {
  discount = purchaseAmount * 0.1;
} else {
  discount = 0;
}

finalAmount = purchaseAmount - discount;

console.log(`Исходная сумма: ${purchaseAmount} руб.`);
console.log(`Скидка: ${discount} руб.`);
console.log(`Итоговая сумма: ${finalAmount} руб.`);
```

### Задание 2: "Определение времени суток"
Напишите программу, которая принимает число (от 0 до 23) и с помощью конструкции `switch` сообщает:
- "Ночь" (0-5)
- "Утро" (6-11)
- "День" (12-17)
- "Вечер" (18-23)

**Решение (пример):**
```javascript
let hour = 14;

switch (true) { // Нестандартный, но рабочий подход
  case (hour >= 0 && hour <= 5):
    console.log("Ночь");
    break;
  case (hour >= 6 && hour <= 11):
    console.log("Утро");
    break;
  case (hour >= 12 && hour <= 17):
    console.log("День");
    break;
  case (hour >= 18 && hour <= 23):
    console.log("Вечер");
    break;
  default:
    console.log("Некорректное время");
}
// Или через if...else if, что в данном случае логичнее.
```
