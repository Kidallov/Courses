## Лекция: Основы ООП в JavaScript

### 1. Что такое ООП?

**Объектно-ориентированное программирование (ООП)** — это подход, при котором программа рассматривается как набор **объектов**, взаимодействующих друг с другом.

* **Класс** — это «чертеж» или шаблон (например, чертеж машины).
* **Объект (Экземпляр)** — это реальная вещь, созданная по чертежу (конкретная красная машина у вас во дворе).

---

### 2. Классы и Конструктор

В JS класс объявляется ключевым словом `class`. Внутри него всегда есть метод `constructor` — он выполняется автоматически в момент создания объекта.

```javascript
class Animal {
  constructor(name, age) {
    this.name = name; // Свойство объекта
    this.age = age;
  }

  // Метод (функция внутри класса)
  sayHi() {
    console.log(`Привет, меня зовут ${this.name}!`);
  }
}

// Создание объекта (экземпляра)
const myDog = new Animal("Шарик", 3);
myDog.sayHi(); // Вывод: Привет, меня зовут Шарик!

```

---

### 3. Инкапсуляция

**Инкапсуляция** — это скрытие внутренней логики и данных объекта от прямого доступа извне. Мы предоставляем только нужные «рычаги управления».

В современном JS для создания приватных свойств используется символ `#`.

```javascript
class BankAccount {
  #balance = 0; // Приватное свойство, недоступно вне класса

  constructor(owner) {
    this.owner = owner;
  }

  deposit(amount) {
    if (amount > 0) {
      this.#balance += amount;
      console.log(`Пополнено на ${amount}. Текущий баланс: ${this.#balance}`);
    }
  }

  getBalance() {
    return `Ваш баланс скрыт, но мы подтверждаем, что он в сохранности.`;
  }
}

const myAcc = new BankAccount("Иван");
myAcc.deposit(100);
// console.log(myAcc.#balance); // Ошибка! Доступа нет.

```

### 4. Наследование

**Наследование** позволяет создать новый класс на основе существующего, чтобы не дублировать код. Используется ключевое слово `extends`.

* `super()` — вызывает конструктор родителя (обязательно, если вы пишете свой конструктор в потомке).

```javascript
class Bird extends Animal {
  constructor(name, age, canFly) {
    super(name, age); // Вызываем конструктор Animal
    this.canFly = canFly;
  }

  fly() {
    if (this.canFly) {
      console.log(`${this.name} летит!`);
    } else {
      console.log(`${this.name} не умеет летать.`);
    }
  }
}

const eagle = new Bird("Орел", 5, true);
eagle.sayHi(); // Метод достался от Animal
eagle.fly();   // Свой метод Bird

```

## Практическое задание на уроке

**Задача:** Создать систему управления транспортом.

1. Создайте класс `Vehicle` (Транспорт) со свойствами `brand` и `speed`. Добавьте метод `move()`, который выводит: "[brand] едет со скоростью [speed] км/ч".
2. Создайте класс `Car`, который наследуется от `Vehicle`. Добавьте свойство `fuelLevel`.
3. Сделайте свойство `fuelLevel` приватным. Добавьте метод `refuel(amount)`, чтобы заправлять машину.

### Решение:

```javascript
class Vehicle {
  constructor(brand, speed) {
    this.brand = brand;
    this.speed = speed;
  }

  move() {
    console.log(`${this.brand} едет со скоростью ${this.speed} км/ч.`);
  }
}

class Car extends Vehicle {
  #fuelLevel = 0;

  constructor(brand, speed) {
    super(brand, speed);
  }

  refuel(amount) {
    this.#fuelLevel += amount;
    console.log(`Заправлено на ${amount} литров. Всего: ${this.#fuelLevel}`);
  }
}

const myCar = new Car("Tesla", 120);
myCar.move();
myCar.refuel(50);

```
