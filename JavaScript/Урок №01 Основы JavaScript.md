# Урок 1. Основы JavaScript
## 1. Базовые типы данных
**Примитивные типы данных** в JavaScript:
* **Number** — числа (целые и дробные)
```javascript
let age = 25;        // целое число
let pi = 3.14;       // дробное число
```
* **String** — строки (текстовая информация)
```javascript
let name = "Иван";   // строка в двойных кавычках
let surname = 'Петров';  // строка в одинарных кавычках
```
* **Boolean** — логические значения / булевские значения.
```javascript
let isReady = true;  // истина
let isCompleted = false;  // ложь
```
* **Null** — намеренное отсутствие значения
```javascript
let nothing = null;
```
* **Undefined** — переменная объявлена, но не инициализирована
```javascript
let unknown;        // значение undefined
```
## 2. Переменные
В JavaScript есть три способа объявления переменных:
* **let** — блочная область видимости
```javascript
let count = 0;
```
* **const** — константа (значение нельзя изменить)
```javascript
const PI = 3.14159;
```
* **var** — функциональная область видимости (устаревший способ)
```javascript
var message = "Привет!";
```
## 3. Операторы и выражения
**Основные операторы**:
* Арифметические:
```javascript
let a = 5;
let b = 2;
console.log(a + b);  // сложение
console.log(a - b);  // вычитание
console.log(a * b);  // умножение
console.log(a / b);  // деление
```
* Сравнения:
```javascript
console.log(a == b);    // равенство
console.log(a === b);   // строгое равенство
console.log(a > b);     // больше
console.log(a < b);     // меньше
```
## 4. Примитивы и объекты
**Примитивы** хранятся по значению, **объекты** — по ссылке:
### Примитивы
```javascript
let num1 = 5;
let num2 = num1;
num2 = 10;
console.log(num1);  // 5
```
### Объекты
```javascript
let obj1 = { name: "Олег" };
let obj2 = obj1;
obj2.name = "Петр";
console.log(obj1.name);  // Петр
```
## 5. Вывод информации
**Способы вывода**:
* В консоль браузера:
```javascript
let name = 'Bob'
console.log("Сообщение в консоль");
console.error("Ошибка");
console.warn("Предупреждение");
console.log("Hello, " + name); // Выведет Hello, Bob
```
* Через alert:
```javascript
alert("Привет, пользователь!");
alert('Hello, ' + name + '!'); // Выведет Hello, Bob!
```
