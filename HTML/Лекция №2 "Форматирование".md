# Лекция: Форматирование текста в HTML

## Введение

**HTML** предоставляет различные теги для форматирования текста, позволяющие изменить его внешний вид и выделить важные элементы. Форматирование текста улучшает читаемость и структуру веб-страницы.

## Основные теги для форматирования текста

1. **`<b>` и `<strong>` (жирный текст):**
   * `<b>`:  Определяет жирный текст. Визуально делает текст толще.
   * `<strong>`:  Определяет важный текст.  Визуально отображается жирным, но также добавляет семантическое значение (указывает на важность).  Рекомендуется использовать `<strong>`, чтобы подчеркнуть важность текста.

   Пример:

   ```html
   <p>Это обычный текст. <b>Этот текст жирный</b>, а <strong>этот текст очень важный!</strong></p>
   ```

2. **`<i>` и `<em>` (курсивный текст):**
   * `<i>`: Определяет курсивный текст. Визуально отображает текст наклонным.
   * `<em>`: Определяет выделенный текст.  Визуально отображается курсивом, но также добавляет семантическое значение (подчеркивает акцент или выделение).  Рекомендуется использовать `<em>` для указания на акцент.

   Пример:

   ```html
   <p>Обычный текст. <i>Этот текст курсивный</i>, а <em>этот текст выделен</em>.</p>
   ```

3. **`<mark>` (выделенный текст):**
   * Определяет выделенный текст (обычно желтым фоном).  Используется для выделения текста, например, при поиске.

   Пример:

   ```html
   <p>Вы искали: <mark>HTML</mark> форматирование текста.</p>
   ```

4. **`<small>` (мелкий текст):**
   * Определяет мелкий текст.  Обычно отображается меньшим размером шрифта, чем обычный текст.  Используется для подписей, сносок и менее важной информации.

   Пример:

   ```html
   <p>Основной текст. <small>Подпись к изображению.</small></p>
   ```

5. **`<del>` (зачеркнутый текст):**
   * Определяет зачеркнутый текст.  Обычно используется для указания на удаленный или устаревший текст.

   Пример:

   ```html
   <p><del>Этот текст удален</del> или исправлен.</p>
   ```

6. **`<ins>` (подчеркнутый текст):**
   * Определяет подчеркнутый текст.  Обычно используется для указания на добавленный или вставленный текст.

   Пример:

   ```html
   <p><ins>Этот текст добавлен</ins> в документ.</p>
   ```

7. **`<sub>` (нижний индекс) и `<sup>` (верхний индекс):**
   * `<sub>`:  Определяет нижний индекс.  Текст отображается ниже базовой линии.  Используется для формул, химических элементов и сносок.
   * `<sup>`: Определяет верхний индекс.  Текст отображается выше базовой линии.  Используется для степеней, порядковых номеров и сносок.

   Пример:

   ```html
   <p>H<sub>2</sub>O - формула воды.  5<sup>2</sup> = 25.</p>
   ```

8. **`<br>` (перенос строки):**
   * Вставляет перенос строки.  Не требует закрывающего тега.

   Пример:

   ```html
   <p>Это первая строка.<br>Это вторая строка.</p>
   ```

9. **`<wbr>` (мягкий перенос):**
   * Определяет положение, в котором браузер может выполнить перенос строки, если это необходимо для размещения текста.  Не требует закрывающего тега.  Полезно для длинных слов.

   Пример:

   ```html
   <p>Это очень длинное слово, которое может быть перенесено: <wbr>невероятнопродолжительноеслово.</p>
   ```

10. **`<q>` (цитата) и `<blockquote>` (длинная цитата):**
    * `<q>`:  Определяет короткую встроенную цитату.  Браузер обычно заключает текст в кавычки.
    * `<blockquote>`: Определяет длинную цитату.  Браузер обычно отображает цитату с отступом.  Также можно использовать атрибут `cite` для указания источника цитаты.

    Пример:

    ```html
    <p>Как сказал кто-то великий: <q>Будьте собой; все остальные уже заняты.</q></p>
    <blockquote cite="https://www.example.com/quote-source">
      Это длинная цитата, которая может занимать несколько абзацев.
    </blockquote>
    ```

11. **`<abbr>` (аббревиатура):**
    * Определяет аббревиатуру или акроним.  Используется атрибут `title` для предоставления полного значения аббревиатуры.  При наведении курсора на аббревиатуру, браузер отображает подсказку с полным значением.

    Пример:

    ```html
    <p>Я изучаю <abbr title="HyperText Markup Language">HTML</abbr>.</p>
    ```

12. **`<address>` (контактная информация):**
    * Определяет контактную информацию для документа или статьи.  Обычно отображается курсивом.

    Пример:

    ```html
    <address>
      Адрес: ул. Примерная, 123<br>
      Телефон: +7 (123) 456-78-90<br>
      Email: example@example.com
    </address>
    ```

13. **`<cite>` (название работы):**
    * Определяет название работы (например, книги, статьи, фильма и т.д.).  Обычно отображается курсивом.

    Пример:

    ```html
    <p>Книга <cite>Война и мир</cite> была написана Львом Толстым.</p>
    ```

## Важные замечания

* **Семантика:** При форматировании текста важно учитывать его семантическое значение.  Используйте теги, которые отражают смысл текста, а не только его внешний вид. Например, используйте `<strong>` вместо `<b>`, если текст важен.
* **CSS:**  Для более сложного форматирования и стилизации текста рекомендуется использовать CSS (Cascading Style Sheets). CSS позволяет контролировать размер шрифта, цвет, отступы, выравнивание и многое другое.  HTML-теги для форматирования текста обеспечивают базовое форматирование, а CSS предоставляет больше гибкости и возможностей.
* **Сочетание тегов:** Теги форматирования можно сочетать друг с другом для достижения желаемого эффекта.

  Пример:

  ```html
  <p><strong><em>Важный и выделенный текст.</em></strong></p>
  ```

## Заключение

HTML предоставляет широкий выбор тегов для форматирования текста, которые позволяют выделить важные элементы и улучшить читаемость веб-страницы. Понимание этих тегов и их правильное использование является важным навыком для любого веб-разработчика. Не забывайте о семантике и используйте CSS для более гибкого и сложного форматирования.
