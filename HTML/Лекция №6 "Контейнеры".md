## Что такое контейнеры?<!-- {"fold":true} -->

* **Объяснение:** Что такое контейнеры в контексте HTML?
  * Контейнеры – это элементы, которые используются для группировки и структурирования других элементов.
  * Они позволяют логически организовывать контент на веб-странице.
  * Они облегчают применение стилей (CSS) к группам элементов.
* **Визуализация:** 
  Верстка без использования контейнеров:
  ```html
  <!DOCTYPE html>
  <html lang="ru">
  <head>
    <meta charset="UTF-8">
    <title>Пример без контейнеров</title>
    <style>
        body {
            margin: 20px;
            font-family: Arial, sans-serif;
        }
        h1 {
            color: #333;
        }
        p {
            line-height: 1.6;
        }
    </style>
  </head>
  <body>
    <h1>Заголовок страницы</h1>
    <p>Это простой текст без использования контейнеров.</p>
    <p>Такой подход подходит для простых страниц с небольшим количеством элементов.</p>
  </body>
  </html>
  ```
  С использованием контейнеров:
  ```html
  <!DOCTYPE html>
  <html lang="ru">
  <head>
    <meta charset="UTF-8">
    <title>Пример с контейнерами</title>
    <style>
        body {
            margin: 0;
            padding: 0;
            font-family: Arial, sans-serif;
        }
        
        .container {
            width: 80%;
            margin: 20px auto;
            padding: 20px;
            background-color: #f9f9f9;
            box-shadow: 0 0 10px rgba(0,0,0,0.1);
        }
        
          header {
            background-color: #4CAF50;
            color: white;
            padding: 15px;
            text-align: center;
        }
        
        main {
            padding: 20px;
        }
        
          footer {
            background-color: #333;
            color: white;
            text-align: center;
            padding: 10px;
            margin-top: 20px;
        }
    </style>
  </head>
  <body>
    <div class="container">
        <header>
            <h1>Заголовок сайта</h1>
        </header>
        
        <main>
            <h2>Основной контент</h2>
            <p>Это пример использования контейнеров для структурирования контента.</p>
        </main>
        
          <footer>
            <p>© 2025 Все права защищены</p>
        	</footer>
    </div>
  </body>
  </html>
  ```
* **Обзор основных тегов-контейнеров:**
  * <div> — универсальный контейнер без семантического значения. 
  * <header> — определяет вводную часть документа или раздела. 
  * <nav> — контейнер для навигационных элементов. 
  * <main> — основной контент страницы. 
  * <article> — независимый самодостаточный контент. 
  * <aside> — дополнительный контент, связанный с основным.
  * <footer> — заключительная часть документа или раздела.
  * <section> — тематически сгруппированный контент.
  
* Блочные элементы (например, <р>, <div>) занимают всю доступную ширину, создают разрыв строки перед и после себя, и могут содержать другие блочные и строчные элементы. Строчные элементы (например, <span>, <a>) занимают только необходимую для содержимого ширину, не создают разрывов строки, и могут содержать только другие строчные элементы или текстовые данные. 

**Блочные элементы**
* Отображение: Начинаются с новой строки и занимают всю доступную ширину родительского контейнера, создавая видимый "блок". 
* Контейнер для: Могут содержать другие блочные элементы, строчные элементы и текстовые данные. 
* Примеры: <p>, <div>, <h1>, <li>.  
**Строчные элементы**
* Отображение: Располагаются в одной строке, занимая лишь ту ширину, которая требуется для их содержимого. 
* Контейнер для: Могут содержать только другие строчные элементы или текстовые данные. 
* Примеры: <span>, <a>, <em>, <strong>.  
**Ключевые различия**
* Ширина: Блочные занимают всю ширину; строчные — только по содержимому. 
* Разрыв строки: Блочные начинаются с новой строки и заканчиваются разрывом; строчные не создают разрывов. 
* Вложенность: Блочные могут содержать другие блочные элементы, строчные — только строчные. 
## Практическая часть 1: Основы `<div>`<!-- {"fold":true} -->

## Семантические контейнеры<!-- {"fold":true} -->

* **Объяснение:** Что такое семантические теги?
  * Семантические теги ( `<header>`, `<nav>`, `<main>`, `<article>`, `<aside>`, `<footer>`, `<section>`) описывают структуру контента, делая код более понятным для разработчиков и поисковых систем.
  * Они улучшают доступность веб-страниц.
* **Примеры:** Покажите, как использовать каждый из семантических тегов в контексте структуры веб-страницы.
  ```html
  <!DOCTYPE html>
  <html>
  <head>
      <title>Пример семантики</title>
  </head>
  <body>
      <header>
          <h1>Заголовок сайта</h1>
          <nav>
              <a href="#">Главная</a> | <a href="#">О нас</a> | <a href="#">Контакты</a>
          </nav>
      </header>
      <main>
          <article>
              <h2>Заголовок статьи</h2>
              <p>Содержание статьи...</p>
          </article>
          <aside>
              <h3>Боковая панель</h3>
              <p>Реклама или другая информация.</p>
          </aside>
      </main>
      <footer>
          <p>&copy; 2024</p>
      </footer>
  </body>
  </html>
  ```
* Без CSS они лишь создают структуру без визуального оформления, но их значение для поисковых систем и других программ, понимающих структуру страницы, огромно, поскольку они улучшают семантику, доступность и SEO, помогая лучше индексировать и интерпретировать контент. 
* SEO (Search Engine Optimization) — это комплекс мер по оптимизации сайта для поисковых систем, направленный на повышение его позиций в органической выдаче по целевым запросам пользователей. Цель SEO — привлечь на сайт как можно больше целевых посетителей (трафик) для увеличения продаж или распространения информации, обеспечивая при этом удобство использования ресурса для пользователей и его техническую оптимизацию. 

## Практика: Структурирование страницы с семантическими тегами<!-- {"fold":true} -->

* **Задание 2**
  * Создайте простую структуру веб-страницы, используя `<header>`, `<nav>`, `<main>`, `<article>`, `<aside>`, `<footer>`.
  * Добавьте базовый контент (заголовки, ссылки, текст).
###### **Решение**<!-- {"fold":true} -->
  ```html
  <!DOCTYPE html>
  <html>
  <head>
    <meta charset="UTF-8">
    <title>Базовая структура веб-страницы</title>
  </head>
  <body>
    <!-- Шапка сайта -->
    <header>
        <h1>Добро пожаловать на наш сайт</h1>
        <p>Ваш надежный источник информации</p>
    </header>
  
    <!-- Навигация -->
    <nav>
        <a href="#home">Главная</a> | <a href="#about">О нас</a> | <a href="#contact">Контакты</a>
    </nav>
  
    <!-- Основное содержимое -->
    <main>
        <!-- Статья -->
        <article>
            <h2>Новости компании</h2>
            <p>Мы рады сообщить о запуске нового проекта!</p>
            <p>Этот проект поможет нашим клиентам сэкономить время и деньги.</p>
        </article>
    </main>
  
      <!-- Боковая колонка -->
    <aside>
        <h3>Полезные ссылки</h3>
        <ul>
            <li><a href="#">Блог компании</a></li>
            <li><a href="#">FAQ</a></li>
            <li><a href="#">Отзывы клиентов</a></li>
        </ul>
    </aside>
  
    <!-- Подвал сайта -->
    <footer>
        <p>&copy; 2025 Моя компания. Все права защищены.</p>
        <p>Телефон: 8 800 555 35 35</p>
        <p>Email: mail@company.ru</p>
    </footer>
  </body>
  </html>
  ```

## Вложенность контейнеров<!-- {"fold":true} -->

* **Объяснение:**
  * Контейнеры могут быть вложены друг в друга для создания более сложной структуры.
* **Примеры:** Примеры вложенности.
  ```html
  <!DOCTYPE html>
  <html>
  <head>
      <title>Вложенные контейнеры</title>
  </head>
  <body>
    <div class="container">
        <h2>Внешний контейнер</h2>
        <div class="inner-container">
            <p>Внутренний контейнер</p>
        </div>
    </div>
  </body>
  </html>
  ```
## Практическая часть 3: Создание более сложной структуры<!-- {"fold":true} -->

* **Задание 3**
  * Создайте структуру веб-страницы, используя вложенные контейнеры.
  * Например: `<header>`, `<main>` (содержащий `<article>` и `<aside>`), `<footer>`.

  ```html
  <!DOCTYPE html>
  <html>
  <head>
    <meta charset="UTF-8">
    <title>Пример структуры веб-страницы</title>
  </head>

        <h1>Добро пожаловать на сайт</h1>

            <ul>
                <li><a href="#home">Главная</a></li>
                <li><a href="#about">О нас</a></li>
                <li><a href="#services">Услуги</a></li>
                <li><a href="#contact">Контакты</a></li>
            </ul>
        </nav>
    </header>
  
    <!-- Основное содержимое страницы -->
    <main>
        <!-- Основной контент -->
        <article>
            <section>
                <h2>Новости и статьи</h2>
                <p>Здесь размещается основной контент сайта, например, статьи, новости или блог.</p>

            <h2>Полезные ссылки</h2>

                <li><a href="#">Архив новостей</a></li>

                <li><a href="#">Telegram</a></li>
                <li><a href="#">YouTube</a></li>
            </ul>
        </aside>
    </main>
  ```

## Домашнее задание<!-- {"fold":true} -->

**Вариант 1: Базовый**
