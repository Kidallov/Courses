# Лекция: Теги HTML, структура страницы и обязательные элементы

## Введение

**HTML** (HyperText Markup Language) - это язык разметки, используемый для создания веб-страниц. Веб-страница представляет собой документ, который браузер интерпретирует и отображает для пользователя. Структура HTML-страницы организована с помощью тегов.

## Что такое теги?

**Тег (tag)** - это ключевой элемент HTML. Тег - это специальный код, который указывает браузеру, как отображать информацию на странице. Теги обычно состоят из:

* **Открывающего тега:** `<имя_тега>`
* **Содержимого:** Текст, изображения, другие теги и т.д.
* **Закрывающего тега:** `</имя_тега>` (закрывающий тег всегда содержит косую черту перед именем тега)

**Пример**
```html
<h1>Заголовок страницы</h1>
<p>Это абзац текста.</p>
```
**В этом примере:**

* `<h1>` - открывающий тег для заголовка первого уровня.
* `Заголовок страницы` - содержимое заголовка.
* `</h1>` - закрывающий тег для заголовка.
* `<p>` - открывающий тег для абзаца.
* `Это абзац текста.` - содержимое абзаца.
* `</p>` - закрывающий тег для абзаца.

Существуют также самозакрывающиеся теги, которые не требуют закрывающего тега. Например: `<br>` (перенос строки) или `<img src="image.jpg" alt="Описание изображения">`.

## Структура HTML-страницы

Каждая HTML-страница имеет определенную структуру, которая включает в себя обязательные элементы. Основная структура HTML-документа выглядит следующим образом:

```html
<!DOCTYPE html>
<html lang="ru">
<head>
    <meta charset="UTF-8">
    <title>Название страницы</title>
</head>
<body>
    <!-- Здесь размещается видимое содержимое страницы -->
    <h1>Заголовок</h1>
    <p>Текст абзаца.</p>
</body>
</html>
```

## Обязательные элементы и их расшифровка:

1. **`<!DOCTYPE html>`**:
   * **Расшифровка:**  Это объявление типа документа. Оно сообщает браузеру, что это HTML5-документ.  Оно должно быть первой строкой в HTML-файле.  Хотя это не тег, а объявление, его важность в определении типа документа нельзя недооценивать.

2. **`<html lang="ru">`**:
   * **Расшифровка:** Корневой элемент HTML-документа.  Атрибут `lang="ru"` указывает язык документа (в данном случае, русский).  Этот атрибут помогает поисковым системам и браузерам правильно интерпретировать контент и учитывать его при поиске и озвучивании.

3. **`<head>`**:
   * **Расшифровка:**  Содержит мета-информацию о документе, которая не отображается непосредственно на странице, но предоставляет информацию для браузера, поисковых систем и других инструментов.

   * **Основные элементы внутри `<head>`:**

     * **`<meta charset="UTF-8">`**:  Определяет кодировку символов для документа.  `UTF-8` - наиболее распространенная кодировка, которая поддерживает большинство символов. Это важно для правильного отображения текста, включая кириллицу.
     * **`<title>Название страницы</title>`**:  Определяет заголовок страницы, который отображается в вкладке браузера и в результатах поиска.  Заголовок важен для SEO (оптимизации для поисковых систем).

     * **`<meta name="description" content="Краткое описание страницы">`**: Содержит краткое описание содержания страницы. Используется поисковыми системами для отображения в результатах поиска.
     * **`<meta name="keywords" content="ключевые слова, разделенные, запятыми">`**:  Содержит ключевые слова, относящиеся к содержанию страницы.  Хотя этот тег менее важен для SEO, чем раньше, он может помочь поисковым системам понять тематику страницы.
     * **`<link rel="stylesheet" href="style.css">`**:  Связывает HTML-документ с таблицей стилей CSS (например, `style.css`), определяющей внешний вид страницы.

4. **`<body>`**:
   * **Расшифровка:**  Содержит видимое содержимое страницы, которое отображается в окне браузера.  Внутри `<body>` размещаются все элементы, которые пользователь видит: текст, изображения, видео, ссылки, формы и т.д.

   * **Примеры элементов внутри `<body>`:**

     * `<h1>` - `<h6>`: Заголовки разного уровня.
     * `<p>`: Абзацы текста.
     * `<img>`: Изображения.
     * `<a href="...">`: Ссылки.
     * `<div>`: Блочные контейнеры для группировки контента.
     * `<nav>`: Элементы навигации.
     * `<header>`: Шапка сайта.
     * `<footer>`: Подвал сайта.
     * `<article>`: Статьи или отдельные блоки контента.
     * `<section>`: Секции контента.

## Заключение

Понимание структуры HTML-документа и обязательных элементов является критически важным для создания веб-страниц. Эти элементы обеспечивают правильную структуру и позволяют браузеру корректно отображать контент.  Использование правильных тегов и атрибутов также способствует улучшению SEO и доступности вашего сайта.
