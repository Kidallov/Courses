# Лекция: Ссылки и изображения в HTML

## Введение

**Ссылки и изображения** – это два важнейших элемента веб-страниц. Ссылки позволяют пользователям перемещаться между страницами, а изображения делают контент более привлекательным и информативным. В этой лекции мы рассмотрим, как использовать теги `<a>` (ссылки) и `<img>` (изображения) в HTML.

## Ссылки: Тег `<a>`

Тег `<a>` (anchor – якорь) используется для создания ссылок.  Основные атрибуты тега `<a>`:

* **`href`**:  (required - обязательный)  Атрибут `href` указывает URL (Uniform Resource Locator – универсальный указатель ресурса), на который ведет ссылка.  Это может быть адрес другой веб-страницы, файла или якоря на текущей странице.
* **`target`**:  Определяет, где открывать ссылку.  Основные значения:
  * `_blank`: Открыть ссылку в новой вкладке или окне.
  * `_self`: Открыть ссылку в текущем окне/вкладке (по умолчанию).
  * `_parent`: Открыть ссылку в родительском фрейме (если страница находится во фрейме).
  * `_top`: Открыть ссылку в самом верхнем фрейме (если страница находится во фрейме).
* **`title`**:  Предоставляет всплывающую подсказку при наведении курсора на ссылку.  Улучшает доступность.
* **`rel`**:  Определяет отношение между текущей страницей и целевой страницей.  Используется для SEO и безопасности (например, `rel="noopener"`, `rel="nofollow"`).

**Примеры**

* **Ссылка на другую страницу:**

  ```html
  <a href="https://www.example.com">Перейти на Example.com</a>
  ```

* **Ссылка, открывающаяся в новой вкладке:**

  ```html
  <a href="https://www.example.com" target="_blank">Открыть в новом окне</a>
  ```

* **Ссылка на якорь (раздел) на той же странице:**

  Сначала нужно создать якорь:

  ```html
  <h2 id="section1">Раздел 1</h2>
  ```

  Затем создать ссылку на этот якорь:

  ```html
  <a href="#section1">Перейти к Разделу 1</a>
  ```

* **Ссылка на email:**

  ```html
  <a href="mailto:example@example.com">Написать письмо</a>
  ```

* **Ссылка на телефон:**

  ```html
  <a href="tel:+71234567890">Позвонить</a>
  ```

## Изображения: Тег `<img>`

Тег `<img>` используется для вставки изображений на веб-страницу.  Основные атрибуты тега `<img>`:

* **`src`**: (required - обязательный)  Атрибут `src` указывает URL изображения.  Это может быть ссылка на изображение в интернете или путь к изображению на вашем сервере.
* **`alt`**: (required - обязательный)  Атрибут `alt` предоставляет альтернативный текст для изображения.  Этот текст отображается, если изображение не может быть загружено, или используется для улучшения доступности (для людей с нарушениями зрения, использующих скринридеры).  **Всегда используйте `alt`!**
* **`width`**:  Указывает ширину изображения в пикселях.
* **`height`**: Указывает высоту изображения в пикселях.
* **`title`**:  Предоставляет всплывающую подсказку при наведении курсора на изображение.
* **`loading`**: Определяет, как браузер должен загружать изображение. Возможные значения:
  * `eager`:  Загружать изображение немедленно. (По умолчанию)
  * `lazy`:  Откладывать загрузку изображения до тех пор, пока оно не приблизится к области просмотра.  Улучшает производительность, особенно для длинных страниц.

**Примеры:**

* **Вставка изображения с указанием URL:**

  ```html
  <img src="https://www.example.com/image.jpg" alt="Описание изображения">
  ```

* **Вставка изображения с указанием пути к файлу (предполагается, что изображение находится в той же папке, что и HTML-файл):**

  ```html
  <img src="image.jpg" alt="Описание изображения" width="200" height="150">
  ```

* **Использование атрибута `loading="lazy"`:**

  ```html
  <img src="image.jpg" alt="Описание изображения" loading="lazy">
  ```

## Рекомендации

* **Оптимизируйте изображения:** Сжимайте изображения, чтобы уменьшить их размер и ускорить загрузку страницы.
* **Используйте правильные форматы изображений:**
  * `JPEG`:  Для фотографий и изображений с большим количеством цветов.
  * `PNG`:  Для изображений с прозрачностью и графикой.
  * `SVG`:  Для векторной графики (логотипы, иконки), масштабируется без потери качества.
* **Всегда используйте атрибут `alt`**:  Это необходимо для доступности и поисковой оптимизации. Описание должно быть информативным и описывать содержимое изображения.
* **Указывайте размеры изображений:**  Это помогает браузеру правильно отображать страницу во время загрузки изображений.

## Заключение

**Ссылки и изображения** – это важные элементы HTML, которые позволяют создавать интерактивные и привлекательные веб-страницы.  Правильное использование тегов `<a>` и `<img>`, а также их атрибутов, поможет вам создавать качественный веб-контент.
