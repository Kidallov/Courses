
# Лекция: Таблицы в HTML

## Введение

Таблицы в HTML используются для организации данных в строки и столбцы. Они позволяют эффективно представлять структурированную информацию, такую как данные, списки, расписания и т.д. В этой лекции мы рассмотрим основные теги, используемые для создания таблиц в HTML.

## Основные теги для создания таблиц

1. **`<table>`**:
   * Определяет таблицу. Это основной контейнер для всех элементов таблицы.

2. **`<tr>`**:
   * (table row - строка таблицы) Определяет строку в таблице. Каждый `<tr>` содержит ячейки строки.

3. **`<td>`**:
   * (table data - данные таблицы) Определяет ячейку данных в таблице. Содержит фактические данные.

4. **`<th>`**:
   * (table header - заголовок таблицы) Определяет ячейку заголовка таблицы. Обычно используется для заголовков столбцов или строк. Текст в `<th>` обычно отображается жирным и выровнен по центру.

5. **`<caption>`**:
   * Определяет заголовок таблицы. Отображается над таблицей.

6. **`<colgroup>`**:
   * Определяет группу столбцов таблицы для применения стилей. Используется совместно с тегом `<col>`.

7. **`<col>`**:
   * Определяет свойства для одного или нескольких столбцов в `<colgroup>`.

8. **`<thead>`**:
   * Определяет раздел заголовка таблицы.

9. **`<tbody>`**:
   * Определяет раздел тела таблицы.

10. **`<tfoot>`**:
    * Определяет раздел подвала таблицы.

## Структура таблицы

Типичная структура таблицы выглядит следующим образом:

```html
<table>
  <caption>Заголовок таблицы</caption>
  <thead>
    <tr>
      <th>Заголовок 1</th>
      <th>Заголовок 2</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td>Данные 1</td>
      <td>Данные 2</td>
    </tr>
    <tr>
      <td>Данные 3</td>
      <td>Данные 4</td>
    </tr>
  </tbody>
  <tfoot>
    <tr>
      <td>Итого:</td>
      <td>...</td>
    </tr>
  </tfoot>
</table>
```

## Атрибуты тегов таблиц

Некоторые важные атрибуты для тегов таблиц:

* **`<table>`:**
  * `border`:  Указывает толщину границы таблицы (устаревший, рекомендуется использовать CSS).
  * `cellpadding`:  Указывает расстояние между содержимым ячейки и ее границей (устаревший, рекомендуется использовать CSS).
  * `cellspacing`: Указывает расстояние между ячейками (устаревший, рекомендуется использовать CSS).
  * `width`:  Указывает ширину таблицы (устаревший, рекомендуется использовать CSS).
* **`<td>` и `<th>`:**
  * `colspan`:  Объединяет ячейку по горизонтали (вправо).  `colspan="2"` объединяет две ячейки.
  * `rowspan`:  Объединяет ячейку по вертикали (вниз).  `rowspan="2"` объединяет две ячейки.
  * `align`:  Выравнивание содержимого ячейки (устаревший, рекомендуется использовать CSS).
  * `valign`:  Вертикальное выравнивание содержимого ячейки (устаревший, рекомендуется использовать CSS).

## Примеры

* **Простая таблица:**

  ```html
  <table>
    <tr>
      <th>Имя</th>
      <th>Возраст</th>
    </tr>
    <tr>
      <td>Иван</td>
      <td>30</td>
    </tr>
    <tr>
      <td>Мария</td>
      <td>25</td>
    </tr>
  </table>
  ```

* **Таблица с заголовком:**

  ```html
  <table>
    <caption>Список дел</caption>
    <tr>
      <th>Задача</th>
      <th>Статус</th>
    </tr>
    <tr>
      <td>Купить продукты</td>
      <td>Выполнено</td>
    </tr>
    <tr>
      <td>Постирать белье</td>
      <td>В процессе</td>
    </tr>
  </table>
  ```

* **Таблица с объединением ячеек:**

  ```html
  <table>
    <tr>
      <th rowspan="2">Имя</th>
      <th colspan="2">Контакты</th>
    </tr>
    <tr>
      <th>Телефон</th>
      <th>Email</th>
    </tr>
    <tr>
      <td>Иван</td>
      <td>123-456-7890</td>
      <td>ivan@example.com</td>
    </tr>
  </table>
  ```

## Рекомендации

* **Семантика:** Используйте теги `<thead>`, `<tbody>`, `<tfoot>` для структурирования таблицы и лучшей семантики.
* **Доступность:**  Убедитесь, что таблицы понятны для пользователей с нарушениями зрения.  Используйте теги заголовков (`<th>`) для обозначения заголовков столбцов и строк.  Если таблица сложная, используйте атрибуты `scope` для `<th>` (например, `scope="col"` или `scope="row"`) для указания области применения заголовка.
* **Оптимизируйте структуру:**  Избегайте слишком сложных таблиц с большим количеством объединенных ячеек, если это возможно.

## Заключение

Таблицы в HTML являются мощным инструментом для представления данных.  Понимание тегов, атрибутов и принципов структурирования таблиц поможет вам эффективно организовывать информацию на ваших веб-страницах.  Помните о семантике, доступности и используйте CSS для стилизации.
